三、全书统一约定（动画与代码严格一致）

  • Clarke 采用幅值不变形式（系数 2/3）；α 轴与 A 相绕组轴线重合，β 轴超前 α 90°。
  • 正方向：逆时针为正。A→B→C 正相序时电流空间矢量逆时针旋转，电角度 θe 增大，对应「正转」。
  • Park：id = iα·cosθ + iβ·sinθ；iq = −iα·sinθ + iβ·cosθ；复数写法 i_dq = i_αβ·e^(−jθ)。反 Park：vα = vd·cosθ − vq·sinθ；vβ = vd·sinθ + vq·cosθ。
  • d 轴对准永磁体磁链方向，q 轴超前 d 轴 90°；iq > 0 产生正向电磁转矩。
  • 相电流正方向：从逆变器流入电机为正。
  • 角度格式 uint16：16384 = 90°，32768 = 180°，加法溢出即自动取模 2π。

第一部分：小节基础

链路位置FOC 最前端：ADC 原始码值 → 物理电流 → 标幺 Q15；同样用于母线电压、温度、旋变角度换算
输入 / 输出输入：ADC 码值 N、标定偏移 N0、增益 K；输出：电流 A、标幺值、Q15 整数
工程价值所有后续计算都建立在「数值代表什么物理量」之上；换算错一处，Clarke/Park/PI 全部失真
上下游依赖下游：C01 电流采样校准、D02 定点实现、C05 PI 标幺参数
适用角色全部角色；MCU 底层与标定工程师必修
前置数学依赖无（本节为起点）
① 为什么需要MCU 只认识整数码值。不会线性映射与移项，就无法把 ADC 读数变成电流，也无法写出 di/dt = (v − R·i)/L 这类后续公式。
② 量产怎么做上电 PWM 关闭时做偏移校准，产线/台架做两点增益标定；中断内用整数乘加 + 移位完成换算，统一标幺基值。
③ 如何证明静止零电流时读数 < 0.1 A；对比钳形表/功率分析仪，增益误差 < 1%；满量程不削顶。

第二部分：前置条件

  • 信号：两相电流 ADC 码值；硬件：采样电阻 + 运放偏置在 ADC 中点。
  • 标定参数：Cal_IaOffset_cnt、Cal_IaGainCorr_q15（B 相同理）。
  • 不满足的现象：偏移未校准 → 静止有「假电流」，运行中 dq 电流出现电频率一次脉动；量程不足 → 波形削顶，过流保护失效或误报。

第三部分：核心原理与公式

【理论公式】线性映射（一次函数）：

I = (N − N0) · K N：ADC 码值；N0：零电流对应码值（偏移）；K：A/码值（增益） 案例：±50 A ↔ 0~4095 → K = 100 A / 4096 = 0.024414 A/cnt，N0 理想 = 2048 【案例假设】

【理论公式】两点标定（二元一次方程组）：已知 (N1, I1)、(N2, I2) 两组实测点

K = (I2 − I1) / (N2 − N1) N0 = N1 − I1 / K

【理论公式】移项求解（后续每章都在用）：由 RL 电压方程 v = R·i + L·di/dt

di/dt = (v − R·i) / L ← 「把要求的量单独放到等号一边」

【理论公式】标幺化与 Q15：

i_pu = I / I_BASE （I_BASE = 50 A） i_q15 = round(i_pu · 32768)，范围 [−32768, 32767] 案例巧合设计：每个 ADC 码对应 Q15 增量 = K·32768/I_BASE = 0.024414×32768/50 = 16（恰为 2⁴，可用移位）

【理论公式】限幅（分段函数）：sat(x) = x_max（x > x_max）；x_min（x < x_min）；x（其他）。

动画在演示什么：一个真实正弦相电流经过「硬件零点」变成 ADC 码，再用「软件偏移 + 增益修正」换算回电流和 Q15。左图是换算直线（蓝）与真实直线（灰虚线），右图是时域对比。
拖动滑块：让「软件偏移」≠「硬件零点」，蓝线整体平移，时域出现直流偏置；增益修正 ≠ 1，峰值被放大/缩小；电流峰值 > 50 A，ADC 卡在 0/4095，波形削顶。
正常现象：灰蓝重合，偏移误差显示绿色。异常：偏置、比例错误、削顶（红色提示）。

第四部分：嵌入式实现步骤

  1. 上电偏移校准（目的：得到 N0）：PWM 输出关闭、运放上电稳定 ≥ 数十 ms 后，每 PWM 周期采样，累加 1024 次求平均（右移 10 位）。中断约束：只读 ADC，不运行电流环。标定量：结果写入 Cal_IaOffset_cnt，超出 2048 ± 100 视为采样电路故障。
  2. 两点增益标定（台架/产线）：直流注入已知电流（如 A 进 B 出 +20 A），用精密表计读 I，代入两点公式得增益修正，写入 Cal_IaGainCorr_q15。
  3. 中断内换算：(adc − off) 用 int32 运算 → 左移 4 位得 Q15 → 乘增益修正（Q15×Q15 >> 15）→ 饱和到 int16。
  4. 溢出保护：(adc − off) 范围约 ±2100，×16 后可达 ±33600，超出 int16，必须先在 int32 中运算再饱和。
  5. 第三相：星接无中线，ic = −ia − ib（A03 证明）。

第五部分：仿真与波形预期

  • 正常：PWM 关闭时 ia、ib 在 0 附近，噪声峰峰值 ≤ 若干码；运行时三相正弦幅值一致、相差 120°。
  • 偏移误差：相电流中心线偏离 0；在 dq 中表现为以电频率脉动的纹波（直流量经 Park 变成一倍频交流）。
  • 增益不一致（A/B 相差几个 %）：dq 中出现 2 倍电频率纹波。
  • 削顶：波形顶部平直，过流判断失效。

第六部分：EPS 案例实现

【定点实现】Q15 基础工具（全书共用，D02 会扩展）：

#include <stdint.h>
typedef int16_t q15_t;

#define Q15_MAX   ((int32_t)32767)
#define Q15_MIN   ((int32_t)-32768)

static inline q15_t Q15_Sat(int32_t x)
{
    if (x > Q15_MAX) { return (q15_t)Q15_MAX; }
    if (x < Q15_MIN) { return (q15_t)Q15_MIN; }
    return (q15_t)x;
}

/* Q15 × Q15：(-1)×(-1) = +1.0 超出 Q15，必须饱和 */
static inline q15_t Q15_Mul(q15_t a, q15_t b)
{
    return Q15_Sat(((int32_t)a * (int32_t)b) >> 15);
}

【定点实现】偏移校准与中断换算：

#define OFFS_CAL_SHIFT   (10u)            /* 1024 次平均 */
#define OFFS_VALID_MIN   (1948)           /* 2048 - 100  【案例假设】 */
#define OFFS_VALID_MAX   (2148)

static uint32_t s_offAccA = 0u, s_offAccB = 0u;
static uint16_t s_offCnt  = 0u;

/* PWM 关闭状态下，在 PWM 中断中调用；返回 1 表示完成 */
uint8_t FOC_OffsetCal_Isr(void)
{
    s_offAccA += gFoc.adcIa;
    s_offAccB += gFoc.adcIb;
    s_offCnt++;
    if (s_offCnt >= (1u << OFFS_CAL_SHIFT)) {
        int16_t offA = (int16_t)(s_offAccA >> OFFS_CAL_SHIFT);
        int16_t offB = (int16_t)(s_offAccB >> OFFS_CAL_SHIFT);
        if ((offA >= OFFS_VALID_MIN) && (offA <= OFFS_VALID_MAX) &&
            (offB >= OFFS_VALID_MIN) && (offB <= OFFS_VALID_MAX)) {
            Cal_IaOffset_cnt = offA;
            Cal_IbOffset_cnt = offB;
        } else {
            Diag_SetFault(DIAG_ISENSE_OFFSET);   /* 采样电路异常 */
        }
        return 1u;
    }
    return 0u;
}

/* ADC → Q15：每码 = 16 LSB（±50 A 量程 / I_BASE 50 A） */
static inline q15_t FOC_AdcToIq15(uint16_t adc, int16_t off, q15_t gainCorr)
{
    int32_t x = ((int32_t)adc - (int32_t)off) * 16;      /* 先在 int32 中运算 */
    x = (x * (int32_t)gainCorr) >> 15;                   /* 增益修正 Q15     */
    return Q15_Sat(x);
}

void FOC_CurrentConvert_Isr(void)
{
    gFoc.ia = FOC_AdcToIq15(gFoc.adcIa, Cal_IaOffset_cnt, Cal_IaGainCorr_q15);
    gFoc.ib = FOC_AdcToIq15(gFoc.adcIb, Cal_IbOffset_cnt, Cal_IbGainCorr_q15);
    gFoc.ic = Q15_Sat(-(int32_t)gFoc.ia - (int32_t)gFoc.ib);
}

说明：增益修正 Cal_IaGainCorr_q15 的标称值 32767（≈1.0）；若需要 > 1.0 的修正，改用 Q14 格式。Diag_SetFault 属于 C12 诊断模块接口。

第七部分：高频调试问题 / 数学易错点

【高频故障】静止时相电流读数不为零
现象
PWM 关闭，CANape 显示 ia ≈ +1.2 A，ib ≈ −0.4 A。
可能根因
偏移校准时运放未稳定；校准时 PWM 已开（有真实电流）；NVM 中旧标定值覆盖了上电校准值。
排查顺序
① 读 Cal_IaOffset_cnt 与 ADC 原始均值对比 → ② 查校准触发时序（与 PWM 使能、运放供电的先后）→ ③ 查是否有写覆盖。
修复
校准延后至供电稳定；校准期间强制 PWM 关闭；增加有效范围判断。
验证波形
静止 ia/ib 均值 < 0.1 A；运行时 iq 频谱一倍电频率分量明显下降。
【高频故障】大电流时波形削顶
现象
堵转大电流测试时相电流顶部平直，过流保护不动作。
可能根因
运放输出饱和早于 ADC 满量程；量程设计不足；偏移偏离中点导致单边量程变小。
排查顺序
示波器同时测运放输出与 ADC 码值 → 计算正负方向剩余量程。
修复
量程至少覆盖最大保护阈值 × 1.2；软件增加「ADC 码值接近 0/4095」诊断。
验证波形
阶跃到保护阈值，波形完整，保护按设定值触发。
数学易错点：无符号减法回绕
现象
电流偶尔跳到 +2000 A 量级。
可能根因
写成 (uint32_t)adc - off，adc < off 时结果回绕成大正数。
排查顺序
在电流为负的半周抓数据；静态代码检查（MISRA 本质类型规则）。
修复
两个操作数都先转 int32 再相减。
验证
负半周波形连续；单元测试覆盖 adc = 0、off = 2148。

第八部分：工程踩坑

  • 整数除法截断：先乘后除（a*b/c），并确认乘积不溢出。
  • 负数右移：C 标准中负数右移是实现定义；Arm 编译器为算术右移，但需在编码规范中明确并做单元测试。
  • 基值混用：电流环用 50 A 基值、保护模块用 100 A 基值，比较阈值时直接相比 → 保护点差一倍。全项目只用一套基值头文件。
  • Q15 无法表示 +1.0：最大 32767/32768；-1 × -1 必须饱和。
  • 温漂：偏移随温度变化，长时间运行可考虑在零矢量/停机期间周期性重校准。

第一部分：小节基础

第三部分：核心原理与公式

【理论公式】 矢量 v = (x, y)；模长 |v| = √(x² + y²)；角度 θ = atan2(y, x)（四象限） 合成：a + b = (ax + bx, ay + by) ← 平行四边形法则 点积：a · b = ax·bx + ay·by = |a||b|cos∠(a,b) 投影：v 在单位矢量 e 方向上的分量 = v · e 旋转坐标系（新轴 d 与 x 轴夹角 φ，q 超前 d 90°）： vd = x·cosφ + y·sinφ vq = −x·sinφ + y·cosφ ← 这就是 Park 变换的几何本质 电压限幅（SVPWM 线性区内切圆）：√(vd² + vq²) ≤ Vdc/√3（12 V 时 6.93 V）
动画在演示什么：两个矢量 a、b 合成 a+b（平行四边形），并把合成矢量投影到一套旋转坐标轴 d、q 上。右图记录 d、q 分量随坐标轴旋转的变化。
拖动滑块：改变 a、b 的模长和角度，合成矢量随之改变；启动后坐标轴 φ 逆时针旋转，固定矢量在旋转坐标系里的分量变成正弦——这正是「静止矢量在旋转坐标系中看是交流」，反之旋转矢量在同步旋转坐标系中看是直流（A04）。
正常：投影垂足落在轴上，d²+q² 恒等于 |a+b|²。异常判断：若你的代码算出的 d²+q² 不守恒，说明 sin/cos 或符号写错。

第四部分：嵌入式实现步骤

  1. 投影：4 次 Q15 乘法 + 2 次加减，int32 累加后右移 15 位再饱和。
  2. 模长：平方和在 Q30（int32）中计算，整数开方得 Q15；仅在慢任务或限幅时使用，避免中断内频繁开方。
  3. 角度：atan2 用「八分区 + 查表」或 CORDIC；禁止 atan(y/x)（丢象限、x=0 除零）。
  4. 电压限幅（d 轴优先）：先限 vd，再按 √(Vmax² − vd²) 限 vq。Vmax 每周期由 Vdc 实时计算，标定量可设裕量系数。

/* 输入 Q30（非负），输出 Q15：sqrt(x·2^30) = sqrt(x)·2^15 */
static q15_t Q15_SqrtQ30(int32_t xQ30)
{
    uint32_t x = (xQ30 > 0) ? (uint32_t)xQ30 : 0u;
    uint32_t r = 0u;
    uint32_t b = 1uL << 30;
    while (b > x) { b >>= 2; }
    while (b != 0u) {
        if (x >= (r + b)) { x -= (r + b); r = (r >> 1) + b; }
        else              { r >>= 1; }
        b >>= 2;
    }
    return (q15_t)((r > 32767u) ? 32767u : r);
}

/* d 轴优先圆限幅；vMax = Vdc/√3 的标幺值（12 V 时 6.93/16 = 0.433 → 14189） */
void FOC_VoltLimit(q15_t *vd, q15_t *vq, q15_t vMax)
{
    int32_t vqMax;
    if (*vd >  vMax) { *vd = vMax; }
    if (*vd < -vMax) { *vd = (q15_t)(-vMax); }
    vqMax = Q15_SqrtQ30(((int32_t)vMax * vMax) - ((int32_t)(*vd) * (*vd)));
    if (*vq >  vqMax) { *vq = (q15_t)vqMax; }
    if (*vq < -vqMax) { *vq = (q15_t)(-vqMax); }
}

d 轴优先 vs 等比例缩放：EPS 力矩模式中，d 轴电压承担弱磁与解耦，优先保证 d 轴可维持磁场控制；等比例缩放保持电压方向不变，实现简单但弱磁区 id 控制易失效。两者均为业内常见做法，按项目验证选择。

  • 前置数学：A02 单位矢量。弧度：一整圈 = 2π rad = 360°。
  • 信号：旋变电角度 θe；电角速度 ωe（用于补偿）。

第三部分：核心原理与公式

【理论公式】 单位圆：角度 θ 处单位矢量 = (cosθ, sinθ)；sin²θ + cos²θ = 1 角频率：ω = 2πf；电角度 θe = p·θm，电角速度 ωe = p·ωm，电频率 fe = p·n/60 案例：3000 rpm → fe = 4×3000/60 = 200 Hz；8000 rpm → 533.3 Hz 三相平衡电流：ia = I·cos(θ+γ)，ib = I·cos(θ+γ−120°)，ic = I·cos(θ+γ+120°)，ia+ib+ic = 0 和差角公式：cos(a−b) = cos a·cos b + sin a·sin b sin(a−b) = sin a·cos b − cos a·sin b 用它证明 Park 的效果：设 iα = I·cos(θ+γ)，iβ = I·sin(θ+γ) id = iα·cosθ + iβ·sinθ = I·cos(θ+γ−θ) = I·cosγ ← 与 θ 无关，直流！ iq = −iα·sinθ + iβ·cosθ = I·sin(θ+γ−θ) = I·sinγ
【离散实现】每 PWM 周期电角度增量 Δθ = ωe·Ts 案例 8000 rpm：Δθ = 2π·533.3·50 µs = 0.1676 rad ≈ 9.6° 采样→PWM 生效的等效延迟约 1.5Ts（中断计算 1Ts + PWM 中心对齐 0.5Ts）→ 约 14.4° 角度误差
动画在演示什么：左边单位圆上的矢量逆时针旋转（与全书正方向一致），它在水平轴的投影就是 cosθ（A 相电流形状），竖直投影是 sinθ。右边画出三相余弦及其和。
拖动滑块：「频率」改变旋转快慢；「C 相相位偏差」模拟三相不平衡——三相和不再为 0，这时「用 ic = −ia − ib 推算第三相」的假设失效。
正常：三相和曲线恒为 0。异常：和曲线出现正弦，提示相序/采样/硬件不平衡。

第四部分：嵌入式实现步骤

  1. 角度格式：uint16 表示 0~2π，16384 = 90°；加法溢出天然取模，无需判断。
  2. 查表：1024 点 sin 表（2 KB Flash，末尾多存 1 点便于插值）；高 10 位作索引，低 6 位线性插值。
  3. cos：cosθ = sin(θ + 90°)，即索引 +16384。
  4. 电角度：θe = (θm × p) 在 uint16 上直接乘 4 截断（自动取模），再减零位偏移 Cal_ThetaOffset（C09）。
  5. 延迟补偿：反 Park 使用 θ + 1.5·Δθ；Park 使用采样时刻角度。补偿量用标定系数可调。

第五部分：仿真与波形预期

  • 恒定 iq 给定，转速从 500 rpm 扫到 6000 rpm：未补偿时实测 id 偏离给定、力矩常数下降；补偿后基本平直。

#define SIN_LUT_BITS   (10u)                     /* 1024 点 */
#define SIN_FRAC_BITS  (16u - SIN_LUT_BITS)      /* 6 位插值 */
extern const q15_t c_SinLut[(1u << SIN_LUT_BITS) + 1u];  /* 离线生成，90° 处取 32767 */

static inline q15_t FOC_Sin(uint16_t th)
{
    uint32_t idx  = (uint32_t)th >> SIN_FRAC_BITS;
    int32_t  frac = (int32_t)(th & ((1u << SIN_FRAC_BITS) - 1u));
    int32_t  y0   = c_SinLut[idx];
    int32_t  y1   = c_SinLut[idx + 1u];
    return (q15_t)(y0 + (((y1 - y0) * frac) >> SIN_FRAC_BITS));
}
static inline q15_t FOC_Cos(uint16_t th) { return FOC_Sin((uint16_t)(th + 16384u)); }

/* 每 PWM 中断：机械角 → 电角 → 延迟补偿 */
void FOC_AngleUpdate_Isr(void)
{
    uint16_t thE  = (uint16_t)((uint16_t)(gFoc.thetaM * FOC_POLE_PAIRS) - Cal_ThetaOffset);
    int16_t  dTh  = (int16_t)(uint16_t)(thE - gFoc.thetaE);      /* 每 Ts 增量 */
    gFoc.thetaEIncPerTs = dTh;                                    /* 后续应用滤波 */
    gFoc.thetaE = thE;
    gFoc.sinTh  = FOC_Sin(thE);
    gFoc.cosTh  = FOC_Cos(thE);
    /* 反 Park 用补偿角：θ + Cal_AngCompK × Δθ，Cal_AngCompK 标称 1.5（Q8：384）【案例假设】 */
    gFoc.thetaEInvPark = (uint16_t)(thE + (uint16_t)(((int32_t)dTh * Cal_AngCompK_q8) >> 8));
}

第三部分：核心原理与公式

【理论公式】 复数 z = x + j·y = |z|·e^(jφ)；|z| = √(x²+y²)，φ = atan2(y, x) 欧拉公式：e^(jθ) = cosθ + j·sinθ 乘法：z1·z2 = |z1||z2|·e^(j(φ1+φ2)) ← 模相乘、角相加 → 乘 e^(jθ) 就是逆时针转 θ 空间矢量（幅值不变）：i_s = (2/3)(ia + a·ib + a²·ic) = iα + j·iβ，a = e^(j120°)，1 + a + a² = 0 Park：i_dq = id + j·iq = i_s · e^(−jθ) 反 Park：v_s = v_dq · e^(+jθ)
【理论公式】dq 电压方程的来源（SPMSM 先令 Ld = Lq = L） 静止坐标：v_s = R·i_s + dψ_s/dt，ψ_s = L·i_s + ψf·e^(jθ) 代入 i_s = i_dq·e^(jθ)，对乘积求导：d(i_dq·e^(jθ))/dt = (di_dq/dt + jω·i_dq)·e^(jθ) 两边约去 e^(jθ)：v_dq = R·i_dq + L·di_dq/dt + jω·L·i_dq + jω·ψf 展开为 IPMSM 形式（Ld ≠ Lq）： vd = R·id + Ld·did/dt − ω·Lq·iq vq = R·iq + Lq·diq/dt + ω·Ld·id + ω·ψf 来源：PMSM 矢量控制经典教材通用推导（如 R. Krishnan《Permanent Magnet Synchronous and Brushless DC Motor Drives》）
动画在演示什么：左图 αβ 平面中，电流矢量 i_s（橙）以电频率逆时针旋转；控制器使用的 dq 轴（紫 d̂ / 黄 q̂）按估计角 θ̂ 旋转，虚线是真实 d 轴。右图是 Park 输出 id、iq 的时间曲线。
拖动滑块：「角度偏差」使 dq 输出出现常值偏移（零位标定错误的典型）；「频率失配」使 dq 输出缓慢正弦摆动（速度估计不准）；勾选「Park 方向写反」，dq 变成 2 倍电频率振荡。
正常：id、iq 两条水平直线，数值 = I·cosγ、I·sinγ。异常：偏移、摆动、高频振荡分别对应三类根因。

第四部分：嵌入式实现步骤

  1. 复数用结构体 {re, im} 表示，Q15。
  2. 乘 e^(−jθ)：(re + j·im)(c − j·s) = (re·c + im·s) + j(im·c − re·s)，4 次乘、2 次加减。
  3. int32 累加，右移 15 位后饱和；输入矢量模长 ≤ 1 pu 时结果不会超限。
  4. Park 与反 Park 在同一中断里使用的角度可能不同（延迟补偿，A03），sin/cos 分别计算。

第五部分：仿真与波形预期

  • 正常稳态：id、iq 直流 + 小纹波（PWM 纹波、谐波）。
  • 纹波频率对应根因：1 倍 fe → 电流偏移；2 倍 fe → 两相增益不一致或 Park 写反；6 倍 fe → 死区 / 反电动势谐波。

typedef struct { q15_t re; q15_t im; } CPLX_tst;

/* z · e^(-jθ)：Park；|z| ≤ 1 pu 时结果不越界 */
static inline CPLX_tst Cplx_RotNeg(CPLX_tst z, q15_t s, q15_t c)
{
    CPLX_tst r;
    r.re = Q15_Sat(((int32_t)z.re * c + (int32_t)z.im * s) >> 15);
    r.im = Q15_Sat(((int32_t)z.im * c - (int32_t)z.re * s) >> 15);
    return r;
}
/* z · e^(+jθ)：反 Park */
static inline CPLX_tst Cplx_RotPos(CPLX_tst z, q15_t s, q15_t c)
{
    CPLX_tst r;
    r.re = Q15_Sat(((int32_t)z.re * c - (int32_t)z.im * s) >> 15);
    r.im = Q15_Sat(((int32_t)z.im * c + (int32_t)z.re * s) >> 15);
    return r;
}

{

}

第一部分：小节基础

链路位置由角度求速度、电感压降 L·di/dt、反电动势 dψ/dt、PID 的 D 项、低通滤波

第二部分：前置条件

  • 前置数学：A01 斜率（Δy/Δx）、A03 正弦。导数 = 时间间隔趋近 0 时的斜率。
  • 信号：旋变机械角度 thetaM；采样周期确定（定时中断）。
  • 不满足：测速噪声大 → 速度环电流给定噪声 → 力矩脉动、噪声；滤波过重 → 速度环相位滞后振荡。

第三部分：核心原理与公式

【理论公式】 导数：dx/dt = lim(Δt→0) [x(t) − x(t−Δt)] / Δt；d(sin ωt)/dt = ω·cos ωt 【离散实现】后向差分：x'[k] ≈ (x[k] − x[k−1]) / Ts · 等效延迟约 Ts/2（相当于在两个采样点中间求斜率） · 噪声放大：若采样噪声标准差 σ，差分噪声 ≈ √2·σ / Ts —— Ts 越小，噪声越大 一阶低通（后向欧拉离散）：y[k] = y[k−1] + α·(x[k] − y[k−1])，α = Ts / (τf + Ts)，fc = 1/(2π·τf) · α 越小越平滑，但延迟（相位滞后）越大 测速分辨率（12 位旋变，窗口 Tw）：Δn = 60 / (4096·Tw) rpm · Tw = 50 µs → 293 rpm/码；Tw = 1 ms → 14.6 rpm/码
动画在演示什么：上图：50 Hz 正弦被以 Ts 采样（点）并叠加噪声；下图：真实导数（灰，已除以 ω 归一化）、后向差分（红）与一阶低通后的差分（蓝）。
拖动滑块：减小 Ts 但保持噪声 → 红线噪声急剧变大（噪声 ∝ 1/Ts）；增大 Ts → 红线阶梯化、滞后；减小 α → 蓝线变平滑但明显滞后于灰线。
正常折中：蓝线贴近灰线、轻微滞后。异常：红线毛刺远大于信号（直接用差分做反馈会让速度环抖动）。

第四部分：嵌入式实现步骤

  1. 角度差分处理过零：(int16_t)(uint16_t)(θ[k] − θ[k−1])，只要一个窗口内转过不足半圈即正确。8000 rpm、1 ms 窗口机械转 48°，安全。
  2. 窗口选择：快速中断里只记录角度，1 ms 任务里做差分（窗口 = 1 ms）。
  3. 换算：rpm = Δθ / 65536 × 60 / Tw，Tw = 1 ms → rpm = Δθ × 60000 / 65536。
  4. 低通：系数 Cal_SpdLpfK_q15，int32 状态；结果用于速度环（C08）。
  5. 低速：分辨率不足时改用 M/T 法、角度 PLL 观测器或解码芯片速度通道（AD2S1210 具有速度输出，具体格式以 ADI 数据手册为准 【待核对】）。

第五部分：仿真与波形预期

  • 恒速 1000 rpm：原始差分以 ±1 码（±14.6 rpm）跳变，滤波后纹波明显减小。
  • 速度阶跃：滤波输出滞后于真实速度，延迟约 τf；若 τf 接近速度环带宽倒数，速度环超调增大。

A06 积分与累加：积分器、相位累加器、漂移与积分饱和

模块 A · 前置工程数学 · 第 6 节

第一部分：小节基础

链路位置PI 的 I 项、开环角度发生器 θ = ∫ω dt、电压模型磁链观测 ψ = ∫(v − R·i)dt、电量/热模型累加
输入 / 输出输入：每周期增量；输出：累加状态
工程价值积分消除稳态误差，也带来漂移、溢出与饱和三大风险
上下游依赖上游 A01、A05；下游 A07、A08、C05、C10、D06
适用角色全部角色
前置数学依赖A01、A05（积分是微分的逆运算）
① 为什么需要开环拖动需要由频率「积」出角度；PI 需要累积误差消除稳态偏差；无感观测从电压「积」出磁链。
② 量产怎么做int32/uint32 累加器；相位累加器利用溢出自动取模；积分器有上下限；纯积分用低通/泄漏替代。
③ 如何证明长时间运行（数小时）累加量不漂移、不溢出；开环频率实测 = 设定。

第二部分：前置条件

  • 前置数学：A01 累加、A05 差分。积分 = 曲线下面积 = Σ x[k]·Ts。
  • 信号：输入的偏置必须尽量小（A01 偏移校准）。
  • 不满足：磁链观测随时间漂移；积分饱和导致超调；开环角度运行越久越抖（浮点精度丢失）。

第三部分：核心原理与公式

【理论公式】y(t) = ∫₀ᵗ u(τ)dτ；∫ sin(ωt)dt = (1 − cos ωt)/ω（从 0 开始） 【离散实现】 前向矩形：y[k] = y[k−1] + Ts·u[k−1] 后向矩形：y[k] = y[k−1] + Ts·u[k] 梯形： y[k] = y[k−1] + Ts·(u[k] + u[k−1])/2 直流偏置的后果：u = 信号 + b → y 中多出 b·t，线性增长直到溢出 泄漏积分（低通替代）：y[k] = (1 − λ)·y[k−1] + Ts·u[k] ≈ 1/(s + λ/Ts)，偏置只造成有限误差 b·Ts/λ 相位累加器：acc[k] = acc[k−1] + inc（uint32 自然回绕），inc = fe·2³²·Ts，θe = acc >> 16 案例：10 Hz 电频率 → inc = 10 × 4294967296 × 50 µs ≈ 2147484
动画在演示什么：输入为正弦 + 小直流偏置（类比带偏移的反电动势电压）。蓝线是数字积分器输出，灰虚线是无偏置时的理想积分。
拖动滑块：偏置 > 0 时蓝线线性爬升（漂移）；开启「积分器限幅」后卡在上限（饱和）；增大泄漏系数 λ，漂移被抑制但积分结果幅值和相位出现误差（低通替代纯积分的代价）。
正常：偏置 0 时蓝灰重合。异常：持续爬升或长时间贴限幅。参数修改实时生效。

第四部分：嵌入式实现步骤

  1. 累加器位宽：状态至少 int32；增量远小于状态时，需更高的小数位（如 Q30），避免「增量 < 1 LSB 被截断」。
  2. 相位累加器：uint32，溢出即取模，无需判断；高 16 位作为 uint16 电角度。
  3. 限幅：积分器上下限与输出限幅匹配（A08 抗饱和）。
  4. 漂移抑制：纯积分观测器改为低通 / 泄漏积分 + 幅相补偿（C10）。

第五部分：仿真与波形预期

  • 开环 I/F 拖动：θe 为均匀锯齿，频率与设定一致；电流幅值稳定。
  • 纯积分磁链：有偏移时估计磁链轨迹圆心逐渐偏移；泄漏积分时圆心稳定。

第三部分：核心原理与公式

【理论公式】 RL 电路：v = R·i + L·di/dt →（零初值拉氏变换）V(s) = (R + L·s)·I(s) 传递函数：G(s) = I(s)/V(s) = 1/(L·s + R) = (1/R) / (τ·s + 1)，τ = L/R 阶跃响应：i(t) = (V/R)·(1 − e^(−t/τ))；t = τ 时 63.2%，t = 3τ 时 95%，5τ 时 99.3% 频率响应：|G(jω)| = 1/√(R² + (ωL)²)，∠G = −arctan(ωL/R)；转折频率 fc = R/(2πL) 闭环：T(s) = C(s)G(s) / (1 + C(s)G(s))；带宽 ≈ |T| 下降 3 dB 的频率 纯延迟 e^(−s·Td)：幅值不变，相位滞后 ω·Td（弧度） 案例：τd = 45 µH/12 mΩ = 3.75 ms，fc,d = 42.4 Hz；τq = 6.25 ms 【案例假设】 Td ≈ 1.5Ts = 75 µs → 1 kHz 处滞后 360°×1000×75e-6 = 27°

  4. 结果写入标定表 Cal_Ld_uH、Cal_Lq_uH、Cal_Rs_mOhm（C11 参数辨识细化）。

#define STEP_N   (400u)              /* 400 × 50 µs = 20 ms ≥ 5τ */
static q15_t s_idBuf[STEP_N];        /* PWM 中断中逐点写入 gFoc.id */

void Ident_Ld_Process(float vStep_V)
{
    float iInf = Q15ToAmp(average(&s_idBuf[STEP_N - 40u], 40u));   /* 取末尾均值作为终值 */

    uint16_t k = first_index_ge(s_idBuf, STEP_N, AmpToQ15(i632));

}

第三部分：核心原理与公式

【理论公式】 连续 PID：u(t) = Kp·e + Ki·∫e dt + Kd·de/dt 零极点对消设计（电流环，对象 1/(Ls+R)）： C(s) = Kp + Ki/s = Kp·(s + Ki/Kp)/s，令 Ki/Kp = R/L 开环 C·G = (Kp/L)/s → 闭环 T(s) = ωc/(s + ωc)，ωc = Kp/L ⇒ Kp = ωc·L，Ki = ωc·R 案例（ωc = 2π·1 kHz）【案例假设】： d 轴 Kp = 0.283 V/A，Ki = 75.4 V/(A·s)；q 轴 Kp = 0.471 V/A，Ki = 75.4 V/(A·s) 【离散实现】位置式（后向矩形积分）： I[k] = I[k−1] + Ki·Ts·e[k]，u[k] = sat(Kp·e[k] + I[k]) 增量式：Δu[k] = Kp·(e[k] − e[k−1]) + Ki·Ts·e[k]，u[k] = sat(u[k−1] + Δu[k]) 【定点实现】标幺：Kp_pu = Kp·I_BASE/V_BASE，KiTs_pu = Ki·Ts·I_BASE/V_BASE d：Kp_pu = 0.884 → Q12 = 3619；q：Kp_pu = 1.473 → Q12 = 6032（> 1，不能用 Q15） KiTs_pu = 75.4 × 50e-6 × 50/16 = 0.01178 → Q15 = 386 抗积分饱和：① 积分器限幅 ② 条件积分（输出饱和且误差同向时冻结）③ 反算法 I += Kb·(u_sat − u)

第四部分：嵌入式实现步骤

  1. 误差：e = ref − fb（Q15），注意 int32 计算防溢出。
  2. P 项：Kp_q12 × e >> 12 → Q15，int32。
  3. I 项：积分状态 int32 Q30，增量 KiTs_q15 × e（Q30），用 int64 求和再限幅。
  4. 输出限幅：限幅值来自电压圆（A02），每周期按实测 Vdc 更新。
  5. 抗饱和：输出饱和时只允许积分朝退饱和方向变化（条件积分）。
  6. 中断约束：PI 在 PWM 中断内执行；参数通过 XCP 修改时，Kp/Ki 写入需原子（int16 单次写入天然原子）。
  7. D 项：电流环一般不用（采样含 PWM 纹波，D 放大噪声且相位已够）；速度/位置环如需 D，必须带低通（C08）。

第五部分：仿真与波形预期

  • 设计值：iq 阶跃上升时间 ≈ 0.35/1 kHz = 0.35 ms，超调很小。
  • Kp 过大：高频振荡（延迟引起）；Ki 过大（Ti 远小于 τ）：低频超调。
  • 电压饱和：电流上升斜率受限（di/dt = (Vmax − R·i)/L），无抗饱和时退出饱和后超调。

typedef struct {
    int16_t kp_q12;        /* Kp 标幺，Q12（范围 ±8）       */
    int16_t kiTs_q15;      /* Ki·Ts 标幺，Q15              */
    int32_t integ_q30;     /* 积分状态，Q30                 */
    q15_t   outMax;        /* 输出上限（正数）              */
    q15_t   outMin;        /* 输出下限（负数）              */
} PI_tst;

q15_t PI_Run(PI_tst *pi, q15_t err)
{
    int32_t p    = ((int32_t)pi->kp_q12 * (int32_t)err) >> 12;            /* Q15 */
    int64_t iNew = (int64_t)pi->integ_q30 + ((int64_t)pi->kiTs_q15 * err);  /* Q30 */
    int64_t iMax = (int64_t)pi->outMax << 15;
    int64_t iMin = (int64_t)pi->outMin << 15;
    int32_t u;

    if (iNew > iMax) { iNew = iMax; }          /* ① 积分器自身限幅 */
    if (iNew < iMin) { iNew = iMin; }

    u = p + (int32_t)(iNew >> 15);

    if (u > pi->outMax) {                      /* ② 条件积分 */
        u = pi->outMax;
        if (err < 0) { pi->integ_q30 = (int32_t)iNew; }   /* 只允许退饱和方向 */
    } else if (u < pi->outMin) {
        u = pi->outMin;
        if (err > 0) { pi->integ_q30 = (int32_t)iNew; }
    } else {
        pi->integ_q30 = (int32_t)iNew;
    }
    return (q15_t)u;
}

第三部分：核心原理与公式

【理论公式】（幅值不变） Clarke： iα = (2/3)·(ia − ib/2 − ic/2) = ia（当 ia+ib+ic = 0） iβ = (2/3)·(√3/2)·(ib − ic) = (ia + 2·ib)/√3 Park： id = iα·cosθ + iβ·sinθ iq = −iα·sinθ + iβ·cosθ 反 Park：vα = vd·cosθ − vq·sinθ vβ = vd·sinθ + vq·cosθ 反 Clarke（SVPWM 的 min-max 实现会用到）： va = vα；vb = −vα/2 + (√3/2)·vβ；vc = −vα/2 − (√3/2)·vβ
动画在演示什么：同一组正弦三相电流在三个坐标系中的样子：左为三相时域波形，中为 αβ 平面矢量（轨迹为圆），右为 dq 输出（直流）。三个视图严格使用上面公式和全书方向约定。
拖动滑块：改变电流幅值和电流角 γ，dq 两条直线随之平移；「B 相增益误差」使 αβ 轨迹变成椭圆、dq 出现 2 倍频纹波；「A 相偏移」使圆心偏移、dq 出现 1 倍频纹波。
正常：圆 + 直线。异常：椭圆 / 偏心 / 纹波，对应 C01 采样问题。

第四部分：嵌入式实现步骤

  1. 顺序：采样换算 → Clarke → 读取 sin/cos → Park → 电流环 → 反 Park（补偿角）→ SVPWM。
  2. Clarke 定点：iBeta = (ia + 2·ib) × (1/√3)，1/√3 的 Q15 为 18919；中间量 int32。
  3. Park/反 Park 定点见 A04 Cplx_RotNeg / Cplx_RotPos。
  4. 每一步结果写入 gFoc 结构体，便于 XCP 测量（D08）。

第五部分：仿真与波形预期

  • 正常：iα 与 ia 重合；iβ 超前 iα 90°（正转）；dq 稳态直流。
  • 反转（θ 减小）：iβ 滞后 iα 90°，XY 圆顺时针，dq 仍为直流。
  • 不同异常对应纹波频率：1×fe 偏移、2×fe 增益 / 写反、6×fe 死区 / 谐波。

B04 矢量控制思想：把交流电机当成直流电机控制

模块 B · 基础扫盲 · 第 4 节

第一部分：小节基础

链路位置整体思想：dq 电流环即「励磁电流 + 电枢电流」两个独立控制通道
输入 / 输出输入：idRef（磁场通道）、iqRef（转矩通道）；输出：电磁转矩
工程价值理解为何 FOC 的力矩响应快、线性好，以及为何角度精度是一切的前提
上下游依赖上游 B02、B03；下游 C05、C06、C07
适用角色全部
前置数学依赖A02 投影、A04 复数
① 为什么需要直流电机靠换向器保证电枢磁场与主磁场始终正交，力矩 ∝ 电枢电流。PMSM 没有换向器，FOC 用「角度 + Park」做电子换向。
② 量产怎么做用旋变角度实时把电流矢量放在 q 轴附近（或 MTPA 角）；id 与 iq 各自一个 PI，并加解耦前馈消除交叉影响。
③ 如何证明恒 iq 下扫转速，力矩常数恒定；改变 iq 力矩线性变化（扭矩传感器）。

第二部分：前置条件

  • 准确的电角度（误差每 10° 电角度，SPMSM 力矩损失约 1.5%，且产生 d 轴分量）。
  • 电流环能够独立控制 id、iq（C05 解耦）。
  • 不满足：角度错 → 「电子换向」错位 → 力矩下降甚至反向（误差 > 90° 时）。

第三部分：核心原理与公式

【理论公式】 直流电机：Te = Kt·Ia（换向器保证 90°） PMSM（SPMSM）：Te = 1.5·p·ψf·|is|·sinβ，β 为电流矢量与 d 轴夹角 β = 90°（纯 q 轴）时转矩最大 → 对应直流电机的「正交」 角度误差 ε 时：实际 iq = |is|·cos ε，实际 id = −|is|·sin ε（符号取决于误差方向） ε = 10° → 力矩损失 1 − cos10° = 1.5%；ε = 90° → 力矩为 0；ε > 90° → 力矩反向
动画在演示什么：转子（磁链 ψf 方向即真实 d 轴，灰色）逆时针旋转；控制器按「控制器认为的角度」把电流矢量 is（橙）放在 q 轴上。柱条显示实际转矩占最大值的比例。
拖动滑块：「角度误差 ε」模拟零位标定错误：电流不再与磁链正交，转矩下降；ε 超过 90° 时转矩变负（电机反向 / 抱死）。「电流角 β」相当于主动给 id。
正常：ε = 0 时电流与 ψf 始终正交，转矩 100%。异常：转矩不足、反向。

第四部分：嵌入式实现步骤

  1. 给定生成：力矩模式下，iqRef 来自上层力矩需求；idRef 来自 MTPA（C06）或弱磁（C07）。
  2. 两个 PI 独立：d 轴 PI 输出 vd，q 轴 PI 输出 vq。
  3. 解耦前馈：vd += −ωe·Lq·iq，vq += ωe·(Ld·id + ψf)（C05）。
  4. 角度：采样时刻角度用于 Park，补偿后角度用于反 Park（A03）。

第五部分：仿真与波形预期

  • iq 阶跃，id 基本不动（解耦良好）；若 id 随 iq 阶跃产生明显扰动 → 解耦不足或角度误差。
  • 相电流幅值 ∝ 力矩需求，频率跟随转速。

B05 控制环层级：电流环（力矩环）→ 速度环 → 位置环

模块 B · 基础扫盲 · 第 5 节

第一部分：小节基础

链路位置串级控制结构：外环输出 = 内环给定
输入 / 输出位置环：θRef → ωRef；速度环：ωRef → iqRef；电流环：iRef → vdq
工程价值决定任务划分（20 kHz / 1 kHz / 更慢）和每个环的带宽上限
上下游依赖上游 A08；下游 C05、C08、D03
适用角色算法、软件架构
前置数学依赖A07 带宽、A08 PI
① 为什么需要外环看到的内环必须「足够快、近似为 1」，否则两个环相互作用产生振荡；带宽分离是串级设计的基本前提。
② 量产怎么做电流环 20 kHz 执行、带宽约 1 kHz；速度环 1 kHz 执行、带宽数十到一百多 Hz；位置环更低。EPS 主模式是力矩模式，速度 / 位置环用于台架和特殊功能。
③ 如何证明逐级阶跃：先验证电流环，再闭速度环，最后位置环；每级超调、上升时间、稳态误差分别达标。

第二部分：前置条件

  • 电流环已调好并验证（否则外环参数没有意义）。
  • 速度反馈质量足够（A05）：低速分辨率、滤波延迟。
  • 不满足：外环带宽接近内环 → 振荡；速度噪声大 → iq 给定抖。

第三部分：核心原理与公式

【理论公式】 带宽分离经验：f_外 ≤ f_内 / (5 ~ 10) 电流环闭环近似：Ti(s) ≈ 1/(s/ωci + 1) 机械方程：J·dωm/dt = Te − TL − B·ωm 速度环对象（电流环理想时）：G_ω(s) = Kt / (J·s + B) 速度 PI 常用对称最优 / 极点配置；工程上常按目标带宽 ωcs 取 Kp_s ≈ ωcs·J/Kt，再整定 Ki 【案例假设】电机侧折算转动惯量 J = 2×10⁻⁵ kg·m²（EPS 含减速机构后折算值会更大，按实测）
动画在演示什么：速度环 PI + 一阶电流环（带宽 f_i）+ 惯量对象的串级仿真（离散 1 ms 速度环），速度给定在 0.05 s 阶跃到 1000 rpm，0.25 s 加阶跃负载。
拖动滑块：减小电流环带宽或增大速度环带宽，使比值低于 5，可见超调与振荡增加；增大速度滤波时间常数也会降低相位裕度。
正常：比值 ≥ 10 时速度响应平滑、负载扰动后快速恢复。异常：持续振荡、iq 打到限幅。

第四部分：嵌入式实现步骤

  1. 任务分配：电流环在 PWM 中断（50 µs）；速度环在 1 ms 任务；位置环在 1 ms 或 5 ms 任务。
  2. 外环输出限幅：速度环输出 iqRef 限幅到电流极限；位置环输出速度限幅。
  3. 跨任务数据：1 ms 任务写 iqRef，中断读；int16 写入天然原子，结构体多字段需双缓冲或关中断拷贝（D03）。
  4. 抗饱和：速度环积分在 iqRef 饱和时冻结（A08 PI_Run 复用）。

第五部分：仿真与波形预期

  • 逐级验收：电流阶跃 → 速度阶跃 → 位置阶跃，每级都抓给定、反馈、控制量三条波形。
  • 速度环振荡频率接近电流环带宽 → 带宽分离不足；接近速度滤波截止频率 → 滤波相位滞后。

  • 不满足：软件触发 ADC → 采样时刻随中断延迟抖动 → 电流噪声大。

第三部分：核心原理与公式

【理论公式】 中心对齐 PWM：载波为三角波，周期 Ts = 1/fpwm（案例 50 µs） 低边电阻采样：在计数器顶点（三相下管都导通，零矢量 000 中段）采样 电感电流纹波在开关中点对称 → 中点采样 ≈ 周期平均值 【离散实现】单采样单更新时序： k·Ts 采样 → 中断计算（耗时 tc）→ 写影子寄存器 → (k+1)·Ts 加载生效 → 对电流影响中心约在 (k+1.5)·Ts ⇒ 总等效延迟 ≈ 1.5·Ts = 75 µs（A03 角度补偿、A07 相位裕度均基于此） 采样窗口约束（低边）：下管导通时间 ≥ ADC 采样保持时间 + 运放建立时间 + 死区 ⇒ 最大占空比受限，例如需 ≥ 3 µs 窗口则 Dmax ≈ 1 − 3/50 = 94% 【案例假设】
动画在演示什么：两个 PWM 周期的中心对齐载波（三角波）、A 相比较值、A 相上管 PWM、A 相电流纹波、ADC 采样点（红点）和中断执行条，以及新占空比生效时刻。
本动画约定：顶点采样、下一个顶点加载（单采样单更新）。拖动滑块：「采样点偏移」让采样离开中点，读到的电流偏离平均值（偏差随占空比变化 → 表现为电流畸变）；「占空比」增大到窗口不足时提示低边采样失效；「中断执行时间」超过一个周期时提示溢出。
正常：红点落在纹波中点，平均值误差 ≈ 0。异常：误差随占空比变化、采样窗口不足、中断超时。

第四部分：嵌入式实现步骤

  1. PWM：中心对齐、互补、死区（案例 1 µs 【案例假设】）、影子寄存器在计数器顶点加载（与采样同一时刻，中断有接近一个周期的预算，延迟 1.5Ts）。另一种做法是顶点采样、底点加载，可把延迟降到约 1Ts，但中断必须在半个周期内完成。
  2. ADC 触发：计数器顶点 + 固定延时（补偿驱动与运放延迟），两相同时采样（双 ADC 并行）或尽量紧邻。
  3. 中断：ADC 转换完成中断 = FOC 主中断，最高优先级（故障中断除外）。
  4. 执行时间监控：入口 / 出口翻转 GPIO 或读定时器计数，记录最大值 gDiag.isrMaxTicks。
  5. 占空比限幅：保证低边采样窗口，超过时进入「单相采样 + 重构」或限制调制比（C01、C04）。

第五部分：仿真与波形预期

  • 示波器：ADC 触发脉冲应稳定落在 PWM 中心，抖动 < 数十 ns。
  • 中断 GPIO 高电平宽度稳定，最大值有足够余量。
  • 相电流采样点落在开关噪声之外（离开边沿 ≥ 振铃衰减时间）。

第三部分：核心原理与公式

【理论公式】 采样链：I_phase × R_shunt × G_amp + V_bias → ADC 案例：±50 A ↔ 0~3.3 V；若 R = 0.5 mΩ，则需 G = 1.65 V / (50 A × 0.5 mΩ) = 66 【案例假设】 偏移平均：N 次独立采样的噪声标准差下降为 σ/√N（1024 次 → 下降 32 倍） 偏移误差的力矩影响：相电流直流偏置 b → dq 中幅值 b 的 1×fe 纹波 → 力矩纹波 ≈ Kt·b 增益差 ε：dq 中出现幅值约 ε·|I|/2 的 2×fe 纹波 【离散实现】运行中偏移跟踪（仅在 PWM 关闭或电流确知为 0 时）： off[k] = off[k−1] + λ·(adc[k] − off[k−1])，λ 很小（时间常数秒级） 采样电阻温漂：锰铜合金温度系数低（约数十 ppm/°C 量级 【待核对：以电阻规格书为准】），主要温漂来自运放偏置

  1. 上电偏移校准：PWM 关闭、运放供电稳定后等待 ≥ 数十 ms（以硬件设计为准）→ 1024 次平均 → 范围检查（A01 代码）。
  2. 产线增益标定：直流注入（A 进 B 出），精密分流器 / 功率分析仪测实际电流，两点法求增益修正，写 NVM，上电加载到 Cal_。
  3. 中断换算：int32 中间量、增益修正、饱和（A01 FOC_AdcToIq15）。
  4. 诊断：ADC 码值接近 0 / 4095（饱和）、偏移超范围、ia+ib+ic 合理性（三电阻时）、运行中 PWM 关闭期间电流应为 0。
  5. 噪声抑制：优先硬件（布局、差分走线、RC），软件不建议对电流环反馈再加大低通（引入相位滞后）；必要时用很短的滤波或过采样平均。

  • 静止：ia、ib 平均 ≈ 0，峰峰噪声若干码。
  • 恒速恒力矩：iq 频谱中 1×fe、2×fe 分量很低；若出现，按 A01/B03 定位。
  • 示波器：ADC 触发脉冲落在低边导通窗口中部、远离开关沿振铃。

static int32_t s_offA_q12, s_offB_q12;   /* 偏移 × 4096；上电校准完成后初始化为 Cal_IxOffset_cnt << 12 */

void FOC_OffsetTrack_Isr(void)
{
    if (gFoc.pwmEnabled == 0u) {
        int32_t xA = (int32_t)gFoc.adcIa << OFFS_TRACK_SHIFT;
        int32_t xB = (int32_t)gFoc.adcIb << OFFS_TRACK_SHIFT;
        s_offA_q12 += (xA - s_offA_q12) >> OFFS_TRACK_SHIFT;     /* 一阶低通 */
        s_offB_q12 += (xB - s_offB_q12) >> OFFS_TRACK_SHIFT;
        Cal_IaOffset_cnt = (int16_t)(s_offA_q12 >> OFFS_TRACK_SHIFT);
        Cal_IbOffset_cnt = (int16_t)(s_offB_q12 >> OFFS_TRACK_SHIFT);
    }
}

/* ADC 饱和诊断：码值连续 N 次接近满量程 → 采样超量程 */
void FOC_IsenseSatDiag_Isr(void)
{
    static uint8_t s_cnt;
    uint8_t sat = (gFoc.adcIa < 16u) || (gFoc.adcIa > 4079u) ||
                  (gFoc.adcIb < 16u) || (gFoc.adcIb > 4079u);
    s_cnt = sat ? (uint8_t)(s_cnt + 1u) : 0u;
    if (s_cnt >= 3u) { Diag_SetFault(DIAG_ISENSE_SAT); }
}

C02 Clarke 变换：三相合成空间矢量

模块 C · 核心 FOC 链路 · 第 2 节

第一部分：小节基础

链路位置采样之后：ia、ib → iα、iβ
输入 / 输出输入：gFoc.ia、ib；输出：gFoc.iAlpha、iBeta
工程价值把三相（实际两个独立量）变成正交两轴，为 Park 做准备
上下游依赖上游 C01；下游 C03
适用角色算法、底层
前置数学依赖A02 合成与投影、A04 空间矢量 a = e^(j120°)
① 为什么需要三相绕组空间上互差 120°，三个电流的磁势叠加就是一个空间矢量；Clarke 求出它在正交 αβ 轴上的坐标。
② 量产怎么做两相输入、一次乘法（1/√3）、int32 中间量、饱和；第三相不参与计算（隐含 ic = −ia − ib）。
③ 如何证明iα 与 ia 重合；XY 轨迹为圆，半径 = 相电流峰值（幅值不变约定）。

第二部分：前置条件

  • C01 校准完成；全书约定：α 轴与 A 相轴线重合，幅值不变系数 2/3。
  • 不满足：系数约定混用 → 电流、转矩、PI 参数整体差一个比例。

第三部分：核心原理与公式

【理论公式】 空间矢量：i_s = K·(ia + a·ib + a²·ic)，a = e^(j120°) 幅值不变：K = 2/3 → |i_s| = 相电流峰值（本教程） 功率不变：K = √(2/3) → |i_s| = √(3/2)·峰值，转矩公式系数变为 p·(…) 展开（K = 2/3）： iα = (2/3)·[ia − (ib + ic)/2] iβ = (2/3)·(√3/2)·(ib − ic) = (ib − ic)/√3 代入 ia + ib + ic = 0：iα = ia，iβ = (ia + 2·ib)/√3 【定点实现】1/√3 → Q15 18919；ia + 2·ib 最大约 ±3 pu，先 int32 再乘，乘积 ±3×32768×18919 ≈ ±1.86×10⁹ < 2³¹，不溢出
动画在演示什么：三个相轴（A 0°、B 120°、C 240°）上，各相电流产生的分矢量 ia·e^(j0)、ib·e^(j120°)、ic·e^(j240°)（细箭头），首尾相接合成后乘 2/3 得到 i_s（粗橙箭头），其 α、β 投影即 Clarke 输出。
拖动滑块：「电流角」旋转合成矢量；「C 相断线」模拟 C 相电流为 0（星接时 ia、ib 也会改变，这里演示「采样以为平衡但实际不平衡」时合成矢量的畸变）；「系数」切换 2/3 与 √(2/3)，观察 |i_s| 变化。
正常：2/3 系数下 |i_s| 恒等于相电流峰值。

第四部分：嵌入式实现步骤

  1. 读取 ia、ib（Q15）。
  2. iAlpha = ia。
  3. iBeta = sat(((ia + 2·ib) × 18919) >> 15)，int32 运算。
  4. 可选：三电阻采样时用三相 iα = (2ia − ib − ic)/3，降低单相误差影响。
  5. 执行时间：几个指令周期，无需优化。

第五部分：仿真与波形预期

  • iα 与 ia 波形完全重合；iβ 与 iα 正交、同幅值。
  • XY：圆；椭圆 → 增益；偏心 → 偏移；尖角 / 平顶 → 采样饱和或死区。

C03 Park 变换与反 Park：同步旋转坐标与延迟补偿

模块 C · 核心 FOC 链路 · 第 3 节（数学证明见 A03、A04）

第一部分：小节基础

链路位置Park：Clarke 之后、电流环之前；反 Park：电流环之后、SVPWM 之前
输入 / 输出Park：iα、iβ、θe → id、iq；反 Park：vd、vq、θe,comp → vα、vβ

适用角色算法

① 为什么需要让 PI 面对直流量；同时反 Park 把电流环输出的 dq 电压送回静止坐标供 SVPWM 使用。

第二部分：前置条件

  • 准确的电角度、正确的旋转方向（C09）；电角速度估计（用于补偿）。

  1. 角度更新（A03 FOC_AngleUpdate_Isr）：θe、sin、cos、Δθ。

C04 SVPWM：扇区判断、时间计算、零矢量分配、过调制与死区效应

模块 C · 核心 FOC 链路 · 第 4 节

第一部分：小节基础

链路位置反 Park 之后、PWM 寄存器之前
输入 / 输出输入：vα、vβ、Vdc；输出：三相占空比 dutyA/B/C（Q15）→ 比较寄存器
工程价值母线电压利用率比 SPWM 高约 15.5%；12 V 系统中直接决定弱磁起点与最高转速
上下游依赖上游 C03；下游 PWM 硬件、C13 死区补偿、B06 采样窗口
适用角色算法、底层
前置数学依赖A02 矢量合成、A03 三角
① 为什么需要逆变器只有 8 个开关状态（6 个有效矢量 + 2 个零矢量），任意方向、幅值的电压矢量要用相邻两个有效矢量 + 零矢量在一个周期内按时间加权合成。
② 量产怎么做两种等价实现：扇区法（教科书）或 min-max 零序注入法（代码短、无扇区判断，量产常用）；七段式对称、中心对齐。
③ 如何证明三相占空比呈「马鞍波」；线电压基波幅值与给定一致；线性区内 |v| ≤ Vdc/√3 时无削顶。

第二部分：前置条件

  • 实测 Vdc（每周期更新）；中心对齐 PWM；死区配置（C13 补偿）。
  • 不满足：Vdc 用常量 → 电源波动时电压幅值误差；电压超出六边形 → 过调制未定义行为。

第三部分：核心原理与公式

【理论公式】（幅值不变约定） 6 个有效基本矢量幅值 2Vdc/3，相邻 60°；构成六边形，内切圆半径 = Vdc/√3 扇区判断：U1 = vβ，U2 = (√3·vα − vβ)/2，U3 = (−√3·vα − vβ)/2 N = (U1>0) + 2·(U2>0) + 4·(U3>0)；N → 扇区：3→Ⅰ，1→Ⅱ，5→Ⅲ，4→Ⅳ，6→Ⅴ，2→Ⅵ 扇区内作用时间（θ' 为扇区内角度，0~60°）： T1 = √3·Ts·|v|/Vdc·sin(60° − θ')，T2 = √3·Ts·|v|/Vdc·sin θ'，T0 = Ts − T1 − T2 【离散实现】min-max 零序注入（与七段式对称 SVPWM 等价）： va,vb,vc = 反 Clarke(vα, vβ) v0 = −(max + min)/2 dutyX = 0.5 + (vX + v0)/Vdc 线性区：|v| ≤ Vdc/√3 时所有 duty ∈ [0, 1]；SPWM 仅 Vdc/2，提升 2/√3 ≈ 1.155 过调制（来源：Holtz、Bolognani 等经典文献中的两区间法；量产常简化）： 以六步方波基波 2Vdc/π 为基准定义调制度 M = |v|/(2Vdc/π)： 线性区：M ≤ π/(2√3) ≈ 0.907（即 |v| ≤ Vdc/√3） 区间Ⅰ：0.907 < M ≤ 0.952，保持参考角度，超出六边形的部分截到边界（并补偿幅值损失） 区间Ⅱ：0.952 < M ≤ 1，逐步在顶点保持，M = 1 即六步运行 简化做法：直接把矢量按比例缩到六边形边界（最小相位误差法），谐波增加但实现简单
动画在演示什么：左图为电压六边形与 6 个扇区，参考电压矢量逆时针旋转，当前扇区高亮，显示相邻两矢量的分量 T1、T2；右图为一个电周期内三相占空比（min-max 实现，马鞍形）以及当前点。
拖动滑块：调制幅值 |v|/(Vdc/√3) 超过 1 进入过调制：勾选「六边形截断」时矢量被截到边界（右图出现平顶），不勾选时占空比超出 [0,1]（红色，表示实际会被硬件削顶）。
正常：线性区内马鞍波、duty ∈ [0,1]。异常：超出范围、扇区跳变异常。

第四部分：嵌入式实现步骤

  1. 反 Clarke 得 va、vb、vc（Q15）。
  2. 求 max、min，v0 = −(max+min)/2。
  3. duty = 0.5 + (vx + v0) × (1/vdcPu)：除法用每周期一次的 1/Vdc 倒数（慢任务或每周期算一次），中断内只乘。
  4. 过调制处理：若 max − min > vdcPu（超出六边形），按比例缩放 (vx + v0)。
  5. duty 限幅到 [Dmin, Dmax]（保证 B06 低边采样窗口与驱动自举）。
  6. 转换为比较值：CMP = duty × PWM 周期计数（中心对齐时注意极性约定）。

第五部分：仿真与波形预期

  • 相电压（对 Vdc 负端）PWM 平均值为马鞍形；线电压平均值为正弦。
  • 过调制区：马鞍波平顶，相电流出现 5、7 次谐波。
  • 扇区编号随角度依次 Ⅰ→Ⅵ（正转），反转相反。

#define Q15_SQRT3_2   (28378)                 /* √3/2 */
#define DUTY_MAX_Q15  (30801)                 /* 94%：低边采样窗口 【案例假设】 */
#define DUTY_MIN_Q15  (983)                   /* 3% */

static inline int16_t max3(int16_t a, int16_t b, int16_t c) { int16_t m = (a > b) ? a : b; return (m > c) ? m : c; }
static inline int16_t min3(int16_t a, int16_t b, int16_t c) { int16_t m = (a < b) ? a : b; return (m < c) ? m : c; }

void FOC_Svpwm_Isr(void)
{
    int32_t va = gFoc.vAlpha;
    int32_t vb = (-(int32_t)gFoc.vAlpha + 2 * (((int32_t)gFoc.vBeta * Q15_SQRT3_2) >> 15)) / 2;
    int32_t vc = -va - vb;
    int32_t v0 = -((max3((int16_t)va, (int16_t)vb, (int16_t)vc) + min3((int16_t)va, (int16_t)vb, (int16_t)vc)) / 2);
    int32_t span = max3((int16_t)va, (int16_t)vb, (int16_t)vc) - min3((int16_t)va, (int16_t)vb, (int16_t)vc);
    int32_t k_q15 = 32767;                                  /* 过调制缩放系数 */
    if (span > gFoc.vdcPu) {                                /* 超出六边形 → 最小相位误差截断 */
        k_q15 = ((int32_t)gFoc.vdcPu << 15) / span;
    }
    /* duty = 0.5 + k·(vx + v0)/Vdc；invVdc_q12 = 1/vdcPu（Q12，慢任务更新）*/
    gFoc.dutyA = FOC_DutyCalc(va + v0, k_q15);
    gFoc.dutyB = FOC_DutyCalc(vb + v0, k_q15);
    gFoc.dutyC = FOC_DutyCalc(vc + v0, k_q15);
    Pwm_WriteDuty(gFoc.dutyA, gFoc.dutyB, gFoc.dutyC);      /* 写影子寄存器 */
}

static q15_t FOC_DutyCalc(int32_t vx, int32_t k_q15)
{
    int32_t x = (vx * k_q15) >> 15;
    int32_t d = 16384 + ((x * gFoc.invVdc_q12) >> 12);     /* 0.5 + x/Vdc */
    if (d > DUTY_MAX_Q15) { d = DUTY_MAX_Q15; }
    if (d < DUTY_MIN_Q15) { d = DUTY_MIN_Q15; }
    return (q15_t)d;
}

代码中 vb 按 (−vα + 2·(√3/2)·vβ)/2 = −vα/2 + (√3/2)·vβ 计算；量产代码以单元测试覆盖 6 个扇区中心与边界点为准。FOC_DutyCalc 应在 FOC_Svpwm_Isr 之前声明（此处为阅读顺序）。

C05 电流环：解耦前馈、交叉耦合、积分饱和与定点实现

模块 C · 核心 FOC 链路 · 第 5 节（PI 基础见 A08）

第一部分：小节基础

链路位置Park 之后、反 Park 之前；FOC 的「力矩环」
输入 / 输出输入：idRef、iqRef、id、iq、ωe、Vdc；输出：vd、vq（已限幅）
工程价值力矩带宽、力矩脉动、低压 / 高速稳定性的直接决定者
上下游依赖上游 C03、C06、C07；下游 C03 反 Park、C04
适用角色算法、标定
前置数学依赖A04 dq 方程、A07 传递函数、A08 PI 与抗饱和
① 为什么需要dq 电压方程中存在 −ωLq·iq、+ωLd·id、+ωψf 三项与转速相关的耦合 / 扰动；不前馈时 PI 只能靠误差去「追」，高速时动态严重恶化。
② 量产怎么做PI（零极点对消参数）+ 解耦与反电动势前馈 + d 轴优先电压圆限幅 + 条件积分抗饱和 + 模式切换时积分器预置。
③ 如何证明不同转速下 iq 阶跃：响应一致、id 扰动小；低压阶跃无大超调；扫频得闭环带宽 ≈ 1 kHz。

第二部分：前置条件

  • 参数：Rs、Ld、Lq、ψf（C11）；Cal_IdKp_q12 等（A08）。
  • 信号：滤波后电角速度标幺 gFoc.wePu_q15（基值 ωe@8000 rpm = 3351 rad/s）；Vdc。
  • 不满足：参数偏差 > 30% 时前馈反而引入误差；ωe 噪声大时前馈把噪声注入电压。

第三部分：核心原理与公式

【理论公式】 vd = Rs·id + Ld·did/dt − ωe·Lq·iq vq = Rs·iq + Lq·diq/dt + ωe·Ld·id + ωe·ψf 前馈解耦（用估计参数）：vd_ff = −ωe·L̂q·iq，vq_ff = ωe·(L̂d·id + ψ̂f) vd = PI_d(idRef − id) + vd_ff，vq = PI_q(iqRef − iq) + vq_ff 参数准确时两轴变为独立的 1/(Ls + R)，PI 按 A08 零极点对消 另一种流派：复矢量 PI（在 dq 复数域设计，对高速 / 低开关频率比更鲁棒），常见于主驱高速应用 【待核对：具体实现依文献与项目】 【定点实现】标幺前馈系数（基值：ωb = 3351 rad/s，I_BASE 50 A，V_BASE 16 V）【案例假设】 kLq = ωb·Lq·Ib/Vb = 0.785 → Q15 25734；kLd = 0.471 → 15441；kψ = ωb·ψf/Vb = 0.733 → 24020 vd_ff_pu = −ωe_pu·kLq·iq_pu；vq_ff_pu = ωe_pu·(kLd·id_pu + kψ) 抗饱和：PI 的输出限幅 = 电压圆限幅值 − 前馈量（PI 知道自己还剩多少电压）
动画在演示什么：dq 两轴耦合的离散电流环（案例参数、Ts = 50 µs、1 拍延迟），给 iq 阶跃 0 → 20 A，观察 id 被交叉耦合「拖动」的程度。上图 iq / id，下图 vd、vq。
拖动滑块：提高转速，未解耦时 id 出现大扰动、iq 响应变慢；勾选「解耦前馈」后两轴近似独立。「参数误差」模拟 L̂ 与真实值偏差，前馈效果随之下降。
正常：解耦后 id 扰动 < 1 A。异常：高速时 id 大幅偏离 0。转速升到约 4000 rpm 以上时稳态所需电压超过 6.6 V，动画会提示电压饱和——这正是 C07 弱磁要解决的问题。

第四部分：嵌入式实现步骤

  1. 误差：ed = idRef − id，eq = iqRef − iq（int32 → 饱和 Q15）。
  2. 前馈：由 wePu、id、iq 计算 vdFf、vqFf（Q15 乘法）。
  3. 电压上限：vMax = Cal_VmaxK × vdcPu / √3（每周期）。
  4. d 轴：PI 限幅 [−vMax − vdFf, vMax − vdFf]，vd = PI + vdFf。
  5. q 轴：vqMax = √(vMax² − vd²)，PI 限幅 [−vqMax − vqFf, vqMax − vqFf]，vq = PI + vqFf。
  6. 积分器预置：开环→闭环或无感切入时，integ = (v_当前 − ff) << 15，保证输出连续。
  7. 故障关管时积分器清零（A08 风险红线）。

第五部分：仿真与波形预期

  • 低速：前馈影响小；高速：解耦显著改善 id 扰动与 iq 上升时间。
  • 电压饱和：vq 贴限幅，iq 跟不上 → 应触发弱磁（C07），而不是继续增大 PI。
  • 扫频：小信号注入 iqRef，闭环幅频 −3 dB 点约 1 kHz，相位裕度 ≥ 45°。

volatile q15_t Cal_KLq_q15  = 25734;   /* ωb·Lq·Ib/Vb 【案例假设】 */
volatile q15_t Cal_KLd_q15  = 15441;
volatile q15_t Cal_KPsi_q15 = 24020;
volatile q15_t Cal_VmaxK_q15 = 31130;  /* 0.95 电压裕量 */
volatile uint8_t Cal_DecoupleEn = 1u;

static PI_tst s_piD, s_piQ;

void FOC_CurrentLoop_Isr(void)
{
    q15_t ed = Q15_Sat((int32_t)gFoc.idRef - gFoc.id);
    q15_t eq = Q15_Sat((int32_t)gFoc.iqRef - gFoc.iq);
    q15_t vdFf = 0, vqFf = 0;
    q15_t vMax = Q15_Mul(Q15_Mul(gFoc.vdcPu, Q15_INV_SQRT3), Cal_VmaxK_q15);
    int32_t vqMax;

    if (Cal_DecoupleEn != 0u) {
        vdFf = Q15_Sat(-(int32_t)Q15_Mul(gFoc.wePu_q15, Q15_Mul(Cal_KLq_q15, gFoc.iq)));
        vqFf = Q15_Mul(gFoc.wePu_q15, Q15_Sat((int32_t)Q15_Mul(Cal_KLd_q15, gFoc.id) + Cal_KPsi_q15));
    }
    /* d 轴优先 */
    s_piD.kp_q12 = Cal_IdKp_q12;  s_piD.kiTs_q15 = Cal_IdKiTs_q15;
    s_piD.outMax = Q15_Sat((int32_t)vMax - vdFf);
    s_piD.outMin = Q15_Sat(-(int32_t)vMax - vdFf);
    gFoc.vd = Q15_Sat((int32_t)PI_Run(&s_piD, ed) + vdFf);
    /* q 轴使用剩余电压 */
    vqMax = Q15_SqrtQ30(((int32_t)vMax * vMax) - ((int32_t)gFoc.vd * gFoc.vd));
    s_piQ.kp_q12 = Cal_IqKp_q12;  s_piQ.kiTs_q15 = Cal_IqKiTs_q15;
    s_piQ.outMax = Q15_Sat(vqMax - vqFf);
    s_piQ.outMin = Q15_Sat(-vqMax - vqFf);
    gFoc.vq = Q15_Sat((int32_t)PI_Run(&s_piQ, eq) + vqFf);
    gFoc.vSat = (uint8_t)((gFoc.vq >= vqMax) || (gFoc.vq <= -vqMax));   /* 给弱磁使用 */
}

/* 开环 → 闭环切换：积分器预置，保证电压连续 */
void FOC_CurrentLoop_Preset(q15_t vdNow, q15_t vqNow, q15_t vdFf, q15_t vqFf)
{
    s_piD.integ_q30 = ((int32_t)vdNow - vdFf) << 15;
    s_piQ.integ_q30 = ((int32_t)vqNow - vqFf) << 15;
}

PI_Run 中积分器限幅使用 outMax/outMin（A08），因此这里传入的动态限幅同时完成了「抗饱和 + 电压圆」。预置时忽略了 P 项（切换瞬间误差应很小），如误差较大可同时扣除 Kp·e。

① 为什么需要IPMSM 有磁阻转矩，id = 0 不是最优；同样转矩下 MTPA 电流更小，热和保护裕量更好。
② 量产怎么做台架实测「同电流扫电流角」找最大力矩点，生成 MTPA 表（考虑 Ld/Lq 饱和），按温度插值；公式法作为初值。
③ 如何证明扭矩传感器验证：同力矩下实测电流 ≤ id = 0 方案；表中每点为电流角扫描的峰值。

第二部分：前置条件

  • 准确零位（零位误差会让「最大力矩角」测量整体偏移）。
  • 扭矩传感器台架；Ld、Lq 随电流的实测数据（C11）。
  • 不满足：用常数电感的公式表 → 大电流时偏离真正 MTPA。

第三部分：核心原理与公式

【理论公式】（来源：IPMSM MTPA 经典推导，对 Te 关于电流角求极值） Te = 1.5·p·[ψf·iq + (Ld − Lq)·id·iq]，|is|² = id² + iq² 以 |is| 表示：id = [−ψf + √(ψf² + 8(Ld−Lq)²·|is|²)] / [4(Ld − Lq)] 以 iq 表示（量产以 iq 为索引时）：id = ψf/(2ΔL) − √(ψf²/(4ΔL²) + iq²)，ΔL = Lq − Ld 案例 【案例假设，常数电感】ψf/(2ΔL) = 58.33 A： iq = 10 / 20 / 30 / 40 / 50 / 60 A → id = −0.85 / −3.33 / −7.26 / −12.4 / −18.5 / −25.4 A SPMSM：ΔL = 0 → id = 0（MTPA 退化为 id = 0 控制） 三类实现： ① 公式法：在线计算，依赖参数准确，饱和时偏差大 ② 查表法（量产主流）：台架标定 2D 表（Te 或 iq，Vdc / 温度）→ (id, iq) ③ 在线寻优：信号注入 / 扰动观察找 dTe/dβ = 0，抗参数变化，但实现与验证复杂 【待核对：各厂商在线 MTPA 多为私有方案】
动画在演示什么：dq 电流平面：灰色同心圆为等电流圆，彩色曲线为等转矩曲线（IPMSM 为双曲线族），绿色为 MTPA 轨迹（等转矩线与电流圆的切点连线）。黄色点为当前工作点。
拖动滑块：改变转矩需求，工作点沿 MTPA 轨迹移动；改变 Lq/Ld，凸极比为 1 时轨迹退化为 q 轴；「用 id = 0」对比同转矩所需电流。
正常：MTPA 点电流最小。注意：为常数电感模型（L0 证据），实测 MTPA 以台架电流角扫描为准。

第四部分：嵌入式实现步骤

  1. 表结构：以 |iqRef|（0~60 A，步长 5 A）为索引的 idRef 一维表；高精度项目用 Te × 温度二维表。
  2. 查表：线性插值（1 ms 任务）；iqRef 为负（反向力矩）时 id 同为负（对称）。
  3. 温度修正：多张表按磁钢温度插值，或乘温度系数。
  4. 与弱磁衔接：idRef = min(idMTPA, idFW)（取更负者，C07）。
  5. 电流圆限幅：|is| ≤ Imax，id 优先保证（C07）。

第五部分：仿真与波形预期

  • 台架电流角扫描：固定 |is|，β 从 90° 扫到 130°，力矩曲线在峰值附近平坦——这意味着 MTPA 角误差几度对力矩影响很小，但对电流有效值仍有收益。
  • MTPA 下 id 随负载增加而变得更负，相电流相位领先反电动势。

/* MTPA 表：索引 |iq| = 0,5,...,60 A；值为 idRef（Q15）。公式初值，需台架覆盖 【案例假设】*/
#define MTPA_N   (13u)
volatile q15_t Cal_MtpaId_q15[MTPA_N] = {
   0, -140, -558, -1244, -2185, -3363, -4759,
   -6353, -8124, -10053, -12122, -14313, -16613
};

q15_t FOC_MtpaIdRef(q15_t iqRef)
{
    const int32_t step = 3277;                      /* 5 A = 5/50 × 32768 */
    int32_t a   = (iqRef < 0) ? -(int32_t)iqRef : (int32_t)iqRef;
    int32_t idx = a / step;
    int32_t frac_q15;
    if (idx >= (int32_t)(MTPA_N - 1u)) { return Cal_MtpaId_q15[MTPA_N - 1u]; }
    frac_q15 = ((a - idx * step) * 32768) / step;   /* 0..32767 */
    return (q15_t)(Cal_MtpaId_q15[idx] +
           (((int32_t)(Cal_MtpaId_q15[idx + 1] - Cal_MtpaId_q15[idx]) * frac_q15) >> 15));
}

节点值由第三部分公式按 iq = 0、5…60 A 计算得出（Q15，基值 50 A）。注意：用 iq 作索引时，加入 id 后实际力矩比 Kt·iq 略大，严格的力矩闭环应使用 Te → (id, iq) 表；EPS 上层通常有力矩闭环 / 标定补偿。

C07 弱磁控制：电压极限椭圆、电流极限圆、负 d 轴去磁与切换逻辑

模块 C · 核心 FOC 链路 · 第 7 节

第一部分：小节基础

链路位置给定生成：MTPA 之后修正 idRef，并约束 iqRef
输入 / 输出输入：电压利用率（|v| / vMax 或 vSat 标志）、ωe、Vdc；输出：idRef 修正量、iqRef 上限
工程价值12 V 系统中，案例电机满电流 MTPA 时基速仅约 3200 rpm，8000 rpm 必须依赖弱磁
上下游依赖上游 C05（电压饱和信息）、C06；下游 C05 给定
适用角色算法、标定
前置数学依赖A02 圆 / 椭圆、A08 PI、B02 反电动势
① 为什么需要反电动势 ∝ 转速；超过可用电压后电流无法再注入，力矩崩溃。负 id 产生与永磁体反向的磁链，降低定子磁链幅值，换取转速。
② 量产怎么做电压闭环弱磁（PI 调节 Δid，使电压利用率保持在 ~95%）为主，叠加前馈查表加快响应；iq 按电流圆与电压椭圆同时限幅。
③ 如何证明扫转速到最高转速：电压利用率稳定在目标值、无振荡；转矩–转速外特性曲线达标；急加速 / 电压跌落时不失控。

第二部分：前置条件

  • 电流环有动态电压限幅与 vSat 标志（C05）；Vdc 实时值。
  • 准确的 Ld、ψf（前馈表）；电流极限 Cal_IsMax（案例 60 A 峰值 【案例假设】）。
  • 不满足：没有弱磁 → 基速以上力矩迅速下降、电流畸变；弱磁过深 → 效率低、可能退磁风险。

第三部分：核心原理与公式

【理论公式】（稳态，忽略 Rs 压降） 电压极限：vd² + vq² ≤ Vmax²，vd ≈ −ωe·Lq·iq，vq ≈ ωe·(Ld·id + ψf) ⇒ (Ld·id + ψf)² + (Lq·iq)² ≤ (Vmax/ωe)² —— 椭圆，中心 (−ψf/Ld, 0)，随转速收缩 电流极限：id² + iq² ≤ Imax² —— 圆 特征电流：Ich = ψf/Ld；若 Ich ≤ Imax，理论上可无限升速（椭圆中心在圆内） 案例 【案例假设】Vmax = 0.95 × 12/√3 = 6.58 V，Ich = 77.8 A > Imax = 60 A（最高转速有限，空载理论值约 1.96 万 rpm） 60 A MTPA 基速 ≈ 3230 rpm；35 A MTPA 基速 ≈ 3930 rpm（未计 Rs 压降） 各转速满电流最大力矩：3000 rpm 1.39 N·m，5000 rpm 1.10 N·m，8000 rpm 0.70 N·m（id ≈ −55.6 A，iq ≈ 22.6 A） 【离散实现】电压闭环弱磁（常见量产流派）： e_v = Vtarget − |v|（或 e_v = Vtarget − |vq_unsat|） Δid = PI_fw(e_v)，限幅 [Δid_min, 0]（只允许去磁方向） idRef = min(idMTPA, idMTPA + Δid)；iqRef 限幅 √(Imax² − idRef²) 另一流派：查表 / 公式前馈（idFW = (Vmax/ωe − ψf)/Ld 等），响应快但依赖参数；常与电压环结合
动画在演示什么：dq 电流平面上的电流极限圆（灰）与电压极限椭圆（蓝，随转速缩小），绿色为可行区域，橙点为在可行区内力矩最大的工作点，绿色虚线为 MTPA 轨迹。
拖动滑块：转速升高 → 椭圆收缩，工作点被迫离开 MTPA 线沿圆向左（负 id）移动，力矩下降；降低 Vdc（如 9 V 冷启动）椭圆更小；增大 Imax 改变可行区。
正常：基速以下工作点在 MTPA 上，基速以上沿圆 / 椭圆交点移动。异常：可行区为空（无法维持该转速）。

第四部分：嵌入式实现步骤

  1. 电压利用率：|v| = √(vd² + vq²)（来自 C05），目标 Vtarget = Cal_FwVoltK × vMax（如 0.95）。
  2. 弱磁 PI（1 ms 或更快，建议 1~2 kHz）：输出 Δid ≤ 0，积分器上下限 [−Imax, 0]。
  3. idRef = min(idMTPA, idMTPA + Δid)；再限 idRef ≥ −Cal_IdMinFw（防止过深退磁，按电机允许值）。
  4. iqRef 限幅：√(Imax² − idRef²)（电流圆）；可再加电压椭圆限幅（前馈表）。
  5. 弱磁 PI 带宽远低于电流环（如 50~100 Hz），避免两环相互作用。
  6. 转速下降时 Δid 自然回到 0（误差变正，积分退回）；加上回退速率限制。

第五部分：仿真与波形预期

  • 扫转速：基速以下 Δid = 0；基速以上 Δid 逐渐变负，|v| 稳定在 Vtarget，iq 上限下降。
  • 急加速：|v| 短时超调，Δid 迅速响应；若振荡 → 弱磁 PI 带宽过高或与电流环耦合。
  • 电压跌落：Vtarget 随之下降，Δid 立即加深。

volatile q15_t Cal_IdMinFw_q15 = -32768;    /* -50 A：去磁下限，按电机供应商允许值 【待核对】*/
static PI_tst s_piFw = { .kp_q12 = 0, .kiTs_q15 = 0, .integ_q30 = 0, .outMax = 0, .outMin = -32768 };

/* 2 kHz 任务（每 10 个 PWM 周期）*/
q15_t FOC_FieldWeakenAdjust(q15_t idMtpa)
{
    q15_t vMax = Q15_Mul(Q15_Mul(gFoc.vdcPu, Q15_INV_SQRT3), Cal_VmaxK_q15);
    q15_t vTgt = Q15_Mul(vMax, Cal_FwVoltK_q15);
    q15_t vAbs = Q15_SqrtQ30((int32_t)gFoc.vd * gFoc.vd + (int32_t)gFoc.vq * gFoc.vq);
    q15_t dId;
    int32_t id;

    s_piFw.kp_q12   = Cal_FwKp_q12;
    s_piFw.kiTs_q15 = Cal_FwKiTs_q15;
    dId = PI_Run(&s_piFw, Q15_Sat((int32_t)vTgt - vAbs));   /* |v| > vTgt → 误差为负 → Δid 变负 */
    id  = (int32_t)idMtpa + dId;
    if (id > idMtpa)          { id = idMtpa; }
    if (id < Cal_IdMinFw_q15) { id = Cal_IdMinFw_q15; }
    return (q15_t)id;
}

/* 电流圆限幅：id 优先 */
void FOC_CurrentLimit(q15_t *idRef, q15_t *iqRef, q15_t isMax)
{
    int32_t iqMax;
    if (*idRef < -isMax) { *idRef = (q15_t)(-isMax); }
    iqMax = Q15_SqrtQ30((int32_t)isMax * isMax - (int32_t)(*idRef) * (*idRef));
    if (*iqRef >  iqMax) { *iqRef = (q15_t)iqMax; }
    if (*iqRef < -iqMax) { *iqRef = (q15_t)(-iqMax); }
}

第四部分：嵌入式实现步骤

  1. 给定轨迹规划（梯形 / S 曲线）同时输出 θRef、ωRef_ff、αRef_ff。
  2. 位置环（1 ms）：ωRef = Kp·eθ + K_vff·ωRef_ff，限幅最大速度。
  3. 速度环（1 ms）：iqRef = PI(eω) + K_aff·αRef_ff·J/Kt，限幅电流；抗饱和。
  4. 角度误差 eθ 使用多圈累计角度（int32），处理过零。
  5. D 项（若用）：反馈微分 + 一阶低通，截止频率 3~5 倍环路带宽以上。

第五部分：仿真与波形预期

  • 无前馈：误差与指令速度近似成正比（速度型误差 = ω/Kp）。
  • 有前馈：误差主要来自内环动态和前馈参数误差。
  • 负载阶跃：速度短暂跌落后由积分恢复。

第三部分：核心原理与公式

【理论公式】 静止坐标电压方程（SPMSM）：v_αβ = Rs·i_αβ + Ls·di_αβ/dt + e_αβ，e_αβ = ωe·ψf·[−sinθ, cosθ] IPMSM 扩展反电动势（EEMF）：把凸极项并入「扩展反电动势」，模型对称化（来源：Morimoto / Chen 等提出的 EEMF 模型） ① 滑模观测器 SMO： 估计电流 d î/dt = (v − Rs·î − z)/Ls，z = k·sign(î − i)（或饱和函数） 滑模面上 z 的等效值 ≈ e，需低通得到 ê，再提取角度；低通相位滞后 Δφ = atan(ωe/ωc) 需补偿 优点：鲁棒、实现简单；缺点：抖振、需滤波与补偿 ② 龙伯格观测器：以反电动势为状态（慢变），用线性增益 L·(î − i) 修正 优点：无抖振、可按极点配置设计；缺点：对参数更敏感 ③ MRAS：参考模型（电压模型）与可调模型（电流模型）的输出误差驱动自适应律估计 ω 优点：理论成熟；缺点：低速对 Rs 敏感 角度提取： atan2(−êα, êβ)：简单但噪声直接进入角度 PLL：ε = −êα·cosθ̂ − êβ·sinθ̂ ≈ |ê|·sin(θ − θ̂)，PI 输出 ω̂，积分得 θ̂（同时得到平滑速度） 零低速：高频注入（脉振 / 旋转注入），利用 Ld ≠ Lq 的凸极性 【待核对：具体注入方案依项目】 【厂商参考】TI InstaSPIN-FOC 的 FAST 观测器为 TI 私有算法 【厂商私有方案】；ST MC SDK 提供基于 PLL / CORDIC 的状态观测器；NXP 提供开源的 MCAT / RTCESL 中的反电动势观测器组件——均为参考实现，不是唯一标准。

第四部分：嵌入式实现步骤

  1. SMO 电流模型（20 kHz）：î[k+1] = î[k] + Ts/Ls·(v − Rs·î − z)，使用上周期电压（与电流时刻对齐）。
  2. 开关函数：sign 用饱和函数（边界层）减小抖振；增益 k 大于反电动势最大值。
  3. 低通：ê = LPF(z)，截止频率随转速自适应（如 ωc = 1.5~2·ωe），相位补偿 atan(ωe/ωc)。
  4. PLL：误差归一化（除以 |ê|）使环路增益与转速无关。
  5. 启动：I/F 开环升速到观测可用转速（如额定 10% 以上），角度误差稳定后切换（D06）。
  6. EPS 降级：低速不可用时的策略（限制助力 / 安全状态）由系统安全设计决定。

第五部分：仿真与波形预期

  • 中高速：观测角与旋变角误差在若干度以内；速度估计平滑。
  • 低速：误差增大并抖动；死区补偿与 Rs 准确度显著影响低速表现。
  • 负载阶跃：短暂角度误差后恢复；PLL 带宽决定恢复速度。

/* 浮点示意（S32K146 带单精度 FPU，可在中断中使用 float；定点版本见 D02 思路）*/
typedef struct { float iaHat, ibHat, eA, eB, thHat, wHat, integ; } SMO_tst;
static SMO_tst s_smo;
volatile float Cal_SmoK = 8.0f, Cal_SmoBnd = 2.0f;     /* 增益 V、边界层 A 【案例假设】 */
volatile float Cal_PllKp = 400.0f, Cal_PllKi = 40000.0f;

static float satf(float x, float b) { return (x > b) ? 1.0f : ((x < -b) ? -1.0f : x / b); }

void FOC_Smo_Isr(float vA, float vB, float iA, float iB)
{
    const float Ts = 50e-6f, Rs = 0.012f, Ls = 60e-6f;   /* Ls 取 (Ld+Lq)/2 近似，IPMSM 应用 EEMF */
    float zA = Cal_SmoK * satf(s_smo.iaHat - iA, Cal_SmoBnd);
    float zB = Cal_SmoK * satf(s_smo.ibHat - iB, Cal_SmoBnd);
    s_smo.iaHat += Ts / Ls * (vA - Rs * s_smo.iaHat - zA);
    s_smo.ibHat += Ts / Ls * (vB - Rs * s_smo.ibHat - zB);
    float wc = fmaxf(1.5f * fabsf(s_smo.wHat), 300.0f);  /* 自适应低通截止 rad/s */
    float a  = wc * Ts;
    s_smo.eA += a * (zA - s_smo.eA);
    s_smo.eB += a * (zB - s_smo.eB);
    /* PLL：误差 = |e|·sin(θ − θ̂)，归一化 */
    float s = sinf(s_smo.thHat), c = cosf(s_smo.thHat);
    float mag = sqrtf(s_smo.eA * s_smo.eA + s_smo.eB * s_smo.eB) + 1e-3f;
    float err = (-s_smo.eA * c - s_smo.eB * s) / mag;
    s_smo.integ += Cal_PllKi * Ts * err;
    s_smo.wHat   = Cal_PllKp * err + s_smo.integ;
    s_smo.thHat += s_smo.wHat * Ts;
    if (s_smo.thHat >  3.14159265f) { s_smo.thHat -= 6.2831853f; }   /* 取模，防止 A06 的精度问题 */
    if (s_smo.thHat < -3.14159265f) { s_smo.thHat += 6.2831853f; }
    gFoc.thetaEObs = (uint16_t)(int32_t)(s_smo.thHat * 10430.378f) + (uint16_t)(atanf(s_smo.wHat / wc) * 10430.378f);
}

最后一行为低通相位补偿（rad → uint16：×65536/2π = 10430.4）。PLL 参数按带宽设计：ωn ≈ √Ki，ζ = Kp/(2√Ki)，示例约 200 rad/s、ζ = 1。该代码用于教学说明结构，量产需完成定点化 / 执行时间评估与充分台架验证。

第三部分：核心原理与公式

【理论公式】 Rs（直流两点法，消除死区 / 管压降常值误差）：d 轴注入两个电流 I1、I2，记录给定电压 V1、V2 Rs ≈ (V2 − V1)/(I2 − I1)；其中含线缆与 MOS 导通电阻，需按需求扣除或保留 Ld：转子对齐 d 轴，d 轴电压阶跃 / 方波，τ = Ld/R（A07），或 Ld = V·Δt/Δi（短脉冲，忽略 R） Lq：方法一 锁止转子后沿 q 轴注入；方法二 静止时 q 轴高频小幅注入（平均转矩为零，转子基本不动） 饱和曲线：在多个偏置电流下测量，得到 Ld(id)、Lq(iq) 表 ψf：方法一 对拖测反电动势：ψf = E_phase_peak/ωe（最准确） 方法二 空载 id = 0 运行：ψf ≈ (vq − Rs·iq)/ωe（受电压误差影响） 在线辨识：递推最小二乘 RLS（以 dq 方程为回归模型）、模型参考自适应；需持续激励，且参数之间存在耦合，不宜同时辨识全部参数 【待核对：具体方案依项目与文献】 温度模型：Rs(T) = Rs25·[1 + 0.00393·(T − 25)]（铜）

【暂无可交互动画】电压阶跃法的动态过程可直接使用 A07 的交互动画（拖动 R、L 观察 τ 与 63.2% 点）；本节重点是台架流程与误差来源。

  • 误报：全工况（低温、高速、电压波动、EMC）下无误报。

第六部分：EPS 案例实现

typedef struct { uint16_t cnt; uint16_t setN; uint16_t clrN; uint8_t active; } DIAG_DEB_tst;

static inline void Diag_Deb(DIAG_DEB_tst *d, uint8_t cond)
{
    if (cond) { if (d->cnt < d->setN) { d->cnt++; } else { d->active = 1u; } }
    else      { if (d->cnt > 0u) { d->cnt--; } if ((d->cnt == 0u) && (d->clrN != 0u)) { d->active = 0u; }   /* clrN = 0：锁存 */ }
}

/* 软件过流：直接比较 ADC 码值（相对零点），避免 Q15 基值饱和问题 */
#define OC_SW_CNT   (1966)    /* 48 A ÷ 0.024414 A/码 【案例假设】 */

void FOC_FastDiag_Isr(void)
{
    static DIAG_DEB_tst s_oc = { 0u, 3u, 0u, 0u };     /* 连续 3 周期，锁存（clrN = 0 表示不自动清除）*/
    int32_t da = (int32_t)gFoc.adcIa - Cal_IaOffset_cnt;
    int32_t db = (int32_t)gFoc.adcIb - Cal_IbOffset_cnt;
    int32_t dc = -da - db;
    uint8_t oc = (da > OC_SW_CNT) || (da < -OC_SW_CNT) ||
                 (db > OC_SW_CNT) || (db < -OC_SW_CNT) ||
                 (dc > OC_SW_CNT) || (dc < -OC_SW_CNT);
    Diag_Deb(&s_oc, oc);
    if (s_oc.active) { FOC_EmergencyOff(DIAG_OC_SW); }
}

void FOC_EmergencyOff(uint16_t code)
{
    Pwm_DisableAll();                 /* 先关管，再做其余处理 */
    FOC_PiResetAll();
    Diag_SetFault(code);
    Diag_FreezeFrame();               /* 冻结帧：ia ib thetaE vdc spd */
    gFoc.state = FOC_ST_FAULT;
}

量程设计提醒：案例中采样量程 ±50 A，而 C07 讨论的电流极限达 50~60 A，软件过流只能设在量程边缘（48 A），与工作电流几乎没有裕量；60 A 的硬件保护也必须走独立于 ADC 运放的通路，否则运放饱和后无法检测。量产设计应让采样量程 ≥ 最大保护阈值 × 1.2（例如 ±80 A），同时相应修改 I_BASE、每码 LSB 与全部标幺参数（X2 讨论）。软件过流阈值不能超过采样量程，否则诊断永远不会触发（B07 过压例子同理）。

C13 扰动补偿：死区补偿、逆变器非线性补偿、齿槽转矩补偿

模块 C · 核心 FOC 链路 · 第 13 节

第一部分：小节基础

链路位置SVPWM 之前修正电压（死区 / 非线性）；给定侧叠加力矩（齿槽）
输入 / 输出输入：相电流方向 / 幅值、角度、Vdc；输出：补偿电压或补偿电流
工程价值EPS 低速手感（颗粒感、6 阶脉动）、无感低速精度、参数辨识准确度都受其影响
上下游依赖上游 C01、C09；下游 C04、C10、C11
适用角色算法、标定
前置数学依赖A01 分段函数、A03 谐波、A04 dq 变换中的谐波阶次
① 为什么需要死区让实际电压偏离给定，误差符号由电流方向决定——在 dq 中表现为 6×fe 电压扰动；12 V 低压系统中 1 µs 死区约 0.24 V，低速时与所需电压同量级。
② 量产怎么做按相电流方向前馈补偿 ΔV（过零附近线性过渡）；逆变器压降按电流查表；齿槽按机械角度查表前馈电流。
③ 如何证明低速 iq 频谱 6 阶下降；相电流过零「平台」消失；扭矩脉动阶次分析。

第二部分：前置条件

  • 已知死区时间、MOS 开关延迟、导通压降（规格书 + 实测）。
  • 电流过零判断的可靠信号（电流给定或滤波后的反馈）。
  • 齿槽表需要高精度角度与无负载 / 低速台架测量。

第三部分：核心原理与公式

【理论公式】 死区平均电压误差（每相）：ΔV ≈ −sign(i)·(Td + ton − toff)/Ts·Vdc − sign(i)·Vf（导通压降，近似） 案例：Td = 1 µs，Ts = 50 µs，Vdc = 12 V → ΔV ≈ 0.24 V 【案例假设，未计开关延迟与压降】 对比：300 rpm、iq = 20 A 时所需 vq ≈ Rs·iq + ωe·ψf ≈ 0.24 + 0.44 = 0.68 V，误差占比约 35% 补偿：vX_comp = vX + Kdt·f(iX)，f 为符号函数的平滑版本（|i| < I0 时线性） 方向判据：用电流给定方向（相位稳定）或反馈（含噪声，过零附近易误判） dq 视角：三相方波电压误差 → dq 中 6×fe 扰动，电流环带宽有限，高速时无法抑制 齿槽转矩：Tcog(θm) 为机械角周期函数，基本周期由极槽数决定（Nc = LCM(槽数, 极数)） 补偿：iq_comp(θm) = −Tcog(θm)/Kt，查表前馈 【待核对：本案例未给槽数，表需实测】
动画在演示什么：一个电周期内 A 相给定电压（灰）、死区后的实际平均电压（红）与相电流（蓝）。右图为 dq 中 q 轴电压误差（6 倍频）。
拖动滑块：增大死区时间或降低转速（降低基波电压幅值），误差占比变大，电流过零处出现「平台」；勾选「死区补偿」，按电流方向加回 ΔV；「过零线性区 I0」太小时补偿在过零附近来回切换（产生噪声），太大时补偿不足。
正常：补偿后红线贴近灰线、6 倍频减小。

第四部分：嵌入式实现步骤

  1. 在反 Clarke 之后、零序注入之前，对每相电压加补偿：vX += Cal_DtCompV × fsat(iX/I0)。
  2. iX 使用给定电流经反 Park / 反 Clarke 得到的三相给定（相位干净）或滤波反馈。
  3. 补偿量随 Vdc 缩放：ΔV ∝ Vdc（每周期更新）。
  4. 齿槽补偿：1 ms 或中断内按 θm 查表叠加到 iqRef，表长按机械周期分辨率。
  5. 标定：低速恒力矩运行，调 Cal_DtCompV 使 6 阶分量最小。

第五部分：仿真与波形预期

  • 未补偿：低速相电流过零处平台、波形「方化」；iq 6 阶纹波。
  • 过补偿：过零处反向尖峰。
  • 齿槽补偿：空载极低速转动时 iq 脉动 / 速度脉动在齿槽阶次下降。

volatile q15_t Cal_DtCompV_q15 = 492;     /* 0.24 V / 16 V × 32768 @12 V，随 Vdc 缩放 【案例假设】*/
volatile q15_t Cal_DtI0_q15    = 655;     /* 线性区 1 A */

static inline int32_t DtComp_OnePhase(q15_t iRef)
{
    int32_t x = ((int32_t)iRef << 15) / Cal_DtI0_q15;            /* i/I0，Q15 */
    if (x >  32767) { x =  32767; }
    if (x < -32768) { x = -32768; }
    /* ΔV = Kdt × fsat(i/I0) × (Vdc/12 V)；vdcPu@12 V = 24576 */
    return (((x * Cal_DtCompV_q15) >> 15) * gFoc.vdcPu) / 24576;
}

/* 在 FOC_Svpwm_Isr 中、求 v0 之前调用：va += DtComp(iaRef) … */
void FOC_DeadTimeComp(int32_t *va, int32_t *vb, int32_t *vc,
                      q15_t iaRef, q15_t ibRef, q15_t icRef)
{
    *va += DtComp_OnePhase(iaRef);
    *vb += DtComp_OnePhase(ibRef);
    *vc += DtComp_OnePhase(icRef);
}
