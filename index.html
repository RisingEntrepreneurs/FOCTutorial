三、全书统一约定（动画与代码严格一致）

  • Clarke 采用幅值不变形式（系数 2/3）；α 轴与 A 相绕组轴线重合，β 轴超前 α 90°。
  • 正方向：逆时针为正。A→B→C 正相序时电流空间矢量逆时针旋转，电角度 θe 增大，对应「正转」。
  • Park：id = iα·cosθ + iβ·sinθ；iq = −iα·sinθ + iβ·cosθ；复数写法 i_dq = i_αβ·e^(−jθ)。反 Park：vα = vd·cosθ − vq·sinθ；vβ = vd·sinθ + vq·cosθ。
  • d 轴对准永磁体磁链方向，q 轴超前 d 轴 90°；iq > 0 产生正向电磁转矩。
  • 相电流正方向：从逆变器流入电机为正。
  • 角度格式 uint16：16384 = 90°，32768 = 180°，加法溢出即自动取模 2π。

第一部分：小节基础

链路位置FOC 最前端：ADC 原始码值 → 物理电流 → 标幺 Q15；同样用于母线电压、温度、旋变角度换算
输入 / 输出输入：ADC 码值 N、标定偏移 N0、增益 K；输出：电流 A、标幺值、Q15 整数
工程价值所有后续计算都建立在「数值代表什么物理量」之上；换算错一处，Clarke/Park/PI 全部失真
上下游依赖下游：C01 电流采样校准、D02 定点实现、C05 PI 标幺参数
适用角色全部角色；MCU 底层与标定工程师必修
前置数学依赖无（本节为起点）
① 为什么需要MCU 只认识整数码值。不会线性映射与移项，就无法把 ADC 读数变成电流，也无法写出 di/dt = (v − R·i)/L 这类后续公式。
② 量产怎么做上电 PWM 关闭时做偏移校准，产线/台架做两点增益标定；中断内用整数乘加 + 移位完成换算，统一标幺基值。
③ 如何证明静止零电流时读数 < 0.1 A；对比钳形表/功率分析仪，增益误差 < 1%；满量程不削顶。

第二部分：前置条件

  • 信号：两相电流 ADC 码值；硬件：采样电阻 + 运放偏置在 ADC 中点。
  • 标定参数：Cal_IaOffset_cnt、Cal_IaGainCorr_q15（B 相同理）。
  • 不满足的现象：偏移未校准 → 静止有「假电流」，运行中 dq 电流出现电频率一次脉动；量程不足 → 波形削顶，过流保护失效或误报。

第三部分：核心原理与公式

【理论公式】线性映射（一次函数）：

I = (N − N0) · K N：ADC 码值；N0：零电流对应码值（偏移）；K：A/码值（增益） 案例：±50 A ↔ 0~4095 → K = 100 A / 4096 = 0.024414 A/cnt，N0 理想 = 2048 【案例假设】

【理论公式】两点标定（二元一次方程组）：已知 (N1, I1)、(N2, I2) 两组实测点

K = (I2 − I1) / (N2 − N1) N0 = N1 − I1 / K

【理论公式】移项求解（后续每章都在用）：由 RL 电压方程 v = R·i + L·di/dt

di/dt = (v − R·i) / L ← 「把要求的量单独放到等号一边」

【理论公式】标幺化与 Q15：

i_pu = I / I_BASE （I_BASE = 50 A） i_q15 = round(i_pu · 32768)，范围 [−32768, 32767] 案例巧合设计：每个 ADC 码对应 Q15 增量 = K·32768/I_BASE = 0.024414×32768/50 = 16（恰为 2⁴，可用移位）

【理论公式】限幅（分段函数）：sat(x) = x_max（x > x_max）；x_min（x < x_min）；x（其他）。

动画在演示什么：一个真实正弦相电流经过「硬件零点」变成 ADC 码，再用「软件偏移 + 增益修正」换算回电流和 Q15。左图是换算直线（蓝）与真实直线（灰虚线），右图是时域对比。
拖动滑块：让「软件偏移」≠「硬件零点」，蓝线整体平移，时域出现直流偏置；增益修正 ≠ 1，峰值被放大/缩小；电流峰值 > 50 A，ADC 卡在 0/4095，波形削顶。
正常现象：灰蓝重合，偏移误差显示绿色。异常：偏置、比例错误、削顶（红色提示）。

第四部分：嵌入式实现步骤

  1. 上电偏移校准（目的：得到 N0）：PWM 输出关闭、运放上电稳定 ≥ 数十 ms 后，每 PWM 周期采样，累加 1024 次求平均（右移 10 位）。中断约束：只读 ADC，不运行电流环。标定量：结果写入 Cal_IaOffset_cnt，超出 2048 ± 100 视为采样电路故障。
  2. 两点增益标定（台架/产线）：直流注入已知电流（如 A 进 B 出 +20 A），用精密表计读 I，代入两点公式得增益修正，写入 Cal_IaGainCorr_q15。
  3. 中断内换算：(adc − off) 用 int32 运算 → 左移 4 位得 Q15 → 乘增益修正（Q15×Q15 >> 15）→ 饱和到 int16。
  4. 溢出保护：(adc − off) 范围约 ±2100，×16 后可达 ±33600，超出 int16，必须先在 int32 中运算再饱和。
  5. 第三相：星接无中线，ic = −ia − ib（A03 证明）。

第五部分：仿真与波形预期

  • 正常：PWM 关闭时 ia、ib 在 0 附近，噪声峰峰值 ≤ 若干码；运行时三相正弦幅值一致、相差 120°。
  • 偏移误差：相电流中心线偏离 0；在 dq 中表现为以电频率脉动的纹波（直流量经 Park 变成一倍频交流）。
  • 增益不一致（A/B 相差几个 %）：dq 中出现 2 倍电频率纹波。
  • 削顶：波形顶部平直，过流判断失效。

第六部分：EPS 案例实现

【定点实现】Q15 基础工具（全书共用，D02 会扩展）：

#include <stdint.h>
typedef int16_t q15_t;

#define Q15_MAX   ((int32_t)32767)
#define Q15_MIN   ((int32_t)-32768)

static inline q15_t Q15_Sat(int32_t x)
{
    if (x > Q15_MAX) { return (q15_t)Q15_MAX; }
    if (x < Q15_MIN) { return (q15_t)Q15_MIN; }
    return (q15_t)x;
}

/* Q15 × Q15：(-1)×(-1) = +1.0 超出 Q15，必须饱和 */
static inline q15_t Q15_Mul(q15_t a, q15_t b)
{
    return Q15_Sat(((int32_t)a * (int32_t)b) >> 15);
}

【定点实现】偏移校准与中断换算：

#define OFFS_CAL_SHIFT   (10u)            /* 1024 次平均 */
#define OFFS_VALID_MIN   (1948)           /* 2048 - 100  【案例假设】 */
#define OFFS_VALID_MAX   (2148)

static uint32_t s_offAccA = 0u, s_offAccB = 0u;
static uint16_t s_offCnt  = 0u;

/* PWM 关闭状态下，在 PWM 中断中调用；返回 1 表示完成 */
uint8_t FOC_OffsetCal_Isr(void)
{
    s_offAccA += gFoc.adcIa;
    s_offAccB += gFoc.adcIb;
    s_offCnt++;
    if (s_offCnt >= (1u << OFFS_CAL_SHIFT)) {
        int16_t offA = (int16_t)(s_offAccA >> OFFS_CAL_SHIFT);
        int16_t offB = (int16_t)(s_offAccB >> OFFS_CAL_SHIFT);
        if ((offA >= OFFS_VALID_MIN) && (offA <= OFFS_VALID_MAX) &&
            (offB >= OFFS_VALID_MIN) && (offB <= OFFS_VALID_MAX)) {
            Cal_IaOffset_cnt = offA;
            Cal_IbOffset_cnt = offB;
        } else {
            Diag_SetFault(DIAG_ISENSE_OFFSET);   /* 采样电路异常 */
        }
        return 1u;
    }
    return 0u;
}

/* ADC → Q15：每码 = 16 LSB（±50 A 量程 / I_BASE 50 A） */
static inline q15_t FOC_AdcToIq15(uint16_t adc, int16_t off, q15_t gainCorr)
{
    int32_t x = ((int32_t)adc - (int32_t)off) * 16;      /* 先在 int32 中运算 */
    x = (x * (int32_t)gainCorr) >> 15;                   /* 增益修正 Q15     */
    return Q15_Sat(x);
}

void FOC_CurrentConvert_Isr(void)
{
    gFoc.ia = FOC_AdcToIq15(gFoc.adcIa, Cal_IaOffset_cnt, Cal_IaGainCorr_q15);
    gFoc.ib = FOC_AdcToIq15(gFoc.adcIb, Cal_IbOffset_cnt, Cal_IbGainCorr_q15);
    gFoc.ic = Q15_Sat(-(int32_t)gFoc.ia - (int32_t)gFoc.ib);
}

说明：增益修正 Cal_IaGainCorr_q15 的标称值 32767（≈1.0）；若需要 > 1.0 的修正，改用 Q14 格式。Diag_SetFault 属于 C12 诊断模块接口。

第七部分：高频调试问题 / 数学易错点

【高频故障】静止时相电流读数不为零
现象
PWM 关闭，CANape 显示 ia ≈ +1.2 A，ib ≈ −0.4 A。
可能根因
偏移校准时运放未稳定；校准时 PWM 已开（有真实电流）；NVM 中旧标定值覆盖了上电校准值。
排查顺序
① 读 Cal_IaOffset_cnt 与 ADC 原始均值对比 → ② 查校准触发时序（与 PWM 使能、运放供电的先后）→ ③ 查是否有写覆盖。
修复
校准延后至供电稳定；校准期间强制 PWM 关闭；增加有效范围判断。
验证波形
静止 ia/ib 均值 < 0.1 A；运行时 iq 频谱一倍电频率分量明显下降。
【高频故障】大电流时波形削顶
现象
堵转大电流测试时相电流顶部平直，过流保护不动作。
可能根因
运放输出饱和早于 ADC 满量程；量程设计不足；偏移偏离中点导致单边量程变小。
排查顺序
示波器同时测运放输出与 ADC 码值 → 计算正负方向剩余量程。
修复
量程至少覆盖最大保护阈值 × 1.2；软件增加「ADC 码值接近 0/4095」诊断。
验证波形
阶跃到保护阈值，波形完整，保护按设定值触发。
数学易错点：无符号减法回绕
现象
电流偶尔跳到 +2000 A 量级。
可能根因
写成 (uint32_t)adc - off，adc < off 时结果回绕成大正数。
排查顺序
在电流为负的半周抓数据；静态代码检查（MISRA 本质类型规则）。
修复
两个操作数都先转 int32 再相减。
验证
负半周波形连续；单元测试覆盖 adc = 0、off = 2148。

第八部分：工程踩坑

  • 整数除法截断：先乘后除（a*b/c），并确认乘积不溢出。
  • 负数右移：C 标准中负数右移是实现定义；Arm 编译器为算术右移，但需在编码规范中明确并做单元测试。
  • 基值混用：电流环用 50 A 基值、保护模块用 100 A 基值，比较阈值时直接相比 → 保护点差一倍。全项目只用一套基值头文件。
  • Q15 无法表示 +1.0：最大 32767/32768；-1 × -1 必须饱和。
  • 温漂：偏移随温度变化，长时间运行可考虑在零矢量/停机期间周期性重校准。

第一部分：小节基础

第三部分：核心原理与公式

【理论公式】 矢量 v = (x, y)；模长 |v| = √(x² + y²)；角度 θ = atan2(y, x)（四象限） 合成：a + b = (ax + bx, ay + by) ← 平行四边形法则 点积：a · b = ax·bx + ay·by = |a||b|cos∠(a,b) 投影：v 在单位矢量 e 方向上的分量 = v · e 旋转坐标系（新轴 d 与 x 轴夹角 φ，q 超前 d 90°）： vd = x·cosφ + y·sinφ vq = −x·sinφ + y·cosφ ← 这就是 Park 变换的几何本质 电压限幅（SVPWM 线性区内切圆）：√(vd² + vq²) ≤ Vdc/√3（12 V 时 6.93 V）
动画在演示什么：两个矢量 a、b 合成 a+b（平行四边形），并把合成矢量投影到一套旋转坐标轴 d、q 上。右图记录 d、q 分量随坐标轴旋转的变化。
拖动滑块：改变 a、b 的模长和角度，合成矢量随之改变；启动后坐标轴 φ 逆时针旋转，固定矢量在旋转坐标系里的分量变成正弦——这正是「静止矢量在旋转坐标系中看是交流」，反之旋转矢量在同步旋转坐标系中看是直流（A04）。
正常：投影垂足落在轴上，d²+q² 恒等于 |a+b|²。异常判断：若你的代码算出的 d²+q² 不守恒，说明 sin/cos 或符号写错。

第四部分：嵌入式实现步骤

  1. 投影：4 次 Q15 乘法 + 2 次加减，int32 累加后右移 15 位再饱和。
  2. 模长：平方和在 Q30（int32）中计算，整数开方得 Q15；仅在慢任务或限幅时使用，避免中断内频繁开方。
  3. 角度：atan2 用「八分区 + 查表」或 CORDIC；禁止 atan(y/x)（丢象限、x=0 除零）。
  4. 电压限幅（d 轴优先）：先限 vd，再按 √(Vmax² − vd²) 限 vq。Vmax 每周期由 Vdc 实时计算，标定量可设裕量系数。

/* 输入 Q30（非负），输出 Q15：sqrt(x·2^30) = sqrt(x)·2^15 */
static q15_t Q15_SqrtQ30(int32_t xQ30)
{
    uint32_t x = (xQ30 > 0) ? (uint32_t)xQ30 : 0u;
    uint32_t r = 0u;
    uint32_t b = 1uL << 30;
    while (b > x) { b >>= 2; }
    while (b != 0u) {
        if (x >= (r + b)) { x -= (r + b); r = (r >> 1) + b; }
        else              { r >>= 1; }
        b >>= 2;
    }
    return (q15_t)((r > 32767u) ? 32767u : r);
}

/* d 轴优先圆限幅；vMax = Vdc/√3 的标幺值（12 V 时 6.93/16 = 0.433 → 14189） */
void FOC_VoltLimit(q15_t *vd, q15_t *vq, q15_t vMax)
{
    int32_t vqMax;
    if (*vd >  vMax) { *vd = vMax; }
    if (*vd < -vMax) { *vd = (q15_t)(-vMax); }
    vqMax = Q15_SqrtQ30(((int32_t)vMax * vMax) - ((int32_t)(*vd) * (*vd)));
    if (*vq >  vqMax) { *vq = (q15_t)vqMax; }
    if (*vq < -vqMax) { *vq = (q15_t)(-vqMax); }
}

d 轴优先 vs 等比例缩放：EPS 力矩模式中，d 轴电压承担弱磁与解耦，优先保证 d 轴可维持磁场控制；等比例缩放保持电压方向不变，实现简单但弱磁区 id 控制易失效。两者均为业内常见做法，按项目验证选择。

  • 前置数学：A02 单位矢量。弧度：一整圈 = 2π rad = 360°。
  • 信号：旋变电角度 θe；电角速度 ωe（用于补偿）。

第三部分：核心原理与公式

【理论公式】 单位圆：角度 θ 处单位矢量 = (cosθ, sinθ)；sin²θ + cos²θ = 1 角频率：ω = 2πf；电角度 θe = p·θm，电角速度 ωe = p·ωm，电频率 fe = p·n/60 案例：3000 rpm → fe = 4×3000/60 = 200 Hz；8000 rpm → 533.3 Hz 三相平衡电流：ia = I·cos(θ+γ)，ib = I·cos(θ+γ−120°)，ic = I·cos(θ+γ+120°)，ia+ib+ic = 0 和差角公式：cos(a−b) = cos a·cos b + sin a·sin b sin(a−b) = sin a·cos b − cos a·sin b 用它证明 Park 的效果：设 iα = I·cos(θ+γ)，iβ = I·sin(θ+γ) id = iα·cosθ + iβ·sinθ = I·cos(θ+γ−θ) = I·cosγ ← 与 θ 无关，直流！ iq = −iα·sinθ + iβ·cosθ = I·sin(θ+γ−θ) = I·sinγ
【离散实现】每 PWM 周期电角度增量 Δθ = ωe·Ts 案例 8000 rpm：Δθ = 2π·533.3·50 µs = 0.1676 rad ≈ 9.6° 采样→PWM 生效的等效延迟约 1.5Ts（中断计算 1Ts + PWM 中心对齐 0.5Ts）→ 约 14.4° 角度误差
动画在演示什么：左边单位圆上的矢量逆时针旋转（与全书正方向一致），它在水平轴的投影就是 cosθ（A 相电流形状），竖直投影是 sinθ。右边画出三相余弦及其和。
拖动滑块：「频率」改变旋转快慢；「C 相相位偏差」模拟三相不平衡——三相和不再为 0，这时「用 ic = −ia − ib 推算第三相」的假设失效。
正常：三相和曲线恒为 0。异常：和曲线出现正弦，提示相序/采样/硬件不平衡。

第四部分：嵌入式实现步骤

  1. 角度格式：uint16 表示 0~2π，16384 = 90°；加法溢出天然取模，无需判断。
  2. 查表：1024 点 sin 表（2 KB Flash，末尾多存 1 点便于插值）；高 10 位作索引，低 6 位线性插值。
  3. cos：cosθ = sin(θ + 90°)，即索引 +16384。
  4. 电角度：θe = (θm × p) 在 uint16 上直接乘 4 截断（自动取模），再减零位偏移 Cal_ThetaOffset（C09）。
  5. 延迟补偿：反 Park 使用 θ + 1.5·Δθ；Park 使用采样时刻角度。补偿量用标定系数可调。

第五部分：仿真与波形预期

  • 恒定 iq 给定，转速从 500 rpm 扫到 6000 rpm：未补偿时实测 id 偏离给定、力矩常数下降；补偿后基本平直。

#define SIN_LUT_BITS   (10u)                     /* 1024 点 */
#define SIN_FRAC_BITS  (16u - SIN_LUT_BITS)      /* 6 位插值 */
extern const q15_t c_SinLut[(1u << SIN_LUT_BITS) + 1u];  /* 离线生成，90° 处取 32767 */

static inline q15_t FOC_Sin(uint16_t th)
{
    uint32_t idx  = (uint32_t)th >> SIN_FRAC_BITS;
    int32_t  frac = (int32_t)(th & ((1u << SIN_FRAC_BITS) - 1u));
    int32_t  y0   = c_SinLut[idx];
    int32_t  y1   = c_SinLut[idx + 1u];
    return (q15_t)(y0 + (((y1 - y0) * frac) >> SIN_FRAC_BITS));
}
static inline q15_t FOC_Cos(uint16_t th) { return FOC_Sin((uint16_t)(th + 16384u)); }

/* 每 PWM 中断：机械角 → 电角 → 延迟补偿 */
void FOC_AngleUpdate_Isr(void)
{
    uint16_t thE  = (uint16_t)((uint16_t)(gFoc.thetaM * FOC_POLE_PAIRS) - Cal_ThetaOffset);
    int16_t  dTh  = (int16_t)(uint16_t)(thE - gFoc.thetaE);      /* 每 Ts 增量 */
    gFoc.thetaEIncPerTs = dTh;                                    /* 后续应用滤波 */
    gFoc.thetaE = thE;
    gFoc.sinTh  = FOC_Sin(thE);
    gFoc.cosTh  = FOC_Cos(thE);
    /* 反 Park 用补偿角：θ + Cal_AngCompK × Δθ，Cal_AngCompK 标称 1.5（Q8：384）【案例假设】 */
    gFoc.thetaEInvPark = (uint16_t)(thE + (uint16_t)(((int32_t)dTh * Cal_AngCompK_q8) >> 8));
}

第三部分：核心原理与公式

【理论公式】 复数 z = x + j·y = |z|·e^(jφ)；|z| = √(x²+y²)，φ = atan2(y, x) 欧拉公式：e^(jθ) = cosθ + j·sinθ 乘法：z1·z2 = |z1||z2|·e^(j(φ1+φ2)) ← 模相乘、角相加 → 乘 e^(jθ) 就是逆时针转 θ 空间矢量（幅值不变）：i_s = (2/3)(ia + a·ib + a²·ic) = iα + j·iβ，a = e^(j120°)，1 + a + a² = 0 Park：i_dq = id + j·iq = i_s · e^(−jθ) 反 Park：v_s = v_dq · e^(+jθ)
【理论公式】dq 电压方程的来源（SPMSM 先令 Ld = Lq = L） 静止坐标：v_s = R·i_s + dψ_s/dt，ψ_s = L·i_s + ψf·e^(jθ) 代入 i_s = i_dq·e^(jθ)，对乘积求导：d(i_dq·e^(jθ))/dt = (di_dq/dt + jω·i_dq)·e^(jθ) 两边约去 e^(jθ)：v_dq = R·i_dq + L·di_dq/dt + jω·L·i_dq + jω·ψf 展开为 IPMSM 形式（Ld ≠ Lq）： vd = R·id + Ld·did/dt − ω·Lq·iq vq = R·iq + Lq·diq/dt + ω·Ld·id + ω·ψf 来源：PMSM 矢量控制经典教材通用推导（如 R. Krishnan《Permanent Magnet Synchronous and Brushless DC Motor Drives》）
动画在演示什么：左图 αβ 平面中，电流矢量 i_s（橙）以电频率逆时针旋转；控制器使用的 dq 轴（紫 d̂ / 黄 q̂）按估计角 θ̂ 旋转，虚线是真实 d 轴。右图是 Park 输出 id、iq 的时间曲线。
拖动滑块：「角度偏差」使 dq 输出出现常值偏移（零位标定错误的典型）；「频率失配」使 dq 输出缓慢正弦摆动（速度估计不准）；勾选「Park 方向写反」，dq 变成 2 倍电频率振荡。
正常：id、iq 两条水平直线，数值 = I·cosγ、I·sinγ。异常：偏移、摆动、高频振荡分别对应三类根因。

第四部分：嵌入式实现步骤

  1. 复数用结构体 {re, im} 表示，Q15。
  2. 乘 e^(−jθ)：(re + j·im)(c − j·s) = (re·c + im·s) + j(im·c − re·s)，4 次乘、2 次加减。
  3. int32 累加，右移 15 位后饱和；输入矢量模长 ≤ 1 pu 时结果不会超限。
  4. Park 与反 Park 在同一中断里使用的角度可能不同（延迟补偿，A03），sin/cos 分别计算。

第五部分：仿真与波形预期

  • 正常稳态：id、iq 直流 + 小纹波（PWM 纹波、谐波）。
  • 纹波频率对应根因：1 倍 fe → 电流偏移；2 倍 fe → 两相增益不一致或 Park 写反；6 倍 fe → 死区 / 反电动势谐波。

typedef struct { q15_t re; q15_t im; } CPLX_tst;

/* z · e^(-jθ)：Park；|z| ≤ 1 pu 时结果不越界 */
static inline CPLX_tst Cplx_RotNeg(CPLX_tst z, q15_t s, q15_t c)
{
    CPLX_tst r;
    r.re = Q15_Sat(((int32_t)z.re * c + (int32_t)z.im * s) >> 15);
    r.im = Q15_Sat(((int32_t)z.im * c - (int32_t)z.re * s) >> 15);
    return r;
}
/* z · e^(+jθ)：反 Park */
static inline CPLX_tst Cplx_RotPos(CPLX_tst z, q15_t s, q15_t c)
{
    CPLX_tst r;
    r.re = Q15_Sat(((int32_t)z.re * c - (int32_t)z.im * s) >> 15);
    r.im = Q15_Sat(((int32_t)z.im * c + (int32_t)z.re * s) >> 15);
    return r;
}

{

}

第一部分：小节基础

链路位置由角度求速度、电感压降 L·di/dt、反电动势 dψ/dt、PID 的 D 项、低通滤波

第二部分：前置条件

  • 前置数学：A01 斜率（Δy/Δx）、A03 正弦。导数 = 时间间隔趋近 0 时的斜率。
  • 信号：旋变机械角度 thetaM；采样周期确定（定时中断）。
  • 不满足：测速噪声大 → 速度环电流给定噪声 → 力矩脉动、噪声；滤波过重 → 速度环相位滞后振荡。

第三部分：核心原理与公式

【理论公式】 导数：dx/dt = lim(Δt→0) [x(t) − x(t−Δt)] / Δt；d(sin ωt)/dt = ω·cos ωt 【离散实现】后向差分：x'[k] ≈ (x[k] − x[k−1]) / Ts · 等效延迟约 Ts/2（相当于在两个采样点中间求斜率） · 噪声放大：若采样噪声标准差 σ，差分噪声 ≈ √2·σ / Ts —— Ts 越小，噪声越大 一阶低通（后向欧拉离散）：y[k] = y[k−1] + α·(x[k] − y[k−1])，α = Ts / (τf + Ts)，fc = 1/(2π·τf) · α 越小越平滑，但延迟（相位滞后）越大 测速分辨率（12 位旋变，窗口 Tw）：Δn = 60 / (4096·Tw) rpm · Tw = 50 µs → 293 rpm/码；Tw = 1 ms → 14.6 rpm/码
动画在演示什么：上图：50 Hz 正弦被以 Ts 采样（点）并叠加噪声；下图：真实导数（灰，已除以 ω 归一化）、后向差分（红）与一阶低通后的差分（蓝）。
拖动滑块：减小 Ts 但保持噪声 → 红线噪声急剧变大（噪声 ∝ 1/Ts）；增大 Ts → 红线阶梯化、滞后；减小 α → 蓝线变平滑但明显滞后于灰线。
正常折中：蓝线贴近灰线、轻微滞后。异常：红线毛刺远大于信号（直接用差分做反馈会让速度环抖动）。

第四部分：嵌入式实现步骤

  1. 角度差分处理过零：(int16_t)(uint16_t)(θ[k] − θ[k−1])，只要一个窗口内转过不足半圈即正确。8000 rpm、1 ms 窗口机械转 48°，安全。
  2. 窗口选择：快速中断里只记录角度，1 ms 任务里做差分（窗口 = 1 ms）。
  3. 换算：rpm = Δθ / 65536 × 60 / Tw，Tw = 1 ms → rpm = Δθ × 60000 / 65536。
  4. 低通：系数 Cal_SpdLpfK_q15，int32 状态；结果用于速度环（C08）。
  5. 低速：分辨率不足时改用 M/T 法、角度 PLL 观测器或解码芯片速度通道（AD2S1210 具有速度输出，具体格式以 ADI 数据手册为准 【待核对】）。

第五部分：仿真与波形预期

  • 恒速 1000 rpm：原始差分以 ±1 码（±14.6 rpm）跳变，滤波后纹波明显减小。
  • 速度阶跃：滤波输出滞后于真实速度，延迟约 τf；若 τf 接近速度环带宽倒数，速度环超调增大。

A06 积分与累加：积分器、相位累加器、漂移与积分饱和

模块 A · 前置工程数学 · 第 6 节

第一部分：小节基础

链路位置PI 的 I 项、开环角度发生器 θ = ∫ω dt、电压模型磁链观测 ψ = ∫(v − R·i)dt、电量/热模型累加
输入 / 输出输入：每周期增量；输出：累加状态
工程价值积分消除稳态误差，也带来漂移、溢出与饱和三大风险
上下游依赖上游 A01、A05；下游 A07、A08、C05、C10、D06
适用角色全部角色
前置数学依赖A01、A05（积分是微分的逆运算）
① 为什么需要开环拖动需要由频率「积」出角度；PI 需要累积误差消除稳态偏差；无感观测从电压「积」出磁链。
② 量产怎么做int32/uint32 累加器；相位累加器利用溢出自动取模；积分器有上下限；纯积分用低通/泄漏替代。
③ 如何证明长时间运行（数小时）累加量不漂移、不溢出；开环频率实测 = 设定。

第二部分：前置条件

  • 前置数学：A01 累加、A05 差分。积分 = 曲线下面积 = Σ x[k]·Ts。
  • 信号：输入的偏置必须尽量小（A01 偏移校准）。
  • 不满足：磁链观测随时间漂移；积分饱和导致超调；开环角度运行越久越抖（浮点精度丢失）。

第三部分：核心原理与公式

【理论公式】y(t) = ∫₀ᵗ u(τ)dτ；∫ sin(ωt)dt = (1 − cos ωt)/ω（从 0 开始） 【离散实现】 前向矩形：y[k] = y[k−1] + Ts·u[k−1] 后向矩形：y[k] = y[k−1] + Ts·u[k] 梯形： y[k] = y[k−1] + Ts·(u[k] + u[k−1])/2 直流偏置的后果：u = 信号 + b → y 中多出 b·t，线性增长直到溢出 泄漏积分（低通替代）：y[k] = (1 − λ)·y[k−1] + Ts·u[k] ≈ 1/(s + λ/Ts)，偏置只造成有限误差 b·Ts/λ 相位累加器：acc[k] = acc[k−1] + inc（uint32 自然回绕），inc = fe·2³²·Ts，θe = acc >> 16 案例：10 Hz 电频率 → inc = 10 × 4294967296 × 50 µs ≈ 2147484
动画在演示什么：输入为正弦 + 小直流偏置（类比带偏移的反电动势电压）。蓝线是数字积分器输出，灰虚线是无偏置时的理想积分。
拖动滑块：偏置 > 0 时蓝线线性爬升（漂移）；开启「积分器限幅」后卡在上限（饱和）；增大泄漏系数 λ，漂移被抑制但积分结果幅值和相位出现误差（低通替代纯积分的代价）。
正常：偏置 0 时蓝灰重合。异常：持续爬升或长时间贴限幅。参数修改实时生效。

第四部分：嵌入式实现步骤

  1. 累加器位宽：状态至少 int32；增量远小于状态时，需更高的小数位（如 Q30），避免「增量 < 1 LSB 被截断」。
  2. 相位累加器：uint32，溢出即取模，无需判断；高 16 位作为 uint16 电角度。
  3. 限幅：积分器上下限与输出限幅匹配（A08 抗饱和）。
  4. 漂移抑制：纯积分观测器改为低通 / 泄漏积分 + 幅相补偿（C10）。

第五部分：仿真与波形预期

  • 开环 I/F 拖动：θe 为均匀锯齿，频率与设定一致；电流幅值稳定。
  • 纯积分磁链：有偏移时估计磁链轨迹圆心逐渐偏移；泄漏积分时圆心稳定。

第三部分：核心原理与公式

【理论公式】 RL 电路：v = R·i + L·di/dt →（零初值拉氏变换）V(s) = (R + L·s)·I(s) 传递函数：G(s) = I(s)/V(s) = 1/(L·s + R) = (1/R) / (τ·s + 1)，τ = L/R 阶跃响应：i(t) = (V/R)·(1 − e^(−t/τ))；t = τ 时 63.2%，t = 3τ 时 95%，5τ 时 99.3% 频率响应：|G(jω)| = 1/√(R² + (ωL)²)，∠G = −arctan(ωL/R)；转折频率 fc = R/(2πL) 闭环：T(s) = C(s)G(s) / (1 + C(s)G(s))；带宽 ≈ |T| 下降 3 dB 的频率 纯延迟 e^(−s·Td)：幅值不变，相位滞后 ω·Td（弧度） 案例：τd = 45 µH/12 mΩ = 3.75 ms，fc,d = 42.4 Hz；τq = 6.25 ms 【案例假设】 Td ≈ 1.5Ts = 75 µs → 1 kHz 处滞后 360°×1000×75e-6 = 27°

  4. 结果写入标定表 Cal_Ld_uH、Cal_Lq_uH、Cal_Rs_mOhm（C11 参数辨识细化）。

#define STEP_N   (400u)              /* 400 × 50 µs = 20 ms ≥ 5τ */
static q15_t s_idBuf[STEP_N];        /* PWM 中断中逐点写入 gFoc.id */

void Ident_Ld_Process(float vStep_V)
{
    float iInf = Q15ToAmp(average(&s_idBuf[STEP_N - 40u], 40u));   /* 取末尾均值作为终值 */

    uint16_t k = first_index_ge(s_idBuf, STEP_N, AmpToQ15(i632));

}

第三部分：核心原理与公式

【理论公式】 连续 PID：u(t) = Kp·e + Ki·∫e dt + Kd·de/dt 零极点对消设计（电流环，对象 1/(Ls+R)）： C(s) = Kp + Ki/s = Kp·(s + Ki/Kp)/s，令 Ki/Kp = R/L 开环 C·G = (Kp/L)/s → 闭环 T(s) = ωc/(s + ωc)，ωc = Kp/L ⇒ Kp = ωc·L，Ki = ωc·R 案例（ωc = 2π·1 kHz）【案例假设】： d 轴 Kp = 0.283 V/A，Ki = 75.4 V/(A·s)；q 轴 Kp = 0.471 V/A，Ki = 75.4 V/(A·s) 【离散实现】位置式（后向矩形积分）： I[k] = I[k−1] + Ki·Ts·e[k]，u[k] = sat(Kp·e[k] + I[k]) 增量式：Δu[k] = Kp·(e[k] − e[k−1]) + Ki·Ts·e[k]，u[k] = sat(u[k−1] + Δu[k]) 【定点实现】标幺：Kp_pu = Kp·I_BASE/V_BASE，KiTs_pu = Ki·Ts·I_BASE/V_BASE d：Kp_pu = 0.884 → Q12 = 3619；q：Kp_pu = 1.473 → Q12 = 6032（> 1，不能用 Q15） KiTs_pu = 75.4 × 50e-6 × 50/16 = 0.01178 → Q15 = 386 抗积分饱和：① 积分器限幅 ② 条件积分（输出饱和且误差同向时冻结）③ 反算法 I += Kb·(u_sat − u)

第四部分：嵌入式实现步骤

  1. 误差：e = ref − fb（Q15），注意 int32 计算防溢出。
  2. P 项：Kp_q12 × e >> 12 → Q15，int32。
  3. I 项：积分状态 int32 Q30，增量 KiTs_q15 × e（Q30），用 int64 求和再限幅。
  4. 输出限幅：限幅值来自电压圆（A02），每周期按实测 Vdc 更新。
  5. 抗饱和：输出饱和时只允许积分朝退饱和方向变化（条件积分）。
  6. 中断约束：PI 在 PWM 中断内执行；参数通过 XCP 修改时，Kp/Ki 写入需原子（int16 单次写入天然原子）。
  7. D 项：电流环一般不用（采样含 PWM 纹波，D 放大噪声且相位已够）；速度/位置环如需 D，必须带低通（C08）。

第五部分：仿真与波形预期

  • 设计值：iq 阶跃上升时间 ≈ 0.35/1 kHz = 0.35 ms，超调很小。
  • Kp 过大：高频振荡（延迟引起）；Ki 过大（Ti 远小于 τ）：低频超调。
  • 电压饱和：电流上升斜率受限（di/dt = (Vmax − R·i)/L），无抗饱和时退出饱和后超调。

typedef struct {
    int16_t kp_q12;        /* Kp 标幺，Q12（范围 ±8）       */
    int16_t kiTs_q15;      /* Ki·Ts 标幺，Q15              */
    int32_t integ_q30;     /* 积分状态，Q30                 */
    q15_t   outMax;        /* 输出上限（正数）              */
    q15_t   outMin;        /* 输出下限（负数）              */
} PI_tst;

q15_t PI_Run(PI_tst *pi, q15_t err)
{
    int32_t p    = ((int32_t)pi->kp_q12 * (int32_t)err) >> 12;            /* Q15 */
    int64_t iNew = (int64_t)pi->integ_q30 + ((int64_t)pi->kiTs_q15 * err);  /* Q30 */
    int64_t iMax = (int64_t)pi->outMax << 15;
    int64_t iMin = (int64_t)pi->outMin << 15;
    int32_t u;

    if (iNew > iMax) { iNew = iMax; }          /* ① 积分器自身限幅 */
    if (iNew < iMin) { iNew = iMin; }

    u = p + (int32_t)(iNew >> 15);

    if (u > pi->outMax) {                      /* ② 条件积分 */
        u = pi->outMax;
        if (err < 0) { pi->integ_q30 = (int32_t)iNew; }   /* 只允许退饱和方向 */
    } else if (u < pi->outMin) {
        u = pi->outMin;
        if (err > 0) { pi->integ_q30 = (int32_t)iNew; }
    } else {
        pi->integ_q30 = (int32_t)iNew;
    }
    return (q15_t)u;
}

  • 速度环 PI 的输出是 iq 给定，限幅为电流极限；电流环输出是电压——不同环的抗饱和信号不能混用。
  • 【风险红线】积分器在故障关管后未清零，重新使能 PWM 瞬间输出满电压 → 过流冲击。
