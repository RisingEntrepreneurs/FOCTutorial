B01 为什么要用 FOC？V/F、DTC 与 FOC 的工程取舍

模块 B · 基础扫盲 · 第 1 节

第一部分：小节基础

链路位置方案选型阶段：决定整个控制软件架构
输入 / 输出输入：应用需求（力矩精度、动态、噪声、转速范围、成本）；输出：控制方案与传感器方案
工程价值EPS 直接作用在方向盘手感上：力矩脉动、延迟、噪声都会被驾驶员感知，选错方案后期无法靠标定弥补
上下游依赖下游：B04 矢量控制思想、F01 FOC vs DTC、F02 有感 vs 无感
适用角色系统 / 算法工程师；嵌入式工程师需理解选型理由
前置数学依赖A02 矢量、A04 复数（理解「控制矢量」）
① 为什么需要V/F 只控制电压幅值和频率，不直接控制力矩；EPS 需要毫秒级、低脉动的力矩响应，只有直接控制 dq 电流的方案才能满足。
② 量产怎么做EPS、电驱主流采用带位置传感器的 FOC + 电流环 20 kHz 执行；风机、水泵等对力矩不敏感的场合仍常用 V/F 或无感 FOC。
③ 如何证明力矩阶跃响应时间、力矩脉动百分比、低速平稳性、噪声主观评价——用台架扭矩传感器数据对比，而不是看仿真。

第二部分：前置条件

  • 需求：力矩精度、带宽、转速范围、功能安全等级（EPS 常见为 ASIL D 相关要求，具体以项目安全目标为准 【待核对】）。
  • 硬件：有无位置传感器、电流采样方式、MCU 算力（FOC 每周期需数十 µs 级计算余量）。
  • 不满足：算力或采样不支持 20 kHz 电流环 → 力矩带宽不足，手感「发木」。

第三部分：核心原理与公式

【理论公式】三类方案控制的核心量 V/F： 控制 |V| 与 f，保持 V/f ≈ 常数（磁通近似恒定）；力矩是「结果」而非被控量 DTC： 直接控制定子磁链 |ψs| 与电磁转矩 Te，滞环比较 + 开关表选电压矢量 FOC： 控制 dq 电流：Te = 1.5·p·[ψf·iq + (Ld − Lq)·id·iq]（B02 推导） → 力矩 ≈ 正比 iq（SPMSM 严格正比），电流环带宽即力矩带宽
维度V/FDTCFOC
力矩控制间接，开环直接，滞环直接，经电流环
开关频率固定变化（滞环），噪声频谱宽固定（SVPWM），噪声可控
力矩脉动大较大（滞环宽度决定）小
低速性能差依赖磁链估计，低速差有位置传感器时零速满力矩
参数依赖低定子电阻电感、磁链（解耦、MTPA、弱磁）
算力 / 采样要求低高采样率中等，需精确同步采样
EPS 适用性不适用少见主流

【暂无可交互动画】本节是方案取舍，用对比表更清楚；三种方案的动态差异在 B04（矢量控制）与 F01（FOC vs DTC）中演示。

第四部分：嵌入式实现步骤（方案落地评估）

  1. 算力预算：20 kHz 主中断 50 µs 周期，FOC 主链路（采样换算、Clarke、Park、2×PI、反 Park、SVPWM、诊断）通常占用一部分；需在 PIL 实测执行时间，保留余量给诊断与通信 【待核对：具体占比以 S32K146 实测为准】。
  2. 外设能力：PWM 中心对齐 + 互补 + 死区 + 硬件故障关断；ADC 由 PWM 定时硬件触发（不能软件触发，否则抖动）。
  3. 位置传感：EPS 要求零速满力矩 → 旋变为主，无感算法作为降级备份。
  4. 标定接口：XCP 测量与标定，确保所有 Cal_ 量可在线改。

第五部分：仿真与波形预期

  • FOC：力矩阶跃时 iq 在 ~0.35 ms 量级跟踪到位（1 kHz 带宽），相电流为正弦。
  • V/F：负载突变时电流冲击大、转速掉落，力矩响应慢且可能失步。
  • DTC：相电流含较宽频谱的纹波，听感为「沙沙」宽频噪声。

第六部分：EPS 案例实现

/* EPS 控制模式枚举（D04 状态机使用）*/
typedef enum {
    FOC_MODE_TORQUE = 0,   /* 力矩模式：上层 EPS 助力算法给 iqRef（主模式） */
    FOC_MODE_SPEED,        /* 速度模式：台架 / 回正 / 测试用              */
    FOC_MODE_POSITION      /* 位置模式：标定、终端保护等特殊功能          */
} FOC_Mode_ten;

/* 上层（1 ms）给出目标电磁力矩，转换为 iq 给定（SPMSM 近似；IPMSM 用 C06 MTPA 表）*/
#define FOC_KT_NM_PER_A   (0.021f)   /* 1.5·p·ψf = 1.5×4×3.5e-3 【案例假设】 */
q15_t FOC_TorqueToIqRef(float teRef_Nm)
{
    float iq_A = teRef_Nm / FOC_KT_NM_PER_A;
    return Q15_Sat((int32_t)(iq_A / FOC_I_BASE * 32768.0f));   /* 1 ms 任务内，可用浮点 */
}

第七部分：高频调试问题

【高频故障】力矩响应「发木」、手感延迟
现象
驾驶员快速打方向时助力滞后。
可能根因
电流环带宽不足（参数保守 / 执行周期过长）、上层力矩给定滤波过重、通信延迟。
排查顺序
① iq 给定 vs 反馈阶跃 → ② 上层给定到 iqRef 的延迟 → ③ 各级滤波器截止频率。
修复
按 A08 重新设计电流环；削减上层冗余滤波。
验证
扭矩传感器测力矩阶跃响应时间满足需求。
【高频故障】低速转向有「颗粒感」
现象
慢打方向盘感到周期性顿挫。
可能根因
齿槽转矩、电流偏移（一倍频）、角度误差、死区（六倍频）。
排查顺序
按频率分解：计算顿挫频率与电频率的倍数关系。
修复
对应 A01 偏移、C09 零位、C13 死区 / 齿槽补偿。
验证
力矩脉动频谱中对应阶次下降。
选型易错点：用 V/F 做低成本降级模式
现象
传感器故障后 V/F 降级运行时电机失步、方向盘抖。
可能根因
V/F 无力矩控制，EPS 负载随转向剧烈变化。
排查
负载突变试验。
修复
降级用无感 FOC 或安全关断策略（按功能安全设计）。
验证
故障注入试验通过。

第八部分：工程踩坑

  • 只看仿真比较方案：DTC 仿真曲线可能很漂亮，但开关频率不固定带来的 EMC、噪声问题仿真不体现。
  • 低估参数依赖：FOC 的解耦、MTPA、弱磁都依赖 Ld、Lq、ψf，参数辨识（C11）必须进入项目计划。
  • 把「能转」当成「能量产」：V/F 一天就能让电机转起来，但离满足 EPS 力矩指标差距很大。

B02 永磁同步电机基础：SPMSM / IPMSM、磁阻转矩、反电动势

模块 B · 基础扫盲 · 第 2 节

第一部分：小节基础

链路位置被控对象模型：所有算法的「物理基础」
输入 / 输出输入：id、iq、ωe；输出：电磁转矩 Te、反电动势、dq 电压
工程价值理解为何 IPMSM 要用负 id（MTPA、弱磁），为何高速电压不够
上下游依赖上游 A04 dq 方程；下游 C05、C06、C07、C10、C11
适用角色全部
前置数学依赖A03、A04
① 为什么需要不知道转矩公式中的磁阻项，就不会理解 IPMSM 的 MTPA；不知道反电动势随转速增长，就无法理解弱磁。
② 量产怎么做用 dq 模型 + 实测参数表（Ld、Lq 随电流变化）建立仿真与查表；反电动势常数在台架对拖测得。
③ 如何证明对拖测线反电动势幅值与转速成正比、与设计 ψf 一致；扭矩传感器测 Te–iq 曲线与公式一致。

第二部分：前置条件

  • 数学：A04 dq 电压方程。物理：磁体产生转子磁链 ψf，定子电流产生旋转磁场。
  • 参数：p、Rs、Ld、Lq、ψf（导读案例表）。
  • 不满足：把 IPMSM 当 SPMSM 用 id = 0 控制 → 同电流下力矩偏小、高速提前电压饱和。

第三部分：核心原理与公式

【理论公式】（幅值不变 Clarke 约定，来源：PMSM 矢量控制经典教材通用式） 磁链：ψd = Ld·id + ψf，ψq = Lq·iq 电压：vd = Rs·id + Ld·did/dt − ωe·Lq·iq vq = Rs·iq + Lq·diq/dt + ωe·Ld·id + ωe·ψf ← ωe·ψf 即反电动势 转矩：Te = 1.5·p·(ψd·iq − ψq·id) = 1.5·p·[ψf·iq + (Ld − Lq)·id·iq] 永磁转矩 ↑ 磁阻转矩 ↑（IPMSM：Ld < Lq，id < 0 时为正） SPMSM：Ld ≈ Lq，磁阻转矩 ≈ 0 → Te = 1.5·p·ψf·iq，id = 0 控制即最优 反电动势峰值（相）：E = ωe·ψf；ke（线反电动势有效值/krpm）可由 ψf 换算 案例 【案例假设】：Kt = 1.5×4×3.5 mWb = 0.021 N·m/A（峰值电流） iq = 35 A（额定峰值）、id = 0：Te = 0.735 N·m（电机轴，EPS 经减速机构放大） 3000 rpm：E = 1256.6 × 3.5e-3 = 4.40 V；8000 rpm：11.7 V > Vdc/√3 = 6.93 V
动画在演示什么：固定电流幅值 |is|，改变电流角 β（从 +d 轴逆时针量起，β = 90° 即纯 q 轴），绘制永磁转矩、磁阻转矩、总转矩随 β 的变化。
拖动滑块：Ld = Lq（SPMSM）时总转矩最大点在 β = 90°；Ld < Lq（IPMSM）时最大点右移到 β > 90°（即 id < 0），这就是 MTPA 的来源（C06）。增大 |is| 时磁阻转矩占比增加。
正常：曲线平滑、最大点随凸极比移动。注意：实际 Ld、Lq 随电流饱和变化，量产 MTPA 用实测表。

第四部分：嵌入式实现步骤

  1. 参数结构体：Rs、Ld、Lq、ψf 以标定量存放（Cal_ 前缀），用于解耦前馈、MTPA、弱磁、观测器。
  2. 温度修正：Rs 随铜温升高（约 +0.39%/°C），ψf 随磁钢温度降低（钕铁硼常见约 −0.1%/°C 量级 【待核对：以磁钢供应商数据为准】），慢任务按温度估计更新。
  3. 转矩估计：用 Te 公式在 1 ms 任务中估算实际力矩，供上层监控（功能安全对力矩合理性检查常用）。
  4. 定点：转矩计算涉及三个量相乘，在慢任务用浮点或 int64，避免 Q 格式链式溢出。

第五部分：仿真与波形预期

  • 对拖（PWM 关闭）：线反电动势正弦，幅值 ∝ 转速；THD 低。若含明显 5、7 次谐波 → 力矩脉动来源之一。
  • 同电流扫电流角：IPMSM 实测最大力矩点在 β > 90°；若在 90° 附近，说明凸极比小或零位偏差（C09）。

第六部分：EPS 案例实现

/* 电机参数标定量（物理单位 float，慢任务使用；快环使用其 Q 格式副本）【案例假设】*/
volatile float Cal_Rs_mOhm   = 12.0f;
volatile float Cal_Ld_uH     = 45.0f;
volatile float Cal_Lq_uH     = 75.0f;
volatile float Cal_PsiF_mWb  = 3.5f;

/* 1 ms 任务：电磁转矩估算（N·m），输入为 A */
float FOC_TorqueEst(float id_A, float iq_A)
{
    float psiF = Cal_PsiF_mWb * 1.0e-3f;
    float dL   = (Cal_Ld_uH - Cal_Lq_uH) * 1.0e-6f;      /* IPMSM: 负值 */
    return 1.5f * (float)FOC_POLE_PAIRS * (psiF * iq_A + dL * id_A * iq_A);
}

第七部分：高频调试问题

【高频故障】同 iq 力矩比设计值低 10%
现象
扭矩传感器读数持续偏低。
可能根因
ψf 实际偏小（磁钢温度高 / 批次差）、零位偏差导致电流不在 q 轴、Clarke 系数约定错误（2/3 vs √(2/3)）。
排查顺序
① 对拖测反电动势反推 ψf → ② 零位检查 → ③ 核对 Clarke 系数。
修复
更新 ψf 标定；修正零位；统一系数。
验证
多温度点 Te–iq 曲线与公式一致。
【高频故障】高温下最高转速提高、低温下下降
现象
不同环境温度最高转速差异明显。
可能根因
ψf 随温度变化 → 反电动势变化；弱磁表未按温度修正。
排查
记录不同温度的 vq 稳态与反电动势。
修复
弱磁用电压闭环（C07）而非纯查表；或表按温度插值。
验证
−40 / 25 / 85 °C 性能一致性满足需求。
易错点：把 ke 单位混淆
现象
由供应商 ke 反推的 ψf 差 √3 或 √2 倍。
根因
ke 可能是线电压有效值 / 线电压峰值 / 相电压峰值，单位 V/krpm 或 V·s/rad。
排查
与供应商确认定义；自行对拖测量。
修复
统一换算：ψf = 相电压峰值 / ωe。
验证
vq 稳态 ≈ ωe·ψf（id = 0、低电流）。

第八部分：工程踩坑

  • Ld、Lq 当常数：IPMSM 的 Lq 随 iq 增大饱和下降明显，大电流时 MTPA 和解耦误差变大。
  • 只测线间电感：LCR 线间读数随转子位置变化，需要按位置找最大 / 最小值推算 Ld、Lq（C11）。
  • 【风险红线】高速对拖时 PWM 关闭，若反电动势峰值超过母线电压，经体二极管向电池回馈，可能引起过压；12 V 系统 8000 rpm 线反电动势峰值约 20 V（√3 × 11.7 V），必须评估。
