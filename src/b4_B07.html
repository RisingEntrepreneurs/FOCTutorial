第二部分：前置条件

  • 硬件分压比、采样电阻、运放增益、旋变解码分辨率已确定。
  • 不满足：XCP 中显示的物理值不可信，标定无从谈起。

第三部分：核心原理与公式

【理论公式】 ωm(rad/s) = 2π·n/60；ωe = p·ωm；fe = p·n/60 每周期电角度增量（uint16）：inc = ωe·Ts·65536/(2π) = p·n/60·Ts·65536 案例 3000 rpm：inc = 4×3000/60×50e-6×65536 = 655.4 8000 rpm：inc ≈ 1748（≈ 9.6°） 母线电压标幺：vdcPu = Vdc/16 V；SVPWM 可用相电压上限 vMax = vdcPu/√3
动画在演示什么：4 对极转子（N/S 交替 8 个磁极）旋转。左图标注机械角度 θm；右图显示同一时刻电角度 θe = 4·θm 的锯齿波以及 uint16 码值。
拖动滑块：改变转速，右图锯齿频率是机械频率的 4 倍；「零位偏移」把电角度整体平移。
正常：机械一圈内电角度走 4 个完整锯齿。异常判断：若你在 CANape 中看到每机械圈锯齿数 ≠ 极对数，说明极对数配置或角度换算错误。

第四部分：嵌入式实现步骤

  1. 建立 foc_units.h：所有基值、换算宏、Q 格式说明（D02 提供模板）。
  2. 变量命名后缀：_rpm、_q15、_cnt、_mOhm，跨模块接口禁止无单位裸数。
  3. A2L：每个测量量配置 COMPU_METHOD，使 CANape 直接显示物理单位（D08）。
  4. 母线电压采样也需滤波（但滤波过重会让 Vmax 跟不上负载突变，导致短时过调制）。

第五部分：仿真与波形预期

  • 匀速时 θm 为锯齿（每机械转一次），θe 每机械转 4 次。
  • 母线电压在大电流加速时有压降和纹波；EPS 12 V 系统还要考虑车载电源波动（启动瞬间跌落）。

第六部分：EPS 案例实现

/* foc_units.h 片段 */
#define SPD_BASE_RPM        (8000)
#define VDC_ADC_FULL_V      (20.0f)                   /* 分压满量程 【案例假设】 */
#define ANG_INC_PER_RPM_Q8  (56)                      /* p×Ts×65536/60 ×256 = 0.2185×256 ≈ 56 */

static inline q15_t FOC_VdcAdcToPu(uint16_t adc)
{   /* Vdc = adc/4096×20 V；pu = Vdc/16 → ×32768 → adc × 10 */
    return Q15_Sat((int32_t)adc * 10);
}
static inline int16_t FOC_RpmToAngInc(int32_t rpm)
{
    return (int16_t)((rpm * ANG_INC_PER_RPM_Q8) >> 8);   /* 3000 rpm → 656 */
}

核对：adc × 10：4096 × 10 = 40960 → 超过 32767，即 Vdc > 16 V 时饱和——Q15 基值 16 V 意味着 16 V 以上的过压无法表示，过压诊断（阈值 18 V）应直接比较 ADC 码值或使用更大基值。这类基值上限问题必须在设计时检查。

第七部分：高频调试问题

【高频故障】CANape 显示转速是实际的 4 倍
现象
台架转速计 1000 rpm，CANape 显示 4000 rpm。
可能根因
用电角度差分算转速却按机械换算。
排查
检查测速输入是 thetaM 还是 thetaE。
修复
机械转速用 thetaM，或除以 p。
验证
与转速计一致。
【高频故障】过压诊断永不触发
现象
母线升到 18 V 仍无报警。
可能根因
vdcPu 基值 16 V，Q15 在 16 V 饱和，阈值 18 V 永远达不到。
排查
手算基值上限。
修复
过压诊断用 ADC 码值或单独基值。
验证
过压注入试验触发。
易错点：rad/s 与 Hz 混用
现象
解耦前馈差 2π 倍，高速电流振荡。
根因
ωe 用了 fe。
排查
手算 3000 rpm 时 ωe = 1256.6 rad/s。
修复
统一换算宏。
验证
vd 前馈与稳态 vd 一致。

第八部分：工程踩坑

  • 转速有正负：反转为负值，所有 int32/rpm 变量必须有符号；用 abs 前确认算法是否需要方向。
  • 旋变解码结果的位数配置改变（12→14 位）后左移位数未同步修改，角度错乱。
  • 母线电压基值选取要覆盖过压测试范围（如 ISO 16750-2 规定的车载电压试验，具体值以项目要求为准 【待核对】）。
