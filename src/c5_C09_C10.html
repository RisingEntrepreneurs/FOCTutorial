模块 C · 核心 FOC 链路 · 第 9 节

第一部分：小节基础

链路位置Park / 反 Park 的角度来源；测速来源
输入 / 输出输入：旋变 sin/cos 包络（经 AD2S1210 解码）；输出：gFoc.thetaM、thetaE、速度

适用角色底层、算法、标定

① 为什么需要FOC 的「电子换向」完全依赖角度；EPS 零速也要满力矩，必须有绝对位置传感器。
② 量产怎么做旋变 + 解码芯片（跟踪型 R/D 转换）；零位产线标定写 NVM；解码芯片故障位（信号丢失 / 退化 / 跟踪丢失）进入诊断。
③ 如何证明对拖反电动势过零与 θe 对齐（误差 < 1° 电角度量级）；正反转对称；恒速时角度误差频谱。

第二部分：前置条件

  • 硬件：旋变激磁驱动、sin/cos 差分接收、解码芯片与 MCU 接口（SPI / 并口）。
  • 配置：分辨率、激磁频率（AD2S1210 支持 10/12/14/16 位分辨率与可编程激磁频率，具体范围与跟踪速率以 ADI 数据手册为准 【待核对】）。
  • 旋变极对数：本案例假设为 1 对极旋变，θe = 4·θres 【案例假设】；若旋变极对数与电机相同，θe 直接等于旋变电角度。

第三部分：核心原理与公式

方案分辨率零速环境鲁棒性典型应用
霍尔（3 路）60° 电角度只知扇区好低成本 BLDC、风机；需插值
增量编码器高需找零（Z 信号 / 对齐）一般（污染、振动）工业伺服
绝对编码器 / 磁编高是较好伺服、部分 EPS
旋变由解码决定（12~16 位）是很好（耐温、耐振）车载电驱、EPS
【理论公式】 旋变输出：Vsin = k·Vex·sin θ·sin(ωex·t)，Vcos = k·Vex·cos θ·sin(ωex·t) 跟踪型解码：误差 ε = sin θ·cos θ̂ − cos θ·sin θ̂ = sin(θ − θ̂)，II 型环路驱动 θ̂ → θ 典型误差源与角度误差谐波（小误差近似）： sin/cos 直流偏置 → 1 次谐波误差 幅值不平衡 Δk/k → 约 (Δk/2k)·sin 2θ，2 次谐波 非正交（相位误差 δ）→ 约 δ/2 的常值 + 2 次谐波 激磁 / 信号相位延迟（随温度、线缆变化）→ 需解码芯片相位补偿 跟踪环动态滞后 → 随转速 / 加速度增大 零位：θe = p·θm − θoff；θoff 由 d 轴对齐或反电动势法标定
动画在演示什么：旋变 sin、cos 包络（左图 XY 为李萨如图，理想为圆），以及 atan2 解码角度相对真实角度的误差曲线（右图，横轴为真实电角度）。
拖动滑块：「幅值不平衡」→ 李萨如图变椭圆，误差出现 2 次谐波；「直流偏置」→ 圆心偏移，1 次谐波误差；「非正交」→ 椭圆倾斜。误差最终以 p × 谐波阶次出现在电角度上，引起力矩脉动。
正常：圆、误差 ≈ 0。异常：按谐波阶次反推原因。

第四部分：嵌入式实现步骤

  1. 读取角度：每 PWM 周期在采样时刻锁存解码芯片位置（与电流采样同步），12 位左移 4 位转 uint16。
  2. 电角度：θe = (uint16)(θm × 4 − Cal_ThetaOffset)（A03）。
  3. 零位标定（d 轴对齐法）：注入 id = 恒定（如 20 A，iq = 0），开环角度固定为 0，转子被吸到 d 轴；稳定后读 θm，Cal_ThetaOffset = θm × 4（取低 16 位）。正反两个方向接近后取平均以减小摩擦影响。
  4. 零位标定（反电动势法）：对拖，PWM 关闭，测 A 相反电动势过零时刻对应的 θe，与理论值比较（更准，需要对拖台架）。
  5. 诊断：解码芯片故障位（信号丢失 LOS、信号退化 DOS、跟踪丢失 LOT 等，以手册为准）；角度跳变（相邻周期 Δθ 超出物理可能）；与无感观测角度比较。

第五部分：仿真与波形预期

  • 恒速：θe 均匀锯齿；Δθ 每周期恒定（±少量噪声）。
  • 零位正确：id = 0 控制、空载对拖时 vd ≈ 0（小电流下），正反转 vd 对称。
  • 角度误差谐波：力矩脉动频谱中出现对应阶次。

第七部分：高频调试问题

【高频故障】力矩脉动在 2×p 阶（机械）突出
现象
转向时感到与机械转速相关的周期脉动，频谱在机械 8 阶（2×4）突出。
可能根因
旋变 sin/cos 幅值不平衡 → 2 次角度误差，乘极对数 4。
排查
采集 sin/cos 包络或解码误差；对比编码器参考角度。
修复
硬件增益匹配；软件误差补偿表（按 θm 查表）。
验证
对应阶次脉动下降。
【高频故障】零位标定结果每次差几度
现象
重复标定 Cal_ThetaOffset 分散 ±3° 电角度。
可能根因
齿槽 / 摩擦使转子停不到 d 轴；对齐电流太小；单方向接近。
排查
不同对齐电流、正反方向接近比较。
修复
增大对齐电流、双向平均；或用反电动势法。
验证
重复性 < 0.5°。
【高频故障】高温下高速力矩下降
现象
冷态正常，高温高速力矩不足。
可能根因
旋变信号相位随温度变化，解码延迟改变；ψf 下降。
排查
高温对拖测零位是否漂移。
修复
解码芯片相位补偿；延迟补偿按温度修正。
验证
高低温力矩一致性。

第八部分：工程踩坑

  • 角度锁存时刻与电流采样不同步：引入与转速成正比的角度误差。
  • 【风险红线】角度传感器失效时继续闭环 → 力矩方向错误。EPS 必须有角度合理性诊断（跳变、与观测器比较、解码故障位）并进入安全状态或降级。
  • 对齐法标定时电机必须无负载、可自由转动；否则标定值错误。
  • 旋变与电机极对数配置不一致：θe 每圈锯齿数错误（B07 动画判据）。

C10 无感观测：MRAS、滑模观测器 SMO、龙伯格观测器、PLL 角度提取

模块 C · 核心 FOC 链路 · 第 10 节（本案例用作旋变失效后的降级备份）

第一部分：小节基础

链路位置替代 / 校验位置传感器：电压、电流 → 估计角度与速度
输入 / 输出输入：vα、vβ（给定电压）、iα、iβ、参数；输出：θ̂e、ω̂e
工程价值EPS：旋变故障降级、角度合理性交叉校验；低成本应用：取消传感器
上下游依赖上游 C02、C04、C11（参数）；下游 C03、C12
适用角色算法
前置数学依赖A04 复数、A06 积分、A07 传递函数、A08 PI（PLL）
① 为什么需要反电动势 e = ωe·ψf·(−sinθ, cosθ) 中包含角度信息；从可测的电压电流中把它「估计」出来即可得到角度。
② 量产怎么做中高速用反电动势类观测器（SMO / 龙伯格 / 磁链观测）+ PLL；零低速用高频注入（IPMSM 凸极）或开环 I/F 启动；参数在线修正。
③ 如何证明与旋变角度对比的角度误差（稳态、动态、各转速）；切换过程电流平滑；参数偏差 ±30% 下的误差。

第二部分：前置条件

  • 准确的 Rs、Ls（SPMSM）或 Ld、Lq（IPMSM 用扩展反电动势模型）。
  • 输入电压：通常用给定电压，需要死区补偿（C13），否则低速误差大。
  • 不满足：低速反电动势太小，信噪比不足 → 观测失效（反电动势类方法的根本限制）。

第三部分：核心原理与公式

【理论公式】 静止坐标电压方程（SPMSM）：v_αβ = Rs·i_αβ + Ls·di_αβ/dt + e_αβ，e_αβ = ωe·ψf·[−sinθ, cosθ] IPMSM 扩展反电动势（EEMF）：把凸极项并入「扩展反电动势」，模型对称化（来源：Morimoto / Chen 等提出的 EEMF 模型） ① 滑模观测器 SMO： 估计电流 d î/dt = (v − Rs·î − z)/Ls，z = k·sign(î − i)（或饱和函数） 滑模面上 z 的等效值 ≈ e，需低通得到 ê，再提取角度；低通相位滞后 Δφ = atan(ωe/ωc) 需补偿 优点：鲁棒、实现简单；缺点：抖振、需滤波与补偿 ② 龙伯格观测器：以反电动势为状态（慢变），用线性增益 L·(î − i) 修正 优点：无抖振、可按极点配置设计；缺点：对参数更敏感 ③ MRAS：参考模型（电压模型）与可调模型（电流模型）的输出误差驱动自适应律估计 ω 优点：理论成熟；缺点：低速对 Rs 敏感 角度提取： atan2(−êα, êβ)：简单但噪声直接进入角度 PLL：ε = −êα·cosθ̂ − êβ·sinθ̂ ≈ |ê|·sin(θ − θ̂)，PI 输出 ω̂，积分得 θ̂（同时得到平滑速度） 零低速：高频注入（脉振 / 旋转注入），利用 Ld ≠ Lq 的凸极性 【待核对：具体注入方案依项目】 【厂商参考】TI InstaSPIN-FOC 的 FAST 观测器为 TI 私有算法 【厂商私有方案】；ST MC SDK 提供基于 PLL / CORDIC 的状态观测器；NXP 提供开源的 MCAT / RTCESL 中的反电动势观测器组件——均为参考实现，不是唯一标准。
动画在演示什么：估计反电动势（含噪声）送入 PLL，PLL 从 30° 初始误差开始收敛。左图：αβ 中真实反电动势（灰）与 PLL 角度对应的单位矢量（紫）；右图：角度误差与速度估计随时间收敛。
拖动滑块：增大 PLL 带宽 → 收敛快但噪声大；降低转速 → 反电动势幅值变小，信噪比下降，误差抖动变大（低速限制）；「SMO 低通未补偿」引入与转速相关的常值角度误差。
正常：误差快速收敛到 0 附近。异常：低速发散、常值偏差。

第四部分：嵌入式实现步骤

  1. SMO 电流模型（20 kHz）：î[k+1] = î[k] + Ts/Ls·(v − Rs·î − z)，使用上周期电压（与电流时刻对齐）。
  2. 开关函数：sign 用饱和函数（边界层）减小抖振；增益 k 大于反电动势最大值。
  3. 低通：ê = LPF(z)，截止频率随转速自适应（如 ωc = 1.5~2·ωe），相位补偿 atan(ωe/ωc)。
  4. PLL：误差归一化（除以 |ê|）使环路增益与转速无关。
  5. 启动：I/F 开环升速到观测可用转速（如额定 10% 以上），角度误差稳定后切换（D06）。
  6. EPS 降级：低速不可用时的策略（限制助力 / 安全状态）由系统安全设计决定。

第五部分：仿真与波形预期

  • 中高速：观测角与旋变角误差在若干度以内；速度估计平滑。
  • 低速：误差增大并抖动；死区补偿与 Rs 准确度显著影响低速表现。
  • 负载阶跃：短暂角度误差后恢复；PLL 带宽决定恢复速度。

第六部分：EPS 案例实现

/* 浮点示意（S32K146 带单精度 FPU，可在中断中使用 float；定点版本见 D02 思路）*/
typedef struct { float iaHat, ibHat, eA, eB, thHat, wHat, integ; } SMO_tst;
static SMO_tst s_smo;
volatile float Cal_SmoK = 8.0f, Cal_SmoBnd = 2.0f;     /* 增益 V、边界层 A 【案例假设】 */
volatile float Cal_PllKp = 400.0f, Cal_PllKi = 40000.0f;

static float satf(float x, float b) { return (x > b) ? 1.0f : ((x < -b) ? -1.0f : x / b); }

void FOC_Smo_Isr(float vA, float vB, float iA, float iB)
{
    const float Ts = 50e-6f, Rs = 0.012f, Ls = 60e-6f;   /* Ls 取 (Ld+Lq)/2 近似，IPMSM 应用 EEMF */
    float zA = Cal_SmoK * satf(s_smo.iaHat - iA, Cal_SmoBnd);
    float zB = Cal_SmoK * satf(s_smo.ibHat - iB, Cal_SmoBnd);
    s_smo.iaHat += Ts / Ls * (vA - Rs * s_smo.iaHat - zA);
    s_smo.ibHat += Ts / Ls * (vB - Rs * s_smo.ibHat - zB);
    float wc = fmaxf(1.5f * fabsf(s_smo.wHat), 300.0f);  /* 自适应低通截止 rad/s */
    float a  = wc * Ts;
    s_smo.eA += a * (zA - s_smo.eA);
    s_smo.eB += a * (zB - s_smo.eB);
    /* PLL：误差 = |e|·sin(θ − θ̂)，归一化 */
    float s = sinf(s_smo.thHat), c = cosf(s_smo.thHat);
    float mag = sqrtf(s_smo.eA * s_smo.eA + s_smo.eB * s_smo.eB) + 1e-3f;
    float err = (-s_smo.eA * c - s_smo.eB * s) / mag;
    s_smo.integ += Cal_PllKi * Ts * err;
    s_smo.wHat   = Cal_PllKp * err + s_smo.integ;
    s_smo.thHat += s_smo.wHat * Ts;
    if (s_smo.thHat >  3.14159265f) { s_smo.thHat -= 6.2831853f; }   /* 取模，防止 A06 的精度问题 */
    if (s_smo.thHat < -3.14159265f) { s_smo.thHat += 6.2831853f; }
    gFoc.thetaEObs = (uint16_t)(int32_t)(s_smo.thHat * 10430.378f) + (uint16_t)(atanf(s_smo.wHat / wc) * 10430.378f);
}

最后一行为低通相位补偿（rad → uint16：×65536/2π = 10430.4）。PLL 参数按带宽设计：ωn ≈ √Ki，ζ = Kp/(2√Ki)，示例约 200 rad/s、ζ = 1。该代码用于教学说明结构，量产需完成定点化 / 执行时间评估与充分台架验证。

第七部分：高频调试问题

【高频故障】无感切入失败、切入后失步
现象
I/F 升速后切换到观测角，电流冲击、电机抖动停转。
可能根因
切换时观测角与开环角相差大；观测器尚未收敛；切换转速过低。
排查
切换前记录 θ_obs − θ_IF；不同切换转速试验。
修复
误差小于阈值并保持一段时间再切；切换过程逐步过渡（角度 / 电流斜坡）；积分器预置（C05）。
验证
多次重复切换成功率 100%，电流平滑。
【高频故障】观测角存在随转速变化的常值偏差
现象
与旋变比较，误差随转速增大。
可能根因
低通相位滞后未补偿 / 补偿不正确；计算延迟未补偿。
排查
扫转速绘制误差曲线。
修复
补偿 atan(ωe/ωc) 与 1.5Ts 延迟。
验证
误差曲线平直接近 0。
【高频故障】低速观测抖动、力矩脉动
现象
额定转速 10% 以下估计角度抖动明显。
可能根因
反电动势小，逆变器非线性（死区）误差占比大；Rs 不准（温漂）。
排查
开启 / 关闭死区补偿对比；Rs 改变 ±20% 对比。
修复
死区补偿；Rs 在线估计；低速改用高频注入或限制工作区。
验证
目标最低转速下误差满足要求。

第八部分：工程踩坑

  • 用给定电压而非实际电压：死区 / 管压降误差直接进入观测器（C13）。
  • 电流与电压时刻不对齐：使用本周期给定电压配本周期采样电流，差了一个周期。
  • atan2 直接取角度：噪声与量化直接进入 Park，不如 PLL 平滑。
  • 【风险红线】反电动势类观测器在零速不可观：EPS 若以无感作降级，必须定义低速下的安全行为，不能「假装可用」。
