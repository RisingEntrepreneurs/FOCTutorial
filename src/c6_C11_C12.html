C11 参数辨识：Rs、Ld、Lq、磁链——离线辨识与在线辨识

模块 C · 核心 FOC 链路 · 第 11 节

第一部分：小节基础

链路位置参数来源：PI 设计、解耦前馈、MTPA、弱磁、观测器都依赖它
输入 / 输出输入：注入电压 / 电流与响应；输出：Rs、Ld(id)、Lq(iq)、ψf(T)
工程价值参数错误会同时影响 4~5 个模块，是很多「玄学」问题的共同根因
上下游依赖下游 A08/C05、C06、C07、C10
适用角色算法、标定
前置数学依赖A01 两点法、A07 阶跃响应与时间常数、A06 积分
① 为什么需要供应商数据通常是常温、小电流或线间值；IPMSM 的 Lq 随电流饱和明显，ψf 随温度变化，必须在实际工况下测。
② 量产怎么做开发阶段台架完整离线辨识（含饱和曲线、温度）→ 生成标定表；量产上电可做简化 Rs 自检；运行中可在线修正 Rs / ψf（温度估计）。
③ 如何证明多种方法交叉验证（误差 < 10%）；用辨识参数设计的电流环阶跃符合预期；前馈 vd、vq 与稳态实测一致。

第二部分：前置条件

  • 零位已标定（Ld/Lq 依赖 d、q 方向准确）；电流采样已校准；死区补偿（低电压注入时影响大）。
  • 台架：可锁止转子的工装（测 Lq）、对拖电机（测 ψf）、温度测量。
  • 不满足：结果把逆变器压降、线缆电阻混入电机参数。

第三部分：核心原理与公式

【理论公式】 Rs（直流两点法，消除死区 / 管压降常值误差）：d 轴注入两个电流 I1、I2，记录给定电压 V1、V2 Rs ≈ (V2 − V1)/(I2 − I1)；其中含线缆与 MOS 导通电阻，需按需求扣除或保留 Ld：转子对齐 d 轴，d 轴电压阶跃 / 方波，τ = Ld/R（A07），或 Ld = V·Δt/Δi（短脉冲，忽略 R） Lq：方法一 锁止转子后沿 q 轴注入；方法二 静止时 q 轴高频小幅注入（平均转矩为零，转子基本不动） 饱和曲线：在多个偏置电流下测量，得到 Ld(id)、Lq(iq) 表 ψf：方法一 对拖测反电动势：ψf = E_phase_peak/ωe（最准确） 方法二 空载 id = 0 运行：ψf ≈ (vq − Rs·iq)/ωe（受电压误差影响） 在线辨识：递推最小二乘 RLS（以 dq 方程为回归模型）、模型参考自适应；需持续激励，且参数之间存在耦合，不宜同时辨识全部参数 【待核对：具体方案依项目与文献】 温度模型：Rs(T) = Rs25·[1 + 0.00393·(T − 25)]（铜）

【暂无可交互动画】电压阶跃法的动态过程可直接使用 A07 的交互动画（拖动 R、L 观察 τ 与 63.2% 点）；本节重点是台架流程与误差来源。

参数推荐方法主要误差源交叉验证
Rs直流两点法死区、MOS、线缆、温度微欧计测线间电阻 ÷ 2
Ldd 轴阶跃 / 方波注入R 偏差、死区、转子未对齐LCR 线间电感最小值 ÷ 2（量级参考）
Lq锁止转子 q 轴注入 / 高频注入转子微动、饱和LCR 线间电感最大值 ÷ 2
ψf对拖反电动势转速测量、温度空载 vq 估算

第四部分：嵌入式实现步骤

  1. 辨识状态机（标定模式，D04）：OFFSET → ALIGN_D → RS_TEST → LD_TEST → LQ_TEST（可选）→ DONE。
  2. Rs：id = 10 A、20 A 各稳态 0.5 s，记录 vd 平均值（PWM 中断累加、1 ms 任务处理）。
  3. Ld：d 轴方波电压（如 ±0.3 V、1 kHz），测 Δi/Δt；或阶跃法（A07 伪代码）。
  4. 结果写入标定量并通过 XCP 读出；超出合理范围（如 ±50% 设计值）判失败。
  5. 在线 Rs 修正（可选）：低速、稳态时 vd 积分器均值与模型比较，慢速修正；或由温度传感器 + 温度模型估计。

第五部分：仿真与波形预期

  • Rs 两点：V–I 直线截距即逆变器压降常值，斜率为 Rs。
  • Lq 饱和曲线：随 iq 增大单调下降，IPMSM 大电流时可能下降明显。
  • ψf：与转速无关、随温度下降。

第六部分：EPS 案例实现

/* 【伪代码】Rs 两点法（1 ms 任务驱动，PWM 中断负责累加 vd、id）*/
float Ident_Rs_TwoPoint(void)
{
    float v1, i1, v2, i2;
    FOC_SetIdqRef(AMP_TO_Q15(10.0f), 0);  Wait_ms(500);  Avg_vd_id(200, &v1, &i1);
    FOC_SetIdqRef(AMP_TO_Q15(20.0f), 0);  Wait_ms(500);  Avg_vd_id(200, &v2, &i2);
    FOC_SetIdqRef(0, 0);
    return (v2 - v1) / (i2 - i1);          /* Ω，含线缆 + MOS；截距 v1 − Rs·i1 ≈ 逆变器压降 */
}

/* 1 s 任务：铜电阻温度修正（温度来自绕组温度估计 / 传感器）*/
void FOC_RsTempUpdate_1s(float tWinding_C)
{
    Cal_Rs_mOhm = Cal_Rs25_mOhm * (1.0f + 0.00393f * (tWinding_C - 25.0f));
}

第七部分：高频调试问题

【高频故障】辨识的 Rs 比微欧计大一倍
现象
单点 V/I 得 Rs = 30 mΩ，微欧计 12 mΩ。
可能根因
单点法包含死区 / 管压降常值；线缆 + MOS 电阻。
排查
两点法看截距；不同电流点画 V–I 曲线。
修复
两点法；明确参数是否包含逆变器侧电阻（观测器通常需要包含）。
验证
两点法斜率与微欧计 + 回路电阻一致。
【高频故障】测 Lq 时转子转动
现象
q 轴注入时电机抖动转动，结果离散。
可能根因
q 轴电流产生转矩；注入频率太低 / 幅值太大。
排查
观察 θm 变化。
修复
锁止转子工装；或提高注入频率（平均转矩为零、惯量滤除）。
验证
注入期间 θm 变化 < 0.5° 电角度，结果重复性好。
【高频故障】ψf 两种方法结果差 10%
现象
对拖 3.5 mWb，空载 vq 法 3.15 mWb。
可能根因
vq 为给定电压，含死区误差；转速信号误差；温度不同。
排查
死区补偿开 / 关对比；同温度测试。
修复
以对拖结果为准；vq 法仅作在线趋势。
验证
温度一致时两者差 < 3%。

第八部分：工程踩坑

  • 辨识结果直接覆盖运行参数：应先人工审核再写 NVM。
  • 只在一个电流点测电感：IPMSM 饱和后 PI 与 MTPA 都会偏离。
  • 在线同时辨识 Rs 与 ψf：两者在稳态方程中相关，缺乏激励时不可分辨。
  • 【风险红线】辨识注入电压从大值开始：低阻电机 0.5 V 即可产生 40 A 以上（A07），必须由小到大并开保护。

第一部分：小节基础

链路位置贯穿全链路：硬件快速通路 + 中断级诊断 + 慢任务诊断 + 故障响应
输入 / 输出输入：电流、电压、温度、角度、观测器、执行时间；输出：故障码、安全动作（关管 / 降额 / 降级）
工程价值防止硬件损坏与危险行为；EPS 涉及功能安全，诊断覆盖率与响应时间是评审重点
上下游依赖依赖全部前序模块信号；与 D03 中断架构、D04 状态机紧密相关
适用角色全部，功能安全工程师
前置数学依赖A01 阈值换算、A05 滤波 / 去抖
① 为什么需要MOS 过流能力以微秒计，软件中断周期 50 µs 太慢；温度、堵转则需要秒级热模型。不同故障需要不同时间尺度的检测通路。
② 量产怎么做硬件比较器 → PWM 故障输入（纳秒~微秒关管）；中断内软件过流 / 角度跳变；慢任务过温、堵转、欠压降额；故障分级与去抖。
③ 如何证明故障注入测试：每个诊断注入实际故障，测检测时间、响应动作与误报率（FMEA / 安全分析要求）。

第二部分：前置条件

  • 硬件：电流比较器、PWM 故障输入引脚、温度传感器、母线电压采样。
  • 安全需求：故障容错时间、安全状态定义（EPS 的安全状态以项目安全目标为准 【待核对】）。
  • 不满足：只有软件过流 → 短路时 MOS 在软件反应前损坏。

第四部分：嵌入式实现步骤

  1. 硬件通路：电流比较器阈值 > 软件阈值，接 PWM 模块故障输入，配置为自动关管且需软件清除。
  2. 中断级：软件过流、角度跳变、ADC 饱和、执行时间——只做比较与计数，复杂处理放慢任务。
  3. 慢任务：过温降额、欠压降额、堵转 I²t、失步判断。
  4. 故障管理：统一故障码、去抖、分级（警告 / 降额 / 关管 / 锁存）、记录冻结帧（故障时刻的电流、角度、Vdc、转速）。
  5. 关管处理：PWM 关闭同时 PI 积分器清零、弱磁积分清零、状态机进入 FAULT。

第五部分：仿真与波形预期

  • 故障注入：示波器测故障发生到 PWM 关闭的时间（硬件通路微秒级，软件通路若干个 PWM 周期）。
  • 降额：温度上升时 iqRef 上限按曲线平滑下降，无台阶。
  • 误报：全工况（低温、高速、电压波动、EMC）下无误报。

第六部分：EPS 案例实现

typedef struct { uint16_t cnt; uint16_t setN; uint16_t clrN; uint8_t active; } DIAG_DEB_tst;

static inline void Diag_Deb(DIAG_DEB_tst *d, uint8_t cond)
{
    if (cond) { if (d->cnt < d->setN) { d->cnt++; } else { d->active = 1u; } }
    else      { if (d->cnt > 0u) { d->cnt--; } if ((d->cnt == 0u) && (d->clrN != 0u)) { d->active = 0u; }   /* clrN = 0：锁存 */ }
}

/* 软件过流：直接比较 ADC 码值（相对零点），避免 Q15 基值饱和问题 */
#define OC_SW_CNT   (1966)    /* 48 A ÷ 0.024414 A/码 【案例假设】 */

void FOC_FastDiag_Isr(void)
{
    static DIAG_DEB_tst s_oc = { 0u, 3u, 0u, 0u };     /* 连续 3 周期，锁存（clrN = 0 表示不自动清除）*/
    int32_t da = (int32_t)gFoc.adcIa - Cal_IaOffset_cnt;
    int32_t db = (int32_t)gFoc.adcIb - Cal_IbOffset_cnt;
    int32_t dc = -da - db;
    uint8_t oc = (da > OC_SW_CNT) || (da < -OC_SW_CNT) ||
                 (db > OC_SW_CNT) || (db < -OC_SW_CNT) ||
                 (dc > OC_SW_CNT) || (dc < -OC_SW_CNT);
    Diag_Deb(&s_oc, oc);
    if (s_oc.active) { FOC_EmergencyOff(DIAG_OC_SW); }
}

void FOC_EmergencyOff(uint16_t code)
{
    Pwm_DisableAll();                 /* 先关管，再做其余处理 */
    FOC_PiResetAll();
    Diag_SetFault(code);
    Diag_FreezeFrame();               /* 冻结帧：ia ib thetaE vdc spd */
    gFoc.state = FOC_ST_FAULT;
}

量程设计提醒：案例中采样量程 ±50 A，而 C07 讨论的电流极限达 50~60 A，软件过流只能设在量程边缘（48 A），与工作电流几乎没有裕量；60 A 的硬件保护也必须走独立于 ADC 运放的通路，否则运放饱和后无法检测。量产设计应让采样量程 ≥ 最大保护阈值 × 1.2（例如 ±80 A），同时相应修改 I_BASE、每码 LSB 与全部标幺参数（X2 讨论）。软件过流阈值不能超过采样量程，否则诊断永远不会触发（B07 过压例子同理）。

第七部分：高频调试问题

【高频故障】偶发过流误报
现象
正常行驶中偶发 DIAG_OC_SW，无真实过流。
可能根因
采样尖刺（B06）、去抖次数太少、EMC 干扰。
排查
冻结帧数据；故障时刻占空比；EMC 试验复现。
修复
改善采样时刻；合理去抖（不超过 MOS 安全时间）。
验证
耐久与 EMC 试验零误报，故障注入仍能检出。
【高频故障】堵转保护过早触发，影响原地转向
现象
停车原地打满方向时助力很快衰减。
可能根因
EPS 原地转向本身就是低速大电流工况，堵转判据与热模型过于保守。
排查
比较热模型估计温度与实测。
修复
以热模型（I²t）为主而非简单计时；标定热参数。
验证
原地转向耐久试验温度在限值内且助力满足需求。
【高频故障】故障后重新使能瞬间过流
现象
故障恢复使能 PWM 时电流冲击。
可能根因
积分器未清零；电机仍在旋转（反电动势）时直接闭环。
排查
恢复时刻 vd、vq、转速。
修复
清零 + 按当前转速预置前馈电压（飞车启动）。
验证
旋转中恢复无冲击。

第八部分：工程踩坑

  • 阈值超出测量量程 / 定点基值：诊断永远不触发（本节代码与 B07 过压例子）。
  • 所有诊断放在中断：执行时间超标；按时间尺度分层。
  • 故障清除过于容易：间歇性故障反复触发，硬件累积损伤；关键故障锁存至下次上电。
  • 【风险红线】调试时屏蔽保护后忘记恢复：发布前检查所有诊断使能标定量。
