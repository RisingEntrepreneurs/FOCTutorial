D05 仿真：Simulink 模型搭建，从开环到闭环

模块 D · 嵌入式落地实战 · 第 5 节

第一部分：小节基础

链路位置开发流程：算法设计 → MIL → SIL → PIL → 台架
输入 / 输出输入：电机参数、控制算法；输出：仿真波形、参数初值、测试用例
工程价值上台架前发现方向、符号、单位、稳定性问题；为标定提供初值与对照基准
上下游依赖上游 B02、C 全部；下游 D06、E03
适用角色算法、模型开发
前置数学依赖A07、D01
① 为什么需要台架试错代价高（损坏硬件、占用资源）；仿真可以安全地尝试极端工况和故障。
② 量产怎么做分层模型：对象（电机 dq 模型 + 逆变器平均模型 + 机械）与控制器（离散、带延迟、可选定点）；按步骤从开环到闭环逐级验证；控制器子系统可代码生成或与手写代码 SIL 比对。
③ 如何证明仿真只证明到 L1/L2（导读证据等级）；必须与台架同工况曲线对比，记录差异来源（E03）。

第二部分：前置条件

  • 电机参数（含不确定范围）、逆变器参数（死区、压降）、采样与延迟时序。
  • MATLAB/Simulink 及相应工具箱（是否使用 Motor Control Blockset 等以项目授权为准 【待核对】）。
  • 不满足：连续域理想模型 → 仿真结果过于乐观（E03）。

第三部分：核心原理与公式

【理论公式】对象模型（dq，B02 / C05）： Ld·did/dt = vd − Rs·id + ωe·Lq·iq Lq·diq/dt = vq − Rs·iq − ωe·(Ld·id + ψf) J·dωm/dt = Te − TL − B·ωm，θe = ∫p·ωm dt 逆变器平均模型：v_actual = v_ref·(Vdc/Vdc_meas) − ΔV_deadtime·sign(i)（C13） 控制器：Ts = 50 µs 离散子系统，输入经 ZOH 采样，输出经 1 拍延迟（单采样单更新）+ ZOH（PWM 平均） 求解器：对象用变步长或小定步长（如 1 µs），控制器 50 µs 触发

【暂无可交互动画】模型搭建是工具操作流程；本页各章动画均为「简化 L0 模型」，D05 关注如何搭建更接近台架的 L1/L2 模型。

从开环到闭环的六步

2加 abc / αβ 变换 + SVPWM 平均 + 开环 V/f 或 I/F电机按设定方向旋转，三相电流正弦相序、Park 符号、方向约定

第四部分：嵌入式实现步骤（模型到代码）

  1. 控制器模型使用与代码相同的数据结构命名（gFoc 字段、Cal_ 参数），便于对照。
  2. 定点模型（若代码生成）：Fixed-Point Designer 设定 Q 格式；手写代码则用 MEX / S-Function 嵌入 C 代码做 SIL。
  3. PIL：在 S32K146 上运行控制器，模型提供对象，测量执行时间与数值一致性。
  4. 测试用例沉淀：阶跃、扫速、电压跌落、参数偏差 ±30%，作为回归测试集。

第五部分：仿真与波形预期

  • 步骤 2：iα–iβ 逆时针圆（正转）；dq 直流。
  • 步骤 4：加入延迟后，原来在理想模型中稳定的高带宽参数可能振荡——这正是需要的「提前暴露」。
  • 与台架对比时，叠加同工况实测曲线，差异按 E03 分类。

第七部分：高频调试问题

【高频故障】仿真完美，台架振荡
现象
仿真电流环阶跃无超调，台架严重振荡。
可能根因
模型无延迟 / 连续控制器；参数理想；无采样噪声。
排查
按步骤 4 补齐延迟与离散。
修复
模型补齐后重新设计参数。
验证
模型与台架阶跃超调一致（差异 < 几个百分点）。
【高频故障】仿真中电机反转
现象
给正 iq，仿真电机反转。
可能根因
模型中 Park 与控制器约定不一致、θe 积分方向、相序。
排查
步骤 2 开环检查方向。
修复
统一约定（导读第三节）。
验证
正 iq 正转。
易错点：仿真步长过大
现象
电流纹波、死区效应在仿真中看不到。
根因
对象步长 ≥ PWM 周期，平均模型不含开关细节。
排查
明确模型目标（平均 or 开关）。
修复
需要研究纹波 / 死区时用开关模型 + 小步长。
验证
与示波器纹波对比。

D06 台架上电流程：电机对齐、零位标定、开环拖动、切入闭环、无感切入

模块 D · 嵌入式落地实战 · 第 6 节

第一部分：小节基础

链路位置从「代码编译通过」到「电机闭环运行」的台架步骤
输入 / 输出输入：新硬件、新软件；输出：经逐项验证的闭环系统与基础标定（偏移、零位、方向）
工程价值按顺序逐项验证可以把问题限定在最小范围；跳步骤是炸管和浪费时间的主要原因
上下游依赖依赖 C01~C10；下游 D07
适用角色全部台架人员
前置数学依赖A06 相位累加器、B04 换向思想
① 为什么需要闭环系统中任何一个环节（采样、方向、角度、PWM）出错都会表现为「抖动 / 过流」，无法区分；必须先开环逐项验证。
② 量产怎么做固定 Checklist：限流电源 → 静态检查 → PWM 空载 → 偏移 → 开环 → 零位 → 电流闭环 → 外环 / 无感；每步有通过判据和记录。
③ 如何证明每一步的通过判据（波形、数值）记录在台架日志中。

第二部分：前置条件

  • 【风险红线】首次上电使用可限流的直流电源（如限流 5~10 A）而非电池；硬件过流保护已验证；急停可用。
  • 示波器（电流探头 ×2、差分电压探头）、CANape + XCP 连接、对拖台架（可选）。

第三部分：核心原理与公式

步骤操作通过判据失败常见原因
0 静态不接电机，上电电源电流正常；Vdc 采样正确；无故障码采样分压、ADC 配置
1 PWM 空载不接电机，输出固定 duty三相波形、死区、中心对齐、互补正确极性、死区配置
2 偏移接电机，PWM 关偏移在范围内，静止电流 < 0.1 AC01
3 对齐开环角度 0、id = 小电流（电流闭环 + 固定角度）转子转到固定位置并保持，电流稳定电流符号、增益
4 I/F 开环拖动固定 id/|i| 电流闭环、开环角度按频率斜坡平稳旋转，方向正确，iα–iβ 逆时针相序、Park 方向
5 角度对比I/F 运行时比较旋变 θe 与开环 θ两者斜率一致、方向一致（差值近似常数）极对数、方向、解码配置
6 零位d 轴对齐法或反电动势法重复性 < 0.5°C09
7 电流闭环旋变角度、小 iq（2~5 A）正 iq 正转，正反对称零位、方向
8 电流环验收阶跃、扫频A08/C05 指标参数
9 外环 / 弱磁 / 无感逐项开启各章判据C07/C08/C10
【理论公式】I/F 开环（电流闭环 + 开环角度）的稳定机理： 设电流矢量与转子 d 轴夹角为 γ（负载角），电磁转矩 Te = Kt·|i|·sin γ 对齐后起动 γ ≈ 0；开环角度前进 → γ 增大 → 转矩增大，自动平衡负载与加速转矩 γ < 90° 时具有自恢复能力；γ > 90° 后转矩随 γ 增大反而下降 → 失步 最大可带负载 TL,max = Kt·|i|；加速时还需克服 J·dω/dt 与摩擦 转子在平衡点附近为弱阻尼振荡（固有频率 ≈ √(p·Kt·|i|/J)），加速度过大会激发振荡越过 90°
动画在演示什么：I/F 启动：对齐后开环角度按加速度斜坡增加，转子在电磁转矩作用下跟随，负载角 γ 为电流矢量与转子 d 轴的夹角。上图转速（给定 / 实际），下图 γ。
拖动滑块：减小电流幅值或增大负载 / 加速度，γ 增大；超过 90° 后转子失步，实际转速崩溃——这就是 I/F 启动失败的物理过程。
正常：γ 稳定在 90° 以下（叠加衰减振荡）。异常：γ 越过 90° 后持续增大、转速下跌。

第四部分：嵌入式实现步骤

  1. 软件提供「台架模式」：开环角度源、固定电流给定、各步独立使能（XCP 标定量控制）。
  2. I/F：先在开环角度 0 对齐，随后电流闭环（PI 正常工作）+ 角度由相位累加器给出（A06），电流保持在开环 d 轴方向，频率按斜坡升高；电流幅值足以带动负载（如 20 A）。也有实现把电流放在开环 q 轴，此时转子会先超前 90° 再建立平衡，起动冲击更大。
  3. 切入闭环（I/F → 旋变或观测器）：角度差 |θsrc − θIF| 小于阈值并稳定 → 预置电流环积分器 → 切换角度源 → 电流给定从「全部在开环 q 轴」逐渐过渡到「由力矩需求决定」。
  4. 每步通过后，在台架日志记录关键数值与截图。

第五部分：仿真与波形预期

  • 步骤 3：转子转到固定位置，可能有小幅振荡后稳定。
  • 步骤 4：相电流幅值恒定、频率按斜坡增加；示波器上三相正弦相差 120°。
  • 步骤 5：θ旋变 − θIF 为近似常数（负载角 + 零位偏差），不随时间漂移。

第六部分：EPS 案例实现

/* I/F 开环拖动（台架模式），1 ms 更新频率斜坡，中断累加角度（A06）*/
volatile float Cal_IfCurr_A    = 20.0f;   /* 【案例假设】*/
volatile float Cal_IfAccel_Hz_s = 50.0f;  /* 电频率加速度 */
volatile float Cal_IfFreqMax_Hz = 40.0f;  /* 600 rpm 机械 */
static float s_ifFreq;

void Bench_IfDrag_1ms(void)
{
    s_ifFreq += Cal_IfAccel_Hz_s * 1.0e-3f;
    if (s_ifFreq > Cal_IfFreqMax_Hz) { s_ifFreq = Cal_IfFreqMax_Hz; }
    gBench.phInc = FOC_FreqToInc((uint32_t)(s_ifFreq * 1000.0f));          /* A06 */
    FOC_SetIdqRef(AMP_TO_Q15(Cal_IfCurr_A), 0);   /* 电流放在开环 d 轴（与对齐一致），转子以负载角 γ 滞后跟随 */
    gBench.angDiff = (int16_t)(uint16_t)(gFoc.thetaEFromRes - gFoc.thetaE); /* 步骤 5 对比 */
}

/* 切入旋变闭环：角度差稳定后切换 */
void Bench_SwitchToResolver_1ms(void)
{
    static uint16_t s_ok;
    s_ok = ((gBench.angDiff > -1820) && (gBench.angDiff < 1820)) ? (uint16_t)(s_ok + 1u) : 0u;  /* ±10° */
    if (s_ok > 200u) {
        FOC_CurrentLoop_Preset(gFoc.vd, gFoc.vq, 0, 0);  /* C05 */
        Angle_SelectSource(ANG_SRC_RESOLVER);
        gFoc.state = FOC_ST_RUN_TORQUE;
    }
}

切换判据中的角度差包含「负载角 + 零位误差」；零位已标定时，空载 I/F 下角度差应接近当前负载角。切换后电流矢量从「开环 d 轴方向」逐渐转到「由力矩需求决定的 dq 给定」，id、iq 均需斜坡过渡。

第八部分：工程踩坑

  • 【风险红线】首次直接用电池上电闭环：方向错误时正反馈，电流瞬间上千安级（取决于回路阻抗），可能损坏 MOS。
  • 跳过步骤 5 直接闭环：极对数 / 方向错误被掩盖为「抖动」。
  • 对齐方向：从静止对齐时转子可能转向反方向的 d 轴（N/S 对称），不影响电角度零位，但影响机械位置相关的标定。
  • 台架结束未恢复保护标定量（C12 踩坑）。
