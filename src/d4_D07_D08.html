D07 标定实战：电流环带宽、滤波、MTPA 表、弱磁表、观测器参数

模块 D · 嵌入式落地实战 · 第 7 节

第一部分：小节基础

链路位置软件冻结后、量产前：参数从「初值」变为「验证值」
输入 / 输出输入：仿真初值、台架测量；输出：标定数据集（HEX / DCM / CDFX 等，以项目流程为准）
工程价值同一套软件适配不同电机批次、不同整车需求，标定质量直接决定性能一致性
上下游依赖依赖 C05~C13、D06；输出给 D08 数据管理
适用角色标定工程师、算法
前置数学依赖A07 伯德图、A08 PI
① 为什么需要参数辨识有误差、电机有饱和与温度特性、整车对噪声与手感有主观要求——这些只能在台架和整车上收敛。
② 量产怎么做固定标定顺序（内环到外环）、每项有输入条件 / 方法 / 判据 / 记录；标定数据版本化管理。
③ 如何证明每个标定量对应的验收试验数据（阶跃、扫频、外特性、脉动频谱）；全温度 / 电压范围抽样复测。

第二部分：前置条件

  • D06 全部步骤通过；扭矩传感器、温箱 / 冷却控制、可编程电源（电压扫描）。
  • XCP 测量与标定连接稳定，DAQ 采样率满足（电流环相关信号建议按主中断事件采集）。

第三部分：核心原理与公式

顺序标定项方法判据
1偏移 / 增益 / 零位 / 延迟补偿 KcC01、C09、C03静止电流、正反对称、力矩常数平直
2死区补偿低速恒力矩，最小化 6 阶6 阶分量下降、小电流无噪声
3电流环 Kp/Ki（分电流区间）阶跃 + 扫频注入开环穿越 ≈ 1 kHz、相位裕度 ≥ 45°、闭环谐振峰 < 1 dB、超调 < 10%
4解耦前馈系数高速阶跃，最小化 id 扰动id 扰动 < 1~2 A
5MTPA 表电流角扫描同力矩电流最小
6弱磁 PI / Vtarget / 前馈表扫速 + 急加速 + 电压跌落无振荡、外特性达标
7速度 / 位置环、滤波阶跃、负载扰动超调、恢复时间
8观测器 / PLL与旋变对比各转速角度误差
9保护阈值、降额曲线故障注入、温升试验检出时间、零误报
【理论公式】扫频注入测闭环频响： iqRef = iq0 + a·sin(2πft)，f 从 50 Hz 扫到 3 kHz；每个频点记录稳态 iq 的幅值比与相位 幅值比 |T(jω)| = A_out/A_in，−3 dB 频率即闭环带宽；由于延迟，闭环 −3 dB 点通常高于开环穿越频率 ωc， 零极点对消设计中的「带宽 1 kHz」严格说指 ωc；开环特性可由 L = T/(1 − T) 推得，或在误差处注入直接测开环 注入幅值要小（如额定 5%）避免饱和；f 接近 PWM/10 以上时注意采样混叠与 DAQ 采样率
动画在演示什么：在 iq 给定上叠加小幅正弦，扫描频率，计算闭环幅频（点）并与设计（虚线）比较。被控对象为离散 RL + 1.5Ts 延迟，控制器 Kp 按「标定电感 L̂」设计。
拖动滑块：真实 Lq 与 L̂ 偏差（模拟饱和）：真实电感变小 → 实际带宽升高、谐振峰出现；Kp 缩放：观察带宽与峰值随 Kp 变化，观察开环穿越频率、相位裕度与谐振峰的变化，找出穿越 ≈ 1 kHz、相位裕度 ≥ 45°、峰值 < 1 dB 的组合。
正常：测量点贴近设计曲线。异常：出现谐振峰（相位裕度不足）。

第四部分：嵌入式实现步骤

  1. 软件提供扫频注入功能（台架模式）：注入频率、幅值、轴选择均为标定量；记录用 DAQ 或片上相关运算（每频点计算 sin/cos 相关得到幅值与相位，减少数据量）。
  2. 分电流区间的电流环参数：按 |iq| 查表 Kp（应对 Lq 饱和）。
  3. 每次标定修改：记录版本号、修改人、原因、验证数据（标定数据库）。
  4. 标定完成后执行「回归套件」：D05 测试用例在台架复测。

第五部分：仿真与波形预期

  • 扫频：低频幅值比 ≈ 0 dB，平坦区一直延续到 ωc 附近，−3 dB 点略高于 ωc（延迟所致），相位单调下降。
  • 若出现 > 3 dB 的峰值 → 相位裕度不足，降 Kp 或减小延迟。

第六部分：EPS 案例实现

/* 扫频注入 + 片上单频点相关分析（台架模式）*/
volatile float Cal_SweepFreq_Hz = 100.0f;
volatile float Cal_SweepAmp_A   = 1.5f;
static float s_ph, s_accIs, s_accIc, s_accRs, s_accRc; static uint32_t s_n;

void Bench_Sweep_Isr(void)     /* 主中断中调用（float，S32K146 FPU）*/
{
    float s = sinf(s_ph), c = cosf(s_ph);
    float ref = Cal_SweepAmp_A * s;
    gBench.iqInj_A = ref;                                 /* 叠加到 iqRef */
    float y = Q15_TO_AMP(gFoc.iq) - gBench.iq0_A;
    s_accRs += ref * s;  s_accRc += ref * c;              /* 输入相关 */
    s_accIs += y * s;    s_accIc += y * c;                /* 输出相关 */
    s_n++;
    s_ph += 6.2831853f * Cal_SweepFreq_Hz * 50e-6f;
    if (s_ph > 6.2831853f) { s_ph -= 6.2831853f; }
}
void Bench_SweepResult(float *magDb, float *phaseDeg)     /* 整数个周期后调用 */
{
    float gin = sqrtf(s_accRs * s_accRs + s_accRc * s_accRc);
    float gout = sqrtf(s_accIs * s_accIs + s_accIc * s_accIc);
    *magDb    = 20.0f * log10f(gout / gin);
    *phaseDeg = (atan2f(s_accIc, s_accIs) - atan2f(s_accRc, s_accRs)) * 57.2958f;
}

第七部分：高频调试问题

【高频故障】同一套标定在另一批电机上啸叫
现象
新批次电机电流环振荡。
可能根因
电感批次差异 / 磁钢差异；参数裕量不足。
排查
对新批次做参数辨识与扫频。
修复
标定时以最不利参数验证鲁棒性（相位裕度留足）。
验证
多批次抽样扫频合格。
【高频故障】扫频结果在高频段乱跳
现象
1.5 kHz 以上幅值 / 相位数据离散。
可能根因
DAQ 采样率不足（混叠）；注入幅值太小信噪比低；积分周期非整数。
排查
改用片上相关运算；整数周期积分。
修复
如上。
验证
重复测量一致。
【高频故障】标定数据回退
现象
已解决的问题在新版本软件中重现。
可能根因
软件升级时标定数据未迁移或被默认值覆盖。
排查
对比 HEX / 标定文件差异。
修复
标定数据版本管理与软件版本绑定；迁移脚本。
验证
回归套件通过。

第八部分：工程踩坑

  • 只在常温、12 V 下标定：低温 / 9 V / 16 V 下表现可能完全不同。
  • 在整车主观评价阶段修改底层电流环参数：会改变所有上层标定的基础；底层参数应在台架阶段冻结。
  • 多人同时修改同一标定集无记录。

D08 常用标定变量、观测信号与 XCP 信号列表

模块 D · 嵌入式落地实战 · 第 8 节（完整参数表模板见 X4）

第一部分：小节基础

链路位置调试与标定接口：软件与 CANape 之间的「合同」
输入 / 输出输入：代码变量、Q 格式；输出：A2L 描述（MEASUREMENT / CHARACTERISTIC / COMPU_METHOD）
工程价值测量信号选得好，问题定位快一个数量级；A2L 错误会导致标定写错值
上下游依赖依赖全部模块；服务 D06、D07、E 模块
适用角色标定工程师、软件
前置数学依赖A01 换算、D02 Q 格式
① 为什么需要XCP 是 FOC 调试的「示波器 + 万用表」：在不停机的情况下观察内部变量、在线修改参数。
② 量产怎么做A2L 由构建工具从 ELF 地址 + 变量描述自动生成；标定量放在独立内存段（支持页切换 / 参考页工作页）；DAQ 事件与任务周期对应。
③ 如何证明每个标定量写入后读回校验；物理值与仪表比对；A2L 与 ELF 版本一致性检查。

第二部分：前置条件

  • XCP on CAN（或 CAN FD）协议栈、DAQ 事件通道配置；CANape 工程。
  • 内存段规划：标定 RAM / Flash 段（参考页 / 工作页机制以协议栈与 MCU 能力为准 【待核对】）。
  • 不满足：手工维护 A2L 地址 → 每次编译地址变化即失效。

第四部分：嵌入式实现步骤

  1. 变量声明：测量量 volatile、全局非 static（或用链接器保留）、避免被优化；标定量放 .calib 段。
  2. 变量描述：在代码中以注释 / 宏标注格式与单位，由脚本提取生成 A2L（或使用工具链 A2L 生成器）。
  3. DAQ 事件：主中断事件（每 N 次一次）、1 ms、10 ms；主中断事件信号数量受执行时间限制（D03）。
  4. 发布前检查：A2L 与 ELF 匹配（地址、EPK 版本标识）。

第五部分：仿真与波形预期

  • CANape 中电流物理值与功率分析仪一致；角度显示 0~360°。
  • 主中断事件 DAQ 打开后，主中断执行时间增加量在预算内。

第六部分：EPS 案例实现

/* 标定段与测量变量声明（GCC 风格，段名以链接脚本为准）*/
#define CALIB  __attribute__((section(".calib")))

CALIB volatile int16_t  Cal_IdKp_q12   = 3619;   /* @a2l phys=raw*7.8125e-5 unit=V/A min=0 max=4 */
CALIB volatile int16_t  Cal_IqKp_q12   = 6032;   /* @a2l phys=raw*7.8125e-5 unit=V/A */
CALIB volatile uint16_t Cal_ThetaOffset = 0u;    /* @a2l phys=raw*0.0054932 unit=deg */

FOC_tst gFoc;                                    /* 测量：@a2l struct FOC_tst */

/* 片段示意：A2L CHARACTERISTIC（由脚本生成）
/begin CHARACTERISTIC Cal_IqKp_q12 "" VALUE 0x1FFF8010 RL_SWORD 0 CM_Kp_q12 0 4
/end CHARACTERISTIC
/begin COMPU_METHOD CM_Kp_q12 "" LINEAR "%8.5" "V/A" COEFFS_LINEAR 7.8125e-5 0
/end COMPU_METHOD
*/

地址 0x1FFF8010 仅为示意，实际由链接结果决定；A2L 关键字细节以 ASAM MCD-2 MC 标准与所用工具为准 【待核对】。

第七部分：高频调试问题

【高频故障】标定修改后不生效
现象
CANape 修改 Kp，行为不变。
可能根因
代码在初始化时把 Cal_ 复制到局部变量后不再读取；编译器优化（非 volatile）；在参考页而非工作页修改。
排查
查代码读取位置；读回地址内容。
修复
在使用处读取标定量（或提供刷新机制）；volatile；页切换配置。
验证
修改即生效。
【高频故障】CANape 显示乱码 / 数值错误
现象
新编译版本后部分信号显示异常。
可能根因
A2L 未随 ELF 更新，地址错位。
排查
EPK 检查。
修复
构建流程自动生成 A2L。
验证
EPK 一致。
【高频故障】DAQ 丢帧
现象
高速记录时数据有缺口。
可能根因
CAN 带宽不足（信号太多 / 频率太高）。
排查
计算带宽：信号字节 × 事件频率 vs 总线容量。
修复
降频、减少信号、使用 CAN FD 或片上缓存后上传。
验证
无丢帧。

第八部分：工程踩坑

  • Q 格式变更（如 Kp 从 Q15 改 Q12）未同步 A2L（A08 高频故障）。
