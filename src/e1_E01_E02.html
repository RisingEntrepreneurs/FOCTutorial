第二部分：前置条件

  • D08 的标准测量信号组可用；能计算电频率 fe = p·n/60 与机械频率 fm = n/60。
  • 能做对比实验：开 / 关某功能、改变转速 / 电流 / 温度 / 电压。

第三部分：核心原理与公式

【理论公式】阶次判别（最有效的定位工具）： 测得脉动 / 纹波频率 fr，计算 kₑ = fr/fe（电阶次）、kₘ = fr/fm = kₑ·p（机械阶次） kₑ = 1：电流偏移；kₑ = 2：两相增益不一致 / 负序 / Park 方向；kₑ = 6：死区、反电动势 5/7 次谐波 kₘ 与旋变极对数相关（1 对极旋变：kₘ = 1、2）：旋变偏置 / 不平衡；kₘ 与极槽配合相关：齿槽转矩 与转速无关的固定频率：控制环振荡（电流环 ~ 数百 Hz~kHz、速度环 ~ 数十 Hz、弱磁环）、机械谐振 工况相关性：随温度 → 偏移温漂 / ψf / Rs；随电压 → 限幅 / 弱磁 / 死区补偿；随电流 → 饱和 / 采样窗口
动画在演示什么：模拟 iq（或力矩）频谱：勾选若干故障源，按当前转速计算各自频率并叠加。频谱下方标出 1×、2×、6× 电频率与机械阶次刻度。
拖动滑块：改变转速，与转速成比例的谱线随之移动，而电流环振荡、机械谐振等固定频率谱线不动——这就是区分「阶次类」与「环路 / 结构类」问题的方法。
使用：台架上测到的频谱，可用同样的方式标阶次后对照下表定位。

第四部分：嵌入式实现步骤（支持定位的软件功能）

  1. 冻结帧：故障时保存前后若干周期的 id/iq/vd/vq/θ/Vdc/转速（环形缓冲）。

  4. 运行统计：最大电流、最大 |v|、最大中断执行时间、故障计数。

/* 阶次计算辅助（1 ms 任务，供 CANape 显示）*/
void Diag_OrderHelper_1ms(void)
{
    float n  = (float)gFoc.spdRpmFilt;
    gDbg.fe_Hz  = (float)FOC_POLE_PAIRS * n / 60.0f;     /* 1 阶电频率 */
    gDbg.f2e_Hz = 2.0f * gDbg.fe_Hz;
    gDbg.f6e_Hz = 6.0f * gDbg.fe_Hz;
    gDbg.fm_Hz  = n / 60.0f;                             /* 1 阶机械频率 */
}

/* 冻结帧环形缓冲：主中断写入，故障时停止 */
#define FF_N (64u)
typedef struct { q15_t id, iq, vd, vq; uint16_t th; q15_t vdc; } FF_tst;
static FF_tst s_ff[FF_N]; static uint8_t s_ffIdx; static uint8_t s_ffFreeze;
void Diag_FreezeLog_Isr(void)
{
    if (s_ffFreeze == 0u) {
        FF_tst *e = &s_ff[s_ffIdx];
        e->id = gFoc.id; e->iq = gFoc.iq; e->vd = gFoc.vd; e->vq = gFoc.vq;
        e->th = gFoc.thetaE; e->vdc = gFoc.vdcPu;
        s_ffIdx = (uint8_t)((s_ffIdx + 1u) % FF_N);
    }
}
void Diag_FreezeFrame(void) { s_ffFreeze = 1u; }   /* C12 中调用 */

第七部分：高频调试问题（跨模块综合案例）

【高频故障】「抖」——同一个字，三种根因
现象
驾驶员反馈方向盘「抖」。
可能根因
① 固定频率 ~800 Hz：电流环振荡；② 随转速变化 6×fe：死区；③ 约 20 Hz 固定：速度 / 上层控制或机械谐振。
排查顺序
先测频率 → 判断是否随转速变化 → 按表定位。
修复
按对应章节处理。
验证
对应谱线下降。
【高频故障】只在高温 + 低压 + 高速同时出现的问题
现象
单独工况都正常，组合工况失步。
可能根因
ψf 下降 + 可用电压下降 + 弱磁裕量不足叠加；或 Rs 增大使观测器偏差。
排查
做工况矩阵（温度 × 电压 × 转速），记录 |v| 裕量。
修复
弱磁电压闭环 + Vdc 实时；参数温度修正。
验证
工况矩阵全通过。
【高频故障】修复一个问题引出另一个
现象
加死区补偿后小电流噪声变大（C13）；降 Kp 消除啸叫后低压超调变大。
可能根因
修复只针对单一工况验证。
排查
每次修改后跑回归套件（D07）。
修复
建立工况覆盖的验证矩阵。
验证
回归全部通过。

第八部分：工程踩坑

  • 只用耳朵和手感描述问题，不测频率：无法定位。
  • 一次改多个参数：无法知道哪个起作用。
  • 用标定「掩盖」硬件或零位问题（如正反转不同增益）：换一台就复现。

E02 示波器抓取要点：相电流、αβ、dq、SVPWM、角度误差

模块 E · 故障与调试实战 · 第 2 节

第一部分：小节基础

链路位置测量手段：硬件信号（示波器）+ 软件内部量（XCP / DAC 输出）
输入 / 输出输入：探头、触发设置；输出：可解释的波形证据
工程价值XCP 看不到 PWM 开关细节与采样时刻，示波器看不到 dq 内部量——两者必须结合
上下游依赖服务 E01、E04、D06
适用角色台架工程师
前置数学依赖B06 时序、A03 频率
① 为什么需要很多问题（采样时刻、死区、窄脉冲、振铃）只在纳秒~微秒尺度可见。
② 量产怎么做固定测点清单与示波器设置模板；内部量通过 DAC / PWM 调试输出或 XCP DAQ 与示波器时间对齐。
③ 如何证明截图附带设置（时基、触发、探头衰减、带宽限制），可复现。

第二部分：前置条件

  • 电流探头（带宽、量程满足 50 A 级与开关纹波）、高压 / 差分电压探头、隔离或差分测量（避免地环路短路）。
  • 【风险红线】普通无源探头的地夹接到相线或高边会短路：测相电压用差分探头。

第三部分：核心原理与公式

测什么测点 / 来源示波器设置看什么
相电流电流探头卡相线（两相或三相）时基覆盖 2~5 个电周期；带宽限制按需正弦度、幅值、过零平台（死区）、削顶（饱和）
采样时刻ADC 触发 GPIO / PDB 输出 + 下管栅极单个 PWM 周期，触发在 PWM 中心采样点是否在低边导通窗口中部、远离振铃
中断执行中断入口 / 出口 GPIO余辉 / 无限持续，统计最大宽度WCET、抖动
相电压 / PWM差分探头测相对负母线单周期 + 长时基死区、窄脉冲、马鞍波（滤波后）
母线电压差分探头AC 耦合看纹波，DC 看跌落大电流纹波、负载突变跌落、关管回馈过压
αβ / dq / 角度误差XCP DAQ，或 DAC 输出XY 模式（iα–iβ）圆度、圆心、旋转方向；dq 纹波阶次
反电动势对拖时 PWM 关，差分测线电压与 θe 同屏（DAC）零位、谐波、ψf

【暂无可交互动画】采样时刻相关的动态演示见 B06 动画；XY 判据见 B03 动画。

【理论公式】DAC / PWM 调试输出：将内部变量（如 iq 或 θe）按 Q15 映射到 DAC 0~3.3 V v_dac = 1.65 V + x_q15/32768 × 1.65 V；带宽受 DAC 更新率（主中断）限制 频谱分析：FFT 长度 N、采样率 fs → 分辨率 fs/N；分析阶次需整周期截取或加窗

第四部分：嵌入式实现步骤

  1. 预留调试 GPIO（中断入口出口、ADC 触发、故障）。
  2. 预留 DAC 或 PWM+RC 调试输出通道，可通过标定量选择输出变量（id、iq、θe、角度误差）。
  3. 示波器设置模板化（保存为 setup 文件），截图命名规则：日期_工况_信号。

第五部分：仿真与波形预期

  • 正常：相电流正弦、iα–iβ 圆、dq 直线（低纹波）、ADC 触发在 PWM 中心。
  • 每种异常波形与 E01 表格对应。

第六部分：EPS 案例实现

/* 调试 DAC 输出：标定量选择变量（若 MCU 无 DAC，可用 PWM + RC 滤波替代）*/
volatile uint8_t Cal_DbgDacSel = 0u;   /* 0:iq 1:id 2:thetaE 3:obs 角度误差 */
void Dbg_DacOut_Isr(void)
{
    int32_t x;
    switch (Cal_DbgDacSel) {
    case 0:  x = gFoc.iq; break;
    case 1:  x = gFoc.id; break;
    case 2:  x = (int32_t)gFoc.thetaE - 32768; break;
    default: x = (int16_t)(uint16_t)(gFoc.thetaEObs - gFoc.thetaE) * 8; break;   /* 放大 8 倍 */
    }
    Dac_Write12((uint16_t)(2048 + (x >> 4)));     /* Q15 → 12 位，中心 2048 */
}

可能根因
地夹接在非地电位（相线 / 高边），通过示波器地短路。

修复

【高频故障】示波器电流与 XCP 电流对不上
现象
幅值相同但相位差明显，或 XCP 波形「锯齿」。
可能根因
DAQ 降采样 / 时间戳；电流探头延迟；Clarke 系数。

用 DAC 输出与探头同屏比较。
修复
按需提高 DAQ 频率；校正延迟。
验证
同屏一致。
【高频故障】频谱阶次判断错误
现象
根据频谱判断为 6 阶，修死区无效。
可能根因

排查
恒速、整周期截取；同时计算 fe 与 fm。
修复
重新判定阶次。
验证
对比实验确认。
