E03 仿真 vs 台架差异来源

模块 E · 故障与调试实战 · 第 3 节（证据等级体系见 X3）

第一部分：小节基础

链路位置模型可信度评估：解释「仿真好、台架差」
输入 / 输出输入：同工况仿真与实测曲线；输出：差异归因与模型修正
工程价值知道差异来源，才能决定是修模型、修参数还是修代码
上下游依赖D05、X3
适用角色算法、模型
前置数学依赖A07、D01
① 为什么需要仿真是设计工具；若不理解它与现实的差距，就会把仿真结果误当成产品性能。
② 量产怎么做逐项补齐非理想因素，并对每个补齐项用台架数据校验；剩余差异记录在案。
③ 如何证明同工况叠加对比：阶跃、扫频、外特性、脉动频谱的差异在约定容差内。

第二部分：前置条件

  • 仿真与台架工况严格一致（Vdc、温度、转速、负载、参数版本、软件版本）。

第三部分：核心原理与公式

差异来源仿真常见简化台架表现如何补齐 / 校验
控制延迟连续控制器、零延迟相位裕度下降、振荡离散 + 1 拍延迟 + ZOH（B06）
参数常数 Ld、Lq、ψf、Rs饱和、温度变化实测查表（C11）
逆变器理想平均电压死区、压降、6 阶纹波平均模型加死区（C13）
采样理想无噪声噪声、偏移、增益、量化注入噪声与误差
角度理想角度零位误差、解码谐波、跟踪滞后角度误差模型（C09）
数值double 浮点Q 格式截断、溢出定点模型 / SIL（D02）
电源理想恒压内阻、跌落、纹波电源内阻模型
机械刚性单惯量谐振、间隙、摩擦双惯量 / 摩擦模型
时序无执行时间中断抖动、超时PIL 测量

【暂无可交互动画】各差异项的动态效果分别在 A07（延迟相位）、A08（延迟振荡）、C13（死区）、D02（定点）、D07（参数偏差）动画中演示。

第四部分：嵌入式实现步骤（建立「对比闭环」）

  1. 台架记录文件与仿真输入格式统一（时间、给定、工况）。
  2. 用台架实测给定作为仿真输入，输出叠加对比。
  3. 差异超出容差时，按上表从「延迟 → 参数 → 逆变器 → 采样 → 角度」顺序补齐。

第五部分：仿真与波形预期

  • 补齐延迟后，电流环阶跃超调应接近台架；补齐死区后，低速 6 阶纹波应出现。

第七部分：高频调试问题

【高频故障】仿真外特性比台架高 20%
现象
仿真最高转速与弱磁区力矩明显高于实测。
可能根因
仿真 Vdc 理想、无电源内阻；未计 Rs 压降与死区；电压裕量系数不同。
排查
对比同点 |v| 与 Vdc。
修复
模型加电源内阻、死区、实际 Vmax 系数。
验证
外特性差异 < 5%。
【高频故障】台架力矩脉动仿真中看不到
现象
台架低速 6 阶脉动，仿真平滑。
可能根因
模型无死区、无反电动势谐波、无齿槽。
排查
逐项加入。
修复
补齐后用于评估补偿算法。
验证
频谱阶次对应。
【高频故障】观测器仿真收敛、台架低速发散
现象
无感在仿真中 50 rpm 可用，台架 300 rpm 都不稳。
可能根因
仿真用实际电压而非给定电压、无死区、无采样噪声、参数理想。
排查
仿真中改用给定电压 + 死区 + 噪声。
修复
重新评估最低可用转速。
验证
仿真与台架最低转速一致。

第八部分：工程踩坑

  • 为了让仿真「对上」台架而随意调整模型参数（过拟合），失去预测能力。
  • 仿真软件版本、参数版本与台架软件版本不对应。

E04 定位流程：采样 → 角度 → 变换 → PID → SVPWM → 观测器

模块 E · 故障与调试实战 · 第 4 节

第一部分：小节基础

链路位置系统化排查顺序：沿数据流从上游到下游
输入 / 输出输入：异常现象；输出：定位到具体环节
工程价值上游错误会在下游被放大和变形；按数据流顺序检查，每一步都有明确的通过判据
上下游依赖汇总 C 模块；配合 E01、E02、X1
适用角色全部
前置数学依赖—
① 为什么需要电流环振荡可能是采样尖刺、角度噪声、参数、SVPWM 窗口任一环节导致；从下游调参通常是错误方向。
② 量产怎么做标准化 6 步检查表，每步 1~3 个判据信号，台架可在 30 分钟内完成一轮。
③ 如何证明每步检查结果记录，定位结论有对比实验支撑。

第二部分：前置条件

  • D08 测量信号、E02 示波器测点、功能开关标定量（E01）。

第三部分：核心原理与公式

步骤检查项通过判据常用对比实验
① 采样静止偏移、ADC 原始码、示波器采样点、三相和静止 < 0.1 A；采样在窗口中部；无饱和PWM 关 / 开；不同占空比
② 角度θe 方向与锯齿数、零位、Δθ 平滑度、解码故障位每机械圈 p 个锯齿；正反对称；无跳变I/F 下对比开环角
③ 变换iα–iβ XY、dq 纹波阶次圆、逆时针（正转）、dq 直流开环拖动观察
④ PID阶跃、扫频、积分器、vSat超调 < 10%，相位裕度 ≥ 45°关前馈 / Kp 减半
⑤ SVPWMduty 马鞍波、上下限、死区补偿线性区内、窗口充足、6 阶小开 / 关死区补偿
⑥ 观测器θobs − θres 误差、PLL 速度、切换误差满足指标、切换平滑改变 PLL 带宽、参数 ±20%

【暂无可交互动画】端到端数据流的交互动画见 X1；本节为排查流程。

  2. 输出检查报告：每步通过 / 不通过 + 截图 + 数值。

第五部分：仿真与波形预期

第六部分：EPS 案例实现

# 【伪代码 / Python】台架自动检查脚本骨架（XCP 访问库与接口以所用工具为准）
def step1_sampling(xcp):
    xcp.write('Cal_BenchPwmOff', 1); time.sleep(0.5)
    ia = xcp.read_avg('gFoc.ia', n=200) * 50 / 32768
    ib = xcp.read_avg('gFoc.ib', n=200) * 50 / 32768
    return abs(ia) < 0.1 and abs(ib) < 0.1, {'ia': ia, 'ib': ib}

def step2_angle(xcp):
    xcp.write('Cal_BenchMode', IF_DRAG); time.sleep(2.0)
    d = xcp.read_series('gBench.angDiff', seconds=1.0)
    drift = (d[-1] - d[0]) * 360 / 65536
    return abs(drift) < 5, {'drift_deg': drift}

for name, fn in [('采样', step1_sampling), ('角度', step2_angle)]:   # … 依次 6 步
    ok, data = fn(xcp)
    report.add(name, ok, data)
    if not ok:
        break                                                         # 不通过即停止，不进入下游

第七部分：高频调试问题

【高频故障】新样件「电流环振荡」
现象
新硬件版本上电流环振荡，老版本正常。
可能根因
按流程：①采样 RC 改变（相位）/ 增益改变 → 实际 Kp 改变。
排查
步骤 ① 发现增益比老版本大 30%（采样电阻改值）。
修复
更新采样换算与增益标定。
验证
步骤 ④ 阶跃合格。
【高频故障】软件升级后正反转不对称
现象
新软件反转力矩下降。
可能根因
步骤 ②：延迟补偿取了绝对值（C03）或零位标定量被默认值覆盖（D07）。
排查
对比标定数据与代码差异。
修复
修正。
验证
正反对称。
【高频故障】调了三天 PI 仍振荡
现象
反复调电流环参数无效。
可能根因
跳过 ①②③ 直接在 ④ 调参；实际是采样尖刺。
排查
回到步骤 ①。
修复
修正采样时刻。
验证
默认参数即稳定。

  • 并行修改多个环节，结论不可追溯。
