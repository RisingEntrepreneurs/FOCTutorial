F01 FOC vs DTC：控制结构、开关频率与工程取舍

模块 F · 拓展对比 · 第 1 节（选型概述见 B01）

第一部分：小节基础

链路位置控制方案层面的对比
输入 / 输出输入：应用需求；输出：方案选择依据
工程价值理解 DTC 的优点（结构简单、动态快、参数依赖少）与代价（脉动、开关频率不定、采样要求高），面试与方案评审常见
上下游依赖B01、C04、C05
适用角色算法、系统
前置数学依赖A04 磁链矢量、A06 积分
① 为什么需要DTC 是工业界（尤其大功率变频器）的重要流派；知道它与 FOC 的差别，才能理解为何车载 EPS / 电驱主流选择 FOC。
② 量产怎么做车载低压 EPS 与主驱普遍采用 FOC + SVPWM；DTC 及其改进形式（如 DTC-SVM，以固定开关频率输出）多见于工业驱动 【待核对：具体应用分布以行业资料为准】。
③ 如何证明同电机同工况对比：力矩脉动、电流 THD、噪声频谱、动态响应时间、低速性能。

第二部分：前置条件

  • 理解定子磁链 ψs = ∫(v − Rs·i)dt（A06）和电磁转矩 Te = 1.5·p·(ψα·iβ − ψβ·iα)。

第三部分：核心原理与公式

【理论公式】经典 DTC（来源：Takahashi / Depenbrock 提出的直接转矩控制经典结构）： 估计 ψs（电压模型积分）与 Te → 与给定比较 → 磁链滞环（2 级）、转矩滞环（3 级） 根据磁链所在扇区 + 两个滞环输出查开关表，直接选择一个电压矢量（V0~V7） 特点：无电流环、无坐标旋转、无 PWM 调制器；采样频率需很高（数十 kHz），开关频率随工况变化 FOC：电流环 + SVPWM，固定开关频率，转矩通过 iq 间接控制 DTC-SVM：用预测 / PI 计算所需电压矢量，经 SVM 输出，恢复固定开关频率
维度FOC经典 DTC
控制量id、iq（经电流环）|ψs|、Te（滞环）
坐标旋转需要 Park，依赖准确角度不需要转子角度（定子磁链扇区即可）
开关频率固定变化，频谱分散
转矩脉动小较大，取决于滞环宽度与采样频率
动态响应受电流环带宽限制很快（直接选矢量）
参数依赖L、ψf（解耦、MTPA、弱磁）主要 Rs（磁链积分），低速敏感
低速 / 零速有传感器时满力矩磁链估计困难
EMC / 噪声频谱集中，可设计宽频，难预测
动画在演示什么：同一转矩阶跃下，FOC（电流环 + 固定频率 PWM，用平均模型表示）与经典 DTC（转矩滞环 + 离散采样）的转矩波形对比。
拖动滑块：DTC 滞环宽度越小、采样频率越高，脉动越小，但开关次数增加；FOC 电流环带宽决定响应速度。
观察：DTC 上升更快但稳态脉动大；FOC 稳态平滑。（教学简化模型，仅示意趋势）

第四部分：嵌入式实现步骤（DTC 结构示意）

  1. 高频采样（如 40~80 kHz）电流与 Vdc。
  2. 电压模型磁链积分（需漂移抑制，A06）。
  3. 转矩估计与滞环比较。
  4. 扇区判断 + 开关表 → 直接写入开关状态。

第五部分：仿真与波形预期

  • DTC 相电流纹波大且不规则；FOC 相电流纹波规则（PWM 频率）。

第六部分：EPS 案例实现

/* 【伪代码】经典 DTC 开关表核心（教学对照，不用于本 EPS 项目）*/
static const uint8_t c_DtcTable[2][3][6] = { /* [磁链增减][转矩增/保持/减][扇区] → 电压矢量编号 */
    { {2,3,4,5,6,1}, {7,0,7,0,7,0}, {6,1,2,3,4,5} },   /* 磁链增 */
    { {3,4,5,6,1,2}, {0,7,0,7,0,7}, {5,6,1,2,3,4} }    /* 磁链减 */
};
void Dtc_Step(float psiErr, float teErr, uint8_t sector)
{
    uint8_t f = (psiErr > 0.0f) ? 0u : 1u;                               /* 2 级磁链滞环（省略滞环宽度）*/
    uint8_t t = (teErr > TE_BAND) ? 0u : ((teErr < -TE_BAND) ? 2u : 1u);  /* 3 级转矩滞环 */
    Inv_ApplyVector(c_DtcTable[f][t][sector]);
}

开关表编号约定在不同文献中不同，此处仅示意结构 【待核对：以所引用文献的扇区与矢量编号为准】。

F02 有传感 FOC vs 无感 FOC

模块 F · 拓展对比 · 第 2 节（原理见 C09、C10）

第一部分：小节基础

链路位置角度来源选择
输入 / 输出输入：成本、性能、安全需求；输出：传感器方案与降级策略
工程价值EPS：有感为主、无感为辅（降级 / 交叉校验）；风机水泵：无感为主
上下游依赖C09、C10、C12
适用角色系统、算法
前置数学依赖—
① 为什么需要传感器影响成本、可靠性与性能；无感在零低速存在原理性限制。
② 量产怎么做按应用的零速力矩需求决定：需要零速满力矩（EPS、伺服）→ 有感；只需中高速（风机、泵、压缩机）→ 无感 + 开环启动。
③ 如何证明全转速范围的角度误差、启动成功率、负载突变鲁棒性、故障降级试验。

第二部分：前置条件

  • C09、C10 内容。

第三部分：核心原理与公式

维度有感（旋变 / 编码器）无感（反电动势类）无感（高频注入）
零速力矩满力矩不可用（需开环启动）可用（需凸极）
低速精度高差中，有注入噪声
高速精度高（需延迟补偿）较好（需相位补偿）一般切换到反电动势法
参数依赖低高（Rs、L）中（凸极比）
成本 / 可靠性传感器 + 线束 + 解码无额外硬件无额外硬件，算力要求高
噪声——注入引起可闻噪声
功能安全需传感器诊断可作为交叉校验 / 降级同左

【暂无可交互动画】观测器动态见 C10 动画。

第四部分：嵌入式实现步骤（EPS 混合方案）

  1. 旋变为主角度源；无感观测器后台持续运行。
  2. 运行中比较两者角度差（C12 失步 / 角度诊断）。
  3. 旋变故障：转速高于阈值 → 切换无感并限制助力；低于阈值 → 按安全设计进入降级 / 安全状态。

第五部分：仿真与波形预期

  • 两角度源差值在正常工况下保持在小范围内；故障注入（断开旋变信号）时检测并切换。

第六部分：EPS 案例实现

/* 角度源交叉校验与选择（1 ms）*/
static DIAG_DEB_tst s_angMismatch = { 0u, 10u, 0u, 0u };   /* 10 ms 去抖，锁存（C12）*/
void Angle_Arbitrate_1ms(void)
{
    int16_t diff = (int16_t)(uint16_t)(gFoc.thetaEObs - gFoc.thetaEFromRes);
    uint8_t obsOk = (labs(gFoc.spdRpmFilt) > Cal_ObsMinRpm);
    uint8_t mismatch = obsOk && ((diff > 5461) || (diff < -5461));          /* ±30° */
    Diag_Deb(&s_angMismatch, mismatch);
    if (Res_HwFault() || s_angMismatch.active) {
        if (obsOk) { Angle_SelectSource(ANG_SRC_OBS); Derate_SetTorqueLimit(Cal_SensorlessTqLim); }
        else       { FOC_EmergencyOff(DIAG_ANGLE_LOST); }
    }
}

F03 SPMSM 和 IPMSM 在算法上的差异

模块 F · 拓展对比 · 第 3 节（本教程案例为 IPMSM；切换为 SPMSM 的改动点在此汇总）

第一部分：小节基础

链路位置电机类型对算法各模块的影响
输入 / 输出输入：Ld、Lq 关系；输出：各模块改动清单
工程价值同一软件平台适配两类电机时，明确哪些模块要改
上下游依赖B02、C05、C06、C07、C10、C11
适用角色算法
前置数学依赖B02 转矩公式
① 为什么需要凸极性（Ld ≠ Lq）决定是否有磁阻转矩、能否高频注入、弱磁能力与观测器模型。
② 量产怎么做平台软件以 IPMSM 通用形式实现，SPMSM 时令 Ld = Lq 自动退化；MTPA 表变为 id = 0。
③ 如何证明按改动清单逐项验证。

第二部分：前置条件

  • 实测 Ld、Lq（C11）。

第三部分：核心原理与公式

模块SPMSM（Ld ≈ Lq）IPMSM（Ld < Lq）
转矩Te = 1.5·p·ψf·iqTe = 1.5·p·[ψf·iq + (Ld − Lq)·id·iq]
MTPAid = 0id < 0，查表 / 公式（C06）
电流环d、q 参数相同d、q 参数不同（Kp 按各自电感）
弱磁能力取决于 ψf/Ls 与 Imax；通常弱磁能力较弱磁阻转矩帮助弱磁区出力，弱磁能力通常更强
无感（反电动势类）标准反电动势模型需扩展反电动势（EEMF）模型
无感（高频注入）无凸极，难以使用可用
参数辨识只需 Ls需 Ld、Lq 及饱和曲线
电感饱和较弱Lq 饱和明显

【暂无可交互动画】凸极比对转矩 / MTPA 的影响可直接在 B02 与 C06 动画中把 Lq 拖到等于 Ld 观察。

第四部分：嵌入式实现步骤（切换为 SPMSM 的改动清单）

  1. 参数：Cal_Ld = Cal_Lq = Ls；前馈系数 kLd = kLq。
  2. MTPA 表全部置 0。
  3. 电流环 d、q 参数相同。
  4. 观测器使用标准模型（EEMF 自动退化）。
  5. 重新评估弱磁深度与最高转速。

第五部分：仿真与波形预期

  • SPMSM：电流角扫描时最大转矩在 β = 90°。

第六部分：EPS 案例实现

/* 通用实现，SPMSM 时自动退化 */
float FOC_TorqueEst_Generic(float id_A, float iq_A)
{
    float psi = Cal_PsiF_mWb * 1e-3f;
    float dL  = (Cal_Ld_uH - Cal_Lq_uH) * 1e-6f;   /* SPMSM: dL = 0 → 磁阻项消失 */
    return 1.5f * FOC_POLE_PAIRS * (psi * iq_A + dL * id_A * iq_A);
}
