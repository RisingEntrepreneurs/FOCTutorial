① 为什么需要在 s 域中微分变乘 s、积分变除 s，微分方程变成代数式，才能用「零极点对消」直接算出 PI 参数。
② 量产怎么做台架用电压阶跃测 τ 得 L；按目标带宽算 Kp、Ki；用扫频注入测闭环伯德图验收。
③ 如何证明阶跃 63.2% 时刻 = τ；闭环 −3 dB 频率 ≈ 设计带宽；相位裕度满足要求。

第二部分：前置条件

  • 前置数学：A05 导数、A06 积分、A04 中 j 的含义。
  • 只需掌握对应关系：d/dt ↔ s；∫dt ↔ 1/s；正弦稳态 s = jω。
  • 不满足：无法理解带宽、相位裕度；调参只能凭经验。

第三部分：核心原理与公式

【理论公式】 RL 电路：v = R·i + L·di/dt →（零初值拉氏变换）V(s) = (R + L·s)·I(s) 传递函数：G(s) = I(s)/V(s) = 1/(L·s + R) = (1/R) / (τ·s + 1)，τ = L/R 阶跃响应：i(t) = (V/R)·(1 − e^(−t/τ))；t = τ 时 63.2%，t = 3τ 时 95%，5τ 时 99.3% 频率响应：|G(jω)| = 1/√(R² + (ωL)²)，∠G = −arctan(ωL/R)；转折频率 fc = R/(2πL) 闭环：T(s) = C(s)G(s) / (1 + C(s)G(s))；带宽 ≈ |T| 下降 3 dB 的频率 纯延迟 e^(−s·Td)：幅值不变，相位滞后 ω·Td（弧度） 案例：τd = 45 µH/12 mΩ = 3.75 ms，fc,d = 42.4 Hz；τq = 6.25 ms 【案例假设】 Td ≈ 1.5Ts = 75 µs → 1 kHz 处滞后 360°×1000×75e-6 = 27°
动画在演示什么：左（上）图：给 d 轴电感加电压阶跃时的电流响应，标出 τ 和 63.2%；右（下）图：同一对象的伯德图（幅值 dB、相位）。
拖动滑块：增大 L → τ 变大、响应变慢、转折频率左移；增大 R → 终值变小、响应变快。勾选「叠加 1.5Ts 延迟」，相位在高频急剧下跌——这就是电流环带宽不能无限提高的原因。
正常：一阶曲线无超调，相位从 0° 平滑趋向 −90°。注意：这是理想 RL 模型（L0 证据），实测存在逆变器死区和磁饱和，台架曲线会偏离。

第四部分：嵌入式实现步骤

  1. 传递函数不能直接写进 MCU：s 需离散化为 z 域差分方程（D01），例如低通 1/(τs+1) → A05 的 α 公式。
  2. 台架电压阶跃法测 L（标定模式，【台架重点】）：转子锁定在 d 轴（先注入 id 对齐），在 d 轴施加小电压阶跃，记录 id，读 63.2% 时刻得 τ，由终值得 R = V/i∞，L = τ·R。
  3. 扫频验收：在 iq 给定叠加小幅正弦，扫 50 Hz ~ 3 kHz，记录幅值比与相位，得到闭环伯德图。
  4. 结果写入标定表 Cal_Ld_uH、Cal_Lq_uH、Cal_Rs_mOhm（C11 参数辨识细化）。

第五部分：仿真与波形预期

  • 理想阶跃：一阶指数，无超调。
  • 实测阶跃若开头有「台阶」或延迟：采样与 PWM 更新延迟、死区；若 τ 随电流幅值变化：电感饱和（Lq 随 iq 增大下降，IPMSM 常见）。

第六部分：EPS 案例实现

/* 【伪代码】台架电压阶跃法辨识 Ld（标定模式下 1 kHz 后台处理，数据由 PWM 中断采集）*/
#define STEP_N   (400u)              /* 400 × 50 µs = 20 ms ≥ 5τ */
static q15_t s_idBuf[STEP_N];        /* PWM 中断中逐点写入 gFoc.id */

void Ident_Ld_Process(float vStep_V)
{
    float iInf = Q15ToAmp(average(&s_idBuf[STEP_N - 40u], 40u));   /* 取末尾均值作为终值 */
    float i632 = 0.632f * iInf;
    uint16_t k = first_index_ge(s_idBuf, STEP_N, AmpToQ15(i632));
    float tau  = (float)k * FOC_TS;
    float rEst = vStep_V / iInf;      /* 注意：含线缆 + MOS 导通电阻 + 死区影响 */
    float lEst = tau * rEst;
    Cal_Ld_uH  = lEst * 1.0e6f;
    Cal_Rs_mOhm = rEst * 1.0e3f;
}

案例：施加 0.24 V，理论终值 20 A、τ = 3.75 ms（第 75 个采样点附近达 12.6 A）。电压给定 ≠ 实际电压：低压大电流时死区压降可达给定的相当比例，需死区补偿（C13）或改用更大电压并扣除。

第七部分：高频调试问题 / 数学易错点

【高频故障】阶跃法测得 τ 远小于设计值
现象
测得 τ = 1.2 ms，设计 3.75 ms。
可能根因
R 包含线缆、MOS、接插件电阻而偏大；死区导致实际电压偏低、终值偏小；转子未锁定（q 轴分量混入）；电感饱和。
排查顺序
① LCR 表测线间电感对比 → ② 用示波器测实际相电压 → ③ 改变阶跃幅值看 τ 是否变化 → ④ 确认对齐。
修复
死区补偿后重测；用 L = τ·R 时 R 取同一实验终值算出的总电阻；多幅值多次平均。
验证
两种方法（阶跃 / 高频注入）结果差 < 10%。
【高频故障】电流环带宽调不上去，一提高就振荡
现象
按 2 kHz 设计参数后 iq 振荡。
可能根因
1.5Ts 延迟在 2 kHz 处滞后 54°，再加 PI 与滤波，相位裕度不足。
排查
计算各环节相位滞后之和；扫频测开环。
修复
带宽回到 PWM 频率 1/20 左右；减小采样滤波；改双采样双更新（需评估）。
验证
阶跃超调 < 10%，相位裕度 ≥ 45°。
数学易错点：把 fc 与 ωc 混淆
现象
参数差 6.28 倍。
根因
ωc = 2π·fc，单位 rad/s 与 Hz 混用。
排查
检查所有公式单位。
修复
代码注释写清单位。
验证
实测带宽与设计一致。

第八部分：工程踩坑

  • 传递函数假设线性时不变：Ld、Lq 随电流饱和、Rs 随温度变化（铜电阻约 +0.39%/°C），参数需分工况标定。
  • 仿真模型忽略延迟：Simulink 连续模型的电流环带宽可以设很高，上台架即振荡——仿真必须加入 1.5Ts 延迟与 ZOH。
  • 【风险红线】阶跃辨识电压过大：低阻电机 0.5 V 即可产生 40 A 以上电流，务必先小后大并开启过流保护。

第二部分：前置条件

第三部分：核心原理与公式

【理论公式】 连续 PID：u(t) = Kp·e + Ki·∫e dt + Kd·de/dt 零极点对消设计（电流环，对象 1/(Ls+R)）： C(s) = Kp + Ki/s = Kp·(s + Ki/Kp)/s，令 Ki/Kp = R/L 开环 C·G = (Kp/L)/s → 闭环 T(s) = ωc/(s + ωc)，ωc = Kp/L ⇒ Kp = ωc·L，Ki = ωc·R 案例（ωc = 2π·1 kHz）【案例假设】： d 轴 Kp = 0.283 V/A，Ki = 75.4 V/(A·s)；q 轴 Kp = 0.471 V/A，Ki = 75.4 V/(A·s) 【离散实现】位置式（后向矩形积分）： I[k] = I[k−1] + Ki·Ts·e[k]，u[k] = sat(Kp·e[k] + I[k]) 增量式：Δu[k] = Kp·(e[k] − e[k−1]) + Ki·Ts·e[k]，u[k] = sat(u[k−1] + Δu[k]) 【定点实现】标幺：Kp_pu = Kp·I_BASE/V_BASE，KiTs_pu = Ki·Ts·I_BASE/V_BASE d：Kp_pu = 0.884 → Q12 = 3619；q：Kp_pu = 1.473 → Q12 = 6032（> 1，不能用 Q15） KiTs_pu = 75.4 × 50e-6 × 50/16 = 0.01178 → Q15 = 386 抗积分饱和：① 积分器限幅 ② 条件积分（输出饱和且误差同向时冻结）③ 反算法 I += Kb·(u_sat − u)

拖动滑块 / 按钮：「零极点对消」恢复 1 kHz 设计值；「演示积分饱和」把电压限幅降到 1 V 并关闭抗饱和，可见大超调和下降沿拖尾，再勾选抗饱和对比；「演示延迟振荡」把 Kp 提高到 1.2，延迟使环路失稳并在限幅间持续振荡。
正常：超调 正常：上升约 0.35 ms、几乎无超调。lt; 5%，10→90% 上升时间在 0.35 ms 量级（连续一阶理论值 2.2/ωc = 0.35 ms；离散 + 量化步长下显示值会略小）。异常：超调 > 20%、持续振荡、长时间贴限幅。

第四部分：嵌入式实现步骤

  1. 误差：e = ref − fb（Q15），注意 int32 计算防溢出。
  2. P 项：Kp_q12 × e >> 12 → Q15，int32。
  3. I 项：积分状态 int32 Q30，增量 KiTs_q15 × e（Q30），用 int64 求和再限幅。
  4. 输出限幅：限幅值来自电压圆（A02），每周期按实测 Vdc 更新。
  5. 抗饱和：输出饱和时只允许积分朝退饱和方向变化（条件积分）。
  6. 中断约束：PI 在 PWM 中断内执行；参数通过 XCP 修改时，Kp/Ki 写入需原子（int16 单次写入天然原子）。
  7. D 项：电流环一般不用（采样含 PWM 纹波，D 放大噪声且相位已够）；速度/位置环如需 D，必须带低通（C08）。

第五部分：仿真与波形预期

  • 设计值：iq 阶跃上升时间 ≈ 0.35/1 kHz = 0.35 ms，超调很小。
  • Kp 过大：高频振荡（延迟引起）；Ki 过大（Ti 远小于 τ）：低频超调。
  • 电压饱和：电流上升斜率受限（di/dt = (Vmax − R·i)/L），无抗饱和时退出饱和后超调。

第六部分：EPS 案例实现

typedef struct {
    int16_t kp_q12;        /* Kp 标幺，Q12（范围 ±8）       */
    int16_t kiTs_q15;      /* Ki·Ts 标幺，Q15              */
    int32_t integ_q30;     /* 积分状态，Q30                 */
    q15_t   outMax;        /* 输出上限（正数）              */
    q15_t   outMin;        /* 输出下限（负数）              */
} PI_tst;

q15_t PI_Run(PI_tst *pi, q15_t err)
{
    int32_t p    = ((int32_t)pi->kp_q12 * (int32_t)err) >> 12;            /* Q15 */
    int64_t iNew = (int64_t)pi->integ_q30 + ((int64_t)pi->kiTs_q15 * err);  /* Q30 */
    int64_t iMax = (int64_t)pi->outMax << 15;
    int64_t iMin = (int64_t)pi->outMin << 15;
    int32_t u;

    if (iNew > iMax) { iNew = iMax; }          /* ① 积分器自身限幅 */
    if (iNew < iMin) { iNew = iMin; }

    u = p + (int32_t)(iNew >> 15);

    if (u > pi->outMax) {                      /* ② 条件积分 */
        u = pi->outMax;
        if (err < 0) { pi->integ_q30 = (int32_t)iNew; }   /* 只允许退饱和方向 */
    } else if (u < pi->outMin) {
        u = pi->outMin;
        if (err > 0) { pi->integ_q30 = (int32_t)iNew; }
    } else {
        pi->integ_q30 = (int32_t)iNew;
    }
    return (q15_t)u;
}

/* 案例初始值（1 kHz 带宽，零极点对消）【案例假设】 */
volatile int16_t Cal_IdKp_q12   = 3619;   /* 0.283 V/A */
volatile int16_t Cal_IqKp_q12   = 6032;   /* 0.471 V/A */
volatile int16_t Cal_IdKiTs_q15 = 386;    /* 75.4 V/(A·s) × 50 µs */
volatile int16_t Cal_IqKiTs_q15 = 386;

第七部分：高频调试问题 / 数学易错点

第八部分：工程踩坑

  • 运行中修改 Kp：位置式 PI 输出跳变；可在修改时重算积分器保证输出连续（bumpless）。
  • d、q 两个 PI 共用限幅值：d 轴优先限幅后 q 轴的限幅是动态的，必须传入圆限幅后的实际剩余量。
  • 速度环 PI 的输出是 iq 给定，限幅为电流极限；电流环输出是电压——不同环的抗饱和信号不能混用。
  • 【风险红线】积分器在故障关管后未清零，重新使能 PWM 瞬间输出满电压 → 过流冲击。
